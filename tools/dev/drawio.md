## 一、簡介與介面設定 (`00:00`)

### 1. 取得方式

- **網頁版**：直接打開 [app.diagrams.net](https://app.diagrams.net) 即可使用，免安裝。
- **桌面版**：提供 Windows / macOS / Linux 安裝包，離線可用。
- **儲存整合**：支援 Google Drive、OneDrive、GitHub、本地硬碟等多種儲存位置，檔案格式為可編輯的 XML（`.drawio`）。

### 2. 介面與偏好設定

- **多國語言**：右上角可切換介面語言（含繁體中文）。
- **範本選擇**：開啟時可選擇空白圖、流程圖、工程圖、網路圖、平面圖等預設範本。
- **形狀區 (Shapes)**：左側面板分類提供各式圖形，亦可搜尋。

## 二、流程圖製作基本功 (`01:26`)

### 1. 新增與編輯形狀

- **新增形狀**：從左側形狀區拖曳到畫布。
- **新增文字**：**雙擊**形狀即可輸入文字；右側面板可調整字型、大小、顏色、樣式。
- **調整大小 / 旋轉**：選取後拖曳控制點或旋轉把手。

### 2. 連接形狀

- 將游標移到形狀上，會出現**藍色方向箭頭**。
- 點擊箭頭即可往該方向**新增一個形狀並自動連接**（快速複製 + 連線）。

### 3. 常用快速鍵

| 快速鍵                  | 功能                         |
| :---------------------- | :--------------------------- |
| `Ctrl + 拖曳`           | 複製形狀                     |
| `Ctrl + D`              | 複製 (原地)                  |
| `Ctrl + G`              | 將多個物件**群組**為一個容器 |
| `Ctrl + Click` 藍色箭頭 | 往該方向**複製並連接**新形狀 |
| `Shift + Click` 箭頭    | 連接到**既有形狀**（不複製） |
| 雙擊形狀                | 輸入 / 編輯文字              |

> 💡 **畫布自動擴展**：當形狀拖到畫布邊緣時，畫布會自動延伸，不需手動調整尺寸。

## 三、流程圖符號意義 (`02:48`)

標準流程圖符號有其约定俗成的意義，正確使用有助於溝通：

| 符號形狀     | 意義                | 範例                       |
| :----------- | :------------------ | :------------------------- |
| 🟢 圓角矩形  | **開始 / 結束**     | 「開始」、「結束」         |
| ▭ 矩形       | **處理 / 動作**     | 「計算總分」、「寄送通知」 |
| ◇ 菱形       | **判斷 / 決策**     | 「分數 ≥ 60？」            |
| ▭ 帶斜邊矩形 | **資料 / 輸入輸出** | 「輸入姓名」、「顯示結果」 |
| → 箭頭       | **流程方向**        | 連接各步驟                 |

## 四、組織圖製作技巧 (`04:52`)

### 1. 群組與範本 (Scratchpad)

- **群組 (`Ctrl + G`)**：把多個形狀組合成單一容器，方便整體移動。
- **Scratchpad (暫存區)**：可將常用形狀組合**拖入暫存區**存成範本，之後直接拖出重複使用，大幅加速製圖效率。

### 2. 替換圖片

- 組織圖的成員方塊可**替換為實際照片**：選取形狀 → 右側面板 → 替換 / 匯入圖片。

## 五、效率技巧：藍色箭頭複製 (`06:32`)

- 游標靠近形狀會浮現**四向藍色箭頭**，搭配 `Ctrl` 操作：
  - **`Ctrl + Click` 藍色箭頭**：往該方向**複製並自動連線**，快速產生一整排或一整層節點。
  - **`Shift + Click` 藍色箭頭**：連線到**既有形狀**而不複製。
- 善用此技巧可省去手動畫線的時間，尤其適合組織圖、決策樹等重複結構。

## 六、樹狀圖動態展示 (`08:15`)

### 1. 移動整個分支

- 拖曳**父節點**時，子節點會跟著移動（保持連線）。
- 群組後移動更穩定。

### 2. 摺疊功能 (Folding)

- 樹狀節點支援**摺疊 / 展開**：點擊節點上的圖示即可隱藏或顯示子分支。
- 適合用於**動態簡報**——展示時逐層展開，避免一次顯示過多資訊。

## 七、泳道圖製作實戰 (`09:14`)

泳道圖（Swimlane Diagram）以**欄 / 列**區分不同角色或部門的職責，清楚標示「誰負責什麼」。

### 1. 新增泳道

- 從左側形狀區拖入 **Swimlane** 圖形，設定欄位（角色 / 部門）名稱。

### 2. 連線類型（關鍵）

| 連線類型                | 行為                                     | 適用情境                     |
| :---------------------- | :--------------------------------------- | :--------------------------- |
| **浮動連接 (Floating)** | 連線端點會隨形狀移動**自動調整最佳位置** | 一般流程連接（推薦預設）     |
| **固定連接 (Fixed)**    | 連線端點**固定**在指定位置，不隨移動改變 | 需要精確控制連線起點／終點時 |

> 切換方式：拖曳連線時，游標靠近形狀會出現連接點；選擇不同的連接點類型即可切換 Floating / Fixed。

## 八、圖層管理 (`11:24`)

面對複雜圖表時，**圖層 (Layers)** 是組織與簡報的利器。

### 1. 新增 / 切換圖層

- 右側或上方工具列開啟**圖層面板**，可新增多個圖層。
- 每個圖層可獨立顯示 / 隱藏、鎖定。

### 2. 應用：分步驟簡報

- 將流程的不同階段放在**不同圖層**。
- 簡報時依序顯示各圖層，即可呈現**逐步展開**的效果，讓複雜流程更易理解。

## 匯出格式

Draw.io 支援多種匯出格式：

| 格式              | 特色                       |
| :---------------- | :------------------------- |
| **PNG / JPEG**    | 點陣圖，適合插入文件、簡報 |
| **SVG**           | 向量圖，縮放不失真         |
| **PDF**           | 適合列印、正式文件         |
| **XML (.drawio)** | 保留可編輯性，方便日後修改 |

---

## 重點總結

1. **免費開源、跨平台**，可直接用瀏覽器或桌面版，支援多種雲端儲存。
2. **藍色箭頭 + `Ctrl / Shift`** 是效率核心，快速複製連線。
3. **Scratchpad** 範本化常用組合，減少重複工作。
4. **泳道圖的 Floating / Fixed 連線**決定連線是否隨形狀自動調整。
5. **圖層 + 樹狀摺疊**讓複雜圖表可做動態、分步驟的簡報展示。
6. 製圖前先確認**標準流程圖符號**的意義，確保溝通無歧義。
