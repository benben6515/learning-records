## 移動（Movement）

### 基礎移動

| 快捷鍵 | 功能 |
|--------|------|
| `h` | 左 |
| `j` | 下 |
| `k` | 上 |
| `l` | 右 |
| `w` | 下一個單字開頭 |
| `W` | 下一個單字開頭（忽略標點） |
| `b` | 上一個單字開頭 |
| `B` | 上一個單字開頭（忽略標點） |
| `e` | 單字結尾 |
| `E` | 單字結尾（忽略標點） |
| `0` | 行首 |
| `^` | 第一個非空白字元 |
| `$` | 行尾 |
| `gg` | 文件開頭 |
| `G` | 文件結尾 |
| `:10` | 跳至第 10 行 |
| `10G` | 跳至第 10 行 |
| `%` | 跳到對應括號 |

| 快捷鍵 | 功能 |

| `,` | 反向重複上次 f/t 搜尋 |

| `{` | 跳到上一段 |

| `M` | 螢幕中間 |
| `L` | 螢幕底部 |
| `zz` | 將當前行置中 |
| `zt` | 將當前行置頂 |
| `zb` | 將當前行置底 |
| `Ctrl + d` | 向下半頁 |
| `Ctrl + u` | 向上半頁 |

| `Ctrl + b` | 向上整頁 |

```
Ctrl+v         進入區塊選取
選取範圍
I              在區塊前插入
輸入文字
Esc            套用到所有行

A              在區塊後追加
輸入文字
Esc            套用到所有行

c              修改區塊
輸入文字
Esc            套用到所有行

r{char}        取代區塊為指定字元
```

## 搜尋與取代（Search & Replace）

### 搜尋

| 快捷鍵 | 功能 |
|--------|------|
| `/pattern` | 向下搜尋 |
| `?pattern` | 向上搜尋 |
| `n` | 下一個搜尋結果 |
| `N` | 上一個搜尋結果 |
| `*` | 搜尋游標下的單字 |
| `#` | 反向搜尋游標下的單字 |
| `g*` | 搜尋游標下的單字（部分匹配） |
| `g#` | 反向搜尋游標下的單字（部分匹配） |
| `:noh` | 取消搜尋高亮 |

### 取代

| 命令 | 功能 |
|------|------|
| `:%s/old/new/g` | 全域替換 |
| `:%s/old/new/gc` | 互動式全域替換 |
| `:%s/old/new/gi` | 不分大小寫全域替換 |
| `:%s/old/new/gI` | 完全比對替換 |
| `:s/old/new/g` | 替換目前行 |
| `:s/old/new/gc` | 互動式目前行替換 |
| `:1,10s/old/new/g` | 第 1-10 行取代 |
| `:%s/old/new/gn` | 顯示匹配次數（不執行） |
| `:%s/old/new/e` | 靜默模式（不顯示錯誤） |

### 正則表達式

| 符號 | 功能 |
|------|------|
| `^` | 行首 |
| `$` | 行尾 |
| `.` | 任意字元 |
| `*` | 前一個字元 0 次或多次 |
| `+` | 前一個字元 1 次或多次 |
| `?` | 前一個字元 0 次或 1 次 |
| `[abc]` | a 或 b 或 c |
| `[^abc]` | 非 a、b、c |
| `\d` | 數字 [0-9] |
| `\w` | 單字字元 [a-zA-Z0-9_] |
| `\s` | 空白字元 |
| `{n,m}` | 前一個字元 n 到 m 次 |
| `\b` | 單字邊界 |
| `\1` | 反向參考 |

## 巨集（Macro）

### 巨集操作

| 快捷鍵 | 功能 |
|--------|------|
| `qa` | 開始錄製巨集到暫存器 a |
| `q` | 停止錄製 |
| `@a` | 執行巨集 a |
| `@@` | 重複上次巨集 |
| `10@a` | 執行巨集 a 十次 |
| `qA` | 附加錄製巨集到暫存器 a |
| `:let @a = '...'` | 直接編輯巨集 |

### 巨集範例

```
qa         開始錄製
^          跳到行首
dw         刪除單字
j          跳到下一行
q          停止錄製
100@a      執行 100 次
```

## 常用組合技（Pro Tips）

### 快速編輯

```
dip            刪除段落
ggdG           刪除整個檔案
:%!sort        排序整個檔案
:%!jq .        格式化 JSON
:%!xmllint --format -  格式化 XML
:g/pattern/d   刪除所有匹配行
:v/pattern/d   刪除所有不匹配行
:%s/^\s\+$//g  刪除行尾空白
:%s/\s\+$//g   刪除行尾空白
:%s/\n\{3,}/\r\r/g  將多個空行換成 2 個
:%s/\r$//      刪除行尾 CR
:%s/ /  /g     將 Tab 換成空格
:%s/   /  /g   將 Tab 換成 2 個空格
:%s/\s\+$//    刪除行尾空白
:%s/\<\w\+\>/\u&/g  將單字首字母大寫
:%s/\<\w\+\>/\l&/g  將單字首字母小寫
```

### 常用搜尋

```
/\<word\>      精確匹配搜尋
/\v\w+         使用極簡正則
/^\s*$         搜尋空行
/\s\+$         搜尋行尾空白
/\t            搜尋 Tab
/^[ \t]*       搜尋空行或只有空白的行
/\r            搜尋換行符號
/\n            搜尋換行符號
```

### 標記與跳轉

```
ma             設標記 a
`a             跳到標記 a
'a             跳到標記 a（行首）
m'             設標記 '（上次跳轉位置）
`'             跳到上次跳轉位置
```

### 常用命令組合

```
:%s/old/new/gc 互動式全域替換
:%s/old/new/g  靜默全域替換
:%!python -m json.tool  格式化 JSON
:%!jq .        格式化 JSON
:%!xmllint --format -  格式化 XML
:%s/^\s\+//g   刪除行首空白
:%s/\s\+$//g   刪除行尾空白
:%sort         排序整個檔案
:%sort!        反向排序
:%sort u       排序並去重複
:g/^/m 0       反轉檔案行順序
:g/pattern/d   刪除所有匹配行
:v/pattern/d   刪除所有不匹配行
```
