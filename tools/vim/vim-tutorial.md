# Vim 完整教學

## 五種模式

| 模式    | 進入方式             | 用途       |
| ------- | -------------------- | ---------- |
| Normal  | `Esc`                | 移動、操作 |
| Insert  | `i` / `a` / `o`      | 編輯文字   |
| Replace | `R`                  | 取代文字   |
| Visual  | `v` / `V` / `Ctrl+v` | 選取文字   |
| Command | `:`                  | 執行命令   |

## 基礎操作

### 移動

```
h j k l        左 下 上 右
w / W          下一個單字（含標點 / 不含標點）
b / B          上一個單字
e / E          單字結尾
0              行首
^              第一個非空白字元
$              行尾
gg             檔案開頭
G              檔案結尾
:{number}      跳到第 n 行
{number}G      跳到第 n 行
%              跳到對應括號
```

### 編輯

```
i              游標前插入
I              行首插入
a              游標後插入
A              行尾插入
o              新增下一行
O              新增上一行
s              刪除字元並插入
S              刪除整行並插入
```

### 刪除與複製

```
x              刪除字元
X              刪除前一個字元
dd             刪除整行
dw             刪除單字
d$ / D         刪除到行尾
d0             刪除到行首
yy / Y         複製整行
yw             複製單字
p              貼上（游標後）
P              貼上（游標前）
```

### 復原與重做

```
u              復原
Ctrl+r         重做
.              重複上一個操作
```

### 存檔與離開

```
:w             儲存
:q             離開
:wq / :x / ZZ  儲存並離開
:q! / ZQ       強制離開（不儲存）
:w {file}      另存新檔
:e {file}      開啟檔案
```

### 重複命令（.）- Vim 最強功能

`.` 命令會重複上次的編輯操作，這是 Vim 最強大的功能之一。

```
範例流程：
1. ciw hello Esc    將單字改成 hello
2. j.               移動到下一行，重複同樣修改
3. j.               再下一行，再重複
4. 10.              重複 10 次
```

更多 `.` 的應用：
```
dd                 刪除一行
.                  再刪一行
3dd                刪除 3 行
.                  再刪 3 行（共 6 行）

ci"old Esc         將引號內的 old 修改
n.                 跳到下一個匹配，重複修改
```

**關鍵觀念**：設計你的編輯流程，讓 `.` 可以重複使用

## 進階技巧

### 搜尋與取代

```
/pattern       向下搜尋
?pattern       向上搜尋
n              下一個匹配
N              上一個匹配
*              搜尋游標下的單字
#              反向搜尋游標下的單字

:%s/old/new/g        全部取代
:%s/old/new/gc       全部取代（逐一確認）
:s/old/new/g         當前行取代
:1,10s/old/new/g     第 1-10 行取代
```

### Visual Mode 選取

```
v              字元選取
V              行選取
Ctrl+v         區塊選取（垂直編輯）
gv             重複上次選取
o              切換選取端點
O              切換選取端點（矩形）
```

### Visual Mode 操作

選取後可以直接執行操作：
```
d              刪除選取
y              複製選取
c              修改選取
>              向右縮排
<              向左縮排
~              切換大小寫
u              轉小寫
U              轉大寫
J              合併選取行
=              自動縮排
```

### 區塊編輯（Pro Tip）

```
Ctrl+v         進入區塊選取
選取範圍
I              在區塊前插入
輸入文字
Esc            套用到所有行

A              在區塊後追加
輸入文字
Esc            套用到所有行

r{char}        取代區塊為指定字元
c              修改區塊
輸入文字
Esc            套用到所有行
```

**範例**：批量加上註解符號
```
1. Ctrl+v         進入區塊選取
2. 選取多行
3. I              插入
4. //             輸入註解符號
5. Esc            套用到所有行
```

### 分頁與分割視窗

```
:tabnew        新增分頁
:tabclose      關閉分頁
gt / gT        切換分頁

:split         水平分割
:vsplit        垂直分割
Ctrl+w h/j/k/l 切換視窗
Ctrl+w q       關閉視窗
Ctrl+w _       最大化水平
Ctrl+w |       最大化垂直
Ctrl+w =       平均分配
```

### 暫存器（Register）

```
"ay            複製到暫存器 a
"ap            從暫存器 a 貼上
"+y            複製到系統剪貼簿
"+p            從系統剪貼板貼上
:reg           查看所有暫存器
```

### 巨集（Macro）

```
qa             開始錄製巨集到暫存器 a
q              停止錄製
@a             執行巨集 a
@@             重複上個巨集
10@a           執行巨集 a 10 次
qA             附加錄製（不覆蓋）
:let @a = '...' 直接編輯巨集
```

**巨集範例 1**：批量加上逗號
```
qa             開始錄製
A,             行尾加逗號
Esc            回到 Normal
j              下一行
q              停止錄製
100@a          執行 100 次
```

**巨集範例 2**：批量替換格式
```
qa             開始錄製
^              跳到行首
dw             刪除單字
i[              插入 [
Esc            回到 Normal
A]              行尾加 ]
Esc            回到 Normal
j              下一行
q              停止錄製
@a              執行一次
@@              重複執行
```

## Pro Tips

### 1. 快速移動

```
zz             將當前行置中
zt             將當前行置頂
zb             將當前行置底
H / M / L      螢幕上 / 中 / 下
Ctrl+u / d     上 / 下 翻半頁
Ctrl+f / b     上 / 下 翻整頁
```

### 2. 文字物件（Text Objects）

```
ciw            改變整個單字
ci"            改變雙引號內容
ci( / ci)      改變括號內容
ci{ / ci}      改變大括號內容
cit            改變 HTML 標籤內容
diw            刪除整個單字
yiW            複製整個單字（含標點）
```

### 3. 快速編輯

```
r              取代單一字元
R              進入取代模式
J              合併下一行
~              切換大小寫
gU             轉大寫
gu             轉小寫
```

### 4. 標記（Mark）

```
ma             設標記 a
`a             跳到標記 a（精確位置）
'a             跳到標記 a（行首）
:marks         查看所有標記
```

### 5. 折疊（Fold）

```
zf             建立折疊
zo             開啟折疊
zc             關閉折疊
za             切換折疊
zR             開啟所有折疊
zM             關閉所有折疊
```

### 6. 自動補全

```
Ctrl+n         下一個補全
Ctrl+p         上一個補全
Ctrl+x Ctrl+f  檔案路徑補全
Ctrl+x Ctrl+l  整行補全
```

### 7. 多檔編輯

```
:bn            下一個 buffer
:bp            上一個 buffer
:bd            關閉 buffer
:ls            列出所有 buffer
```

### 8. 全域命令（Global Command）

`:g` 和 `:v` 可以對符合條件的行執行命令：

```
:g/pattern/d           刪除所有匹配行
:v/pattern/d           刪除所有不匹配行
:g/pattern/normal dd   對匹配行執行 normal 模式命令
:g/pattern/y A         將匹配行複製到暫存器 a
:g/^/m 0               反轉檔案行順序
:g/pattern/s/old/new/g 對匹配行執行取代
```

**範例**：刪除所有空行
```
:g/^$/d
```

**範例**：將所有 TODO 改成 DONE
```
:g/TODO/s/TODO/DONE/g
```

**範例**：複製所有包含 error 的行到新檔案
```
:g/error/y A
:new
"Ap
```

### 9. 常用組合技

```
dip            刪除段落
ggdG           刪除整個檔案
:%!sort        排序整個檔案
:%!jq .        格式化 JSON
:%!xmllint --format -  格式化 XML
:g/pattern/d   刪除所有匹配行
:v/pattern/d   刪除所有不匹配行
:%s/^\s\+$//g  刪除行尾空白
:%s/\s\+$//g   刪除行尾空白
:%s/\<\w\+\>/\u&/g  將單字首字母大寫
:%s/\<\w\+\>/\l&/g  將單字首字母小寫
```

## 常見工作流

### 工作流 1：批量修改變數名

```
1. /old_variable    搜尋第一個
2. cw new_variable  修改
3. n.               跳到下一個，重複修改
4. n.               繼續...
```

### 工作流 2：重構程式碼

```
1. qa               開始錄製
2. ^                跳到行首
3. i                插入
4. "                輸入
5. Esc              回到 Normal
6. $                跳到行尾
7. a                插入
8. "                輸入
9. Esc              回到 Normal
10. j               下一行
11. q               停止錄製
12. @a              執行一次
13. 99@a            執行 99 次
```

### 工作流 3：清理日誌檔案

```
1. :g/^$/d          刪除空行
2. :g/DEBUG/d       刪除 debug 訊息
3. :%s/\t/  /g      將 Tab 換成空格
4. :%s/\s\+$//g     刪除行尾空白
5. :wq              儲存離開
```

### 工作流 4：格式化 JSON

```
1. gg               跳到檔案開頭
2. :%!jq .          格式化整個檔案
3. :wq              儲存離開
```

## 練習建議

### 學習階段

1. **第一天**：熟悉 `h j k l` 移動、`i` 插入、`Esc` 回 Normal、`:wq` 存檔
2. **第一週**：加入 `dd` `yy` `p` `u`、搜尋 `/`
3. **第二週**：學習 Visual mode、文字物件 `ciw`
4. **第三週**：學習 `.` 重複命令、`*` 搜尋單字
5. **第四週**：學習巨集、區塊編輯
6. **持續**：每天學一個新指令，慢慢累積

### 每日練習

- **早晨 5 分鐘**：用 `vimtutor` 練習基本操作
- **工作時**：嘗試用 Vim 完成一個小任務
- **睡前**：回顧今天學到的新指令

### 關鍵觀念

**最重要的觀念**：保持在 Normal mode，只有要輸入文字才進 Insert mode

**次重要觀念**：設計你的編輯流程，讓 `.` 可以重複使用

**進階觀念**：學會組合指令（如 `ciw`、`dap`、`yit`），讓操作更高效
