## OpenClaw 架構

### 核心元件

- Tool（工具）
- Skill（技能）
- Agent（代理）
- Task（任務）
- Memory（記憶）

### 執行流程

```
觸發 Task
  ↓
評估 Agent & Memory
  ↓
策劃 Agent & Skill
  ↓
執行 Skill & Tool
  ↓
回饋 Agent & Memory
```

### 架構演進

DAG（有向無環圖）→ A2A（Agent to Agent）
