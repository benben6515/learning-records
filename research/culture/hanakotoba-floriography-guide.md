## 一、什麼是花語

花語（Floriography / Language of Flowers）是用花卉來傳遞情感的「非語言溝通系統」。透過花的種類、顏色、數量、排列方式，表達文字不便明說的情感——尤其是愛情。

它不是單一文化的產物，而是歐洲、亞洲、非洲各地都獨立發展出的傳統，最後在 19 世紀維多利亞時代被系統化為一套「密碼」。

## 二、歷史起源：一條從伊斯坦堡到倫敦的傳播路線

### 2.1 最早的源頭：鄂圖曼土耳其（14 世紀）

花語的系統化源頭是土耳其的 **sélam** 傳統——一種透過物品（包括花）押韻來傳遞訊息的遊戲。14 世紀起在鄂圖曼宮廷流行，18 世紀初君士坦丁堡宮廷對鬱金香的狂熱達到頂峰（「鬱金香時代」1718-1730）。

### 2.2 傳入歐洲（18 世紀）

| 年份     | 關鍵人物                                                   | 貢獻                                                                      |
| -------- | ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| 1718     | **Mary Wortley Montagu**（英國女詩人）                     | 隨丈夫駐鄂圖曼大使期間，將 sélam 傳統帶回英國                             |
| 1727     | **Aubry de La Mottraye**（法國旅行家）                     | 將花語傳入瑞典宮廷                                                        |
| 1809     | **Joseph Hammer-Purgstall**                                | 出版《Dictionnaire du language des fleurs》——第一本花與象徵意義的關聯清單 |
| **1819** | **Madame Charlotte de la Tour**（ Louise Cortambert 筆名） | 出版《Le langage des Fleurs》——**史上第一本花語字典**                     |

### 2.3 維多利亞時期的黃金時代（1837-1901）

花語在英國維多利亞時代達到巅峰。原因是當時的社會氛圍：

- 社交禮儀極度嚴格，情人之間不能公開表達愛意
- 花語成了**秘密通訊工具**——一束花就是一封情書
- 送花的方式也有學問：正拿表示肯定，倒拿表示反義；用右手送表示「是」，左手表示「否」

這段時期大量花語辭典出版，Robert Tyas（1811-1879）是當時最受歡迎的花語作家。

### 2.4 日本的花言葉（Hanakotoba）

日本獨立發展出了自己的花語體系——**花言葉（はなことば）**，深受神道與佛教影響：

- **神道**信仰萬物有靈，花不只是裝飾，而是帶有精神力量
- **佛教**強調花的無常與純淨（如蓮花出淤泥而不染）
- **花道（Ikebana）**：最高的象徵性插花藝術，三段結構——最高枝=天，中枝=人，最低枝=地，人居中為橋樑

學者 Davis F. Hadland 說得好：「拿走日本的風景，就等於拿走他們的詩意，以及他們宗教的花之面——日本人崇拜花木的方式，是務實的西方人完全無法理解的。」

### 2.5 各古文明的根源

| 文明   | 花的角色                                                    |
| ------ | ----------------------------------------------------------- |
| 古埃及 | 用於喪葬儀式，代表淨化與來世                                |
| 古希臘 | 與神話綁定——月桂=阿波羅勝利、水仙=自戀之神、石榴=波瑟芬迴圈 |
| 猶太教 | 用於慶典（五旬節、住棚節），表達感恩                        |
| 印度教 | 花與「空」元素相連，代表靈性                                |
| 中國   | 道密象徵中，花=靈性覺醒的工具，如長生不老藥                 |

## 三、東方 vs 西方：同一朵花，不同意義

這是花語最有趣的部分——沒有「世界通用花語」這回事。

### 3.1 「花中之王」的分歧

- **西方**：玫瑰是萬花之后（Queen of Flowers），愛的終極象徵
- **中國**：牡丹才是花中之王（King of Flowers），代表富貴榮華
- **東亞佛教圈**：蓮花地位最高，代表真理、完美、不朽

### 3.2 同花異義對照表

| 花種 | 東方含義                     | 西方含義   | 反差程度 |
| ---- | ---------------------------- | ---------- | -------- |
| 櫻花 | 忠誠、愛國、燦爛而短暫的生命 | 良好的教育 | ★★★      |
| 水仙 | 好運、幸福                   | 自戀、利己 | ★★★★     |
| 蓮花 | 純潔、真理、神聖             | 口才辯給   | ★★★★     |
| 柳樹 | 柔順、女性美、好運           | 憂鬱、悲傷 | ★★★      |
| 牡丹 | 陽剛、光明、繁榮             | 大膽       | ★★       |
| 石榴 | 多產、生育                   | 愚蠢、痴迷 | ★★★★     |

最戲劇性的反差是**水仙**：東方覺得是好運花，西方直接連結到希臘神話中愛上自己倒影的 Narcissus——代表自戀。

## 六、21 世紀的花語現狀

花語在現代已經不再是「秘密通訊系統」，但它的影響力以另一種形式延續：

1. **情人節紅玫瑰**：最普遍的花語實踐——全球共識
2. **國殤日罌粟花**（11/11）：紀念陣亡將士，源自一戰詩《In Flanders Fields》
3. **母親節康乃馨**：源自美國 Anna Jarvis（1908）
4. **刺青文化**：花型刺青的選擇仍然參考花語（玫瑰=愛、蓮花=重生、向日葵=忠誠）
5. **珠寶設計**：花卉圖案的飾品帶有象徵意義
6. **動漫/文學**：花語仍是重要的敘事工具——例如《進擊的巨人》中大量使用花言葉做暗示

## 七、誠實的反思

### 花語沒有「正確答案」

這份報告整理的對照表是「主流版本」，但實際上花語因地域、時代、甚至花語辭典版本不同就有出入。同一朵花在不同書裡可能有不同意義。花語本質上是**約定俗成**的，不是科學。

### 「花語」不等於「花的文化象徵」

嚴格說，Floriography 指的是 19 世紀那套「用花傳訊息」的密碼系統。而花的「文化象徵」（plant symbolism）——比如蓮花在佛教中的地位——是更古老更廣泛的概念，兩者有重疊但不等同。

### 實用建議

送花時與其鑽研花語密碼，不如考慮：

1. 收花人的**個人偏好**（最安全）
2. **場合**（喪禮別送紅花這種基本常識）
3. **文化背景**（跨文化送花要查禁忌）
4. 附一張手寫卡片——文字永遠比花語精確
