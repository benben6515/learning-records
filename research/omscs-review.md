# Georgia Tech OMSCS 線上資工碩士 — 深度評測筆記

> 來源：YouTube 影片 <https://www.youtube.com/watch?v=jMVOtD1kwJI> + 公開資料補充
> 整理日期：2025-07-05（2025-07-08 擴充）

## 一句話總結

美國頂尖大學的線上 CS 碩士，學費約 $8,950 USD（已漲價），不需要 GRE，錄取率約 74%，但每門課每週需投入 10–25 小時、前置知識門檻極高、支援偏少——**cp 值極高，但不適合多數人**。

## 學費（已更新——不再是 $7,000）

影片中說的 $7,000 已過時。2025/2026 學費已調漲：

| 項目                     | 金額                              |
| ------------------------ | --------------------------------- |
| 每學分                   | **$225 USD**（OMSCS）             |
| 30 學分學費合計          | $6,750                            |
| 雜費（每學期）           | $176（<4 學分）或 $440（≥4 學分） |
| 總費用估計               | **約 $8,950 USD**（約 28 萬台幣） |
| 對比 — OMSA 分析碩士     | $327/credit                       |
| 對比 — OMSCyber 資安碩士 | $369/credit                       |

雙修課程可省雜費（每多一門省約 $107）。2024 年曾有 8% 學費漲幅（+$15/credit）。

來源：[omscs.fyi 學費計算器](https://omscs.fyi/)、[Reddit 討論](https://www.reddit.com/r/OMSCS/comments/1avrwkh/is_omscs_really_only_7000/)

### 工時分佈結論

| 等級   | 工時/週   | 代表課程                                |
| ------ | --------- | --------------------------------------- |
| 地獄級 | 20+ hrs   | ML, AI, Distributed Computing           |
| 重度   | 15–20 hrs | Graduate Algorithms, OS                 |

| 輕度   | <10 hrs   | Software Dev Process, Computer Networks |

### Reddit 過來人經驗

- 一位修完 9 門課的學生：**平均 10–15 小時/週**，但 Distributed Computing 在專案期可能 **25+ 小時/週**
- 有人投入 **50+ 小時/週**（所有空閒時間都奉獻給課業）
- 有 CS 背景的人通常比 OMSCentral 列的平均少 30–50% 時間
- 非 CS 背景的人可能需要 **30+ 小時/週** 來補課
- 大多數課程 15 hrs/wk 可過，輕鬆的 <10 hrs，但想學扎實就要再加 5 hrs

> 你記得的「15–20 小時/週」就是核心課程的真實寫照——Graduate Algorithms 確實在 19 hrs/wk 左右。

## 為什麼不適合多數人（三大警訊）

### 1. 前置知識門檻超高

核心課程是**真正的研究所等級**。

官方建議先修過：

- 演算法設計與分析（graph algorithms, DP, divide & conquer）
- 離散數學（asymptotic runtime analysis）
- 軟體工程或同等業界經驗
- 線性代數、機率與統計（ML 課程需求）

**真實案例**：一位 DevOps 工程師沒 CS 背景就入學，第一學期兩門「入門課」（Software Dev Process + ML for Trading）直接拿雙 F，靠大量自學才勉強畢業。

### 2. 學費便宜 = 砍掉了支援

- 講者自身碩士經驗：80% 時間花在作業和專案
- 撐過去靠的是 office hours、TA、同學每天討論、一對一指導
- OMSCS 在這方面支援明顯較少，需要大量自學
- 但有活躍的線上社群（Reddit r/OMSCS、Discord）彌補一部分

### 3. 就業數據不透明

- 官網**沒公布**畢業生就業去向（講者認為是 red flag）
- 零星 Reddit/Quora 資訊顯示能拿到面試，但主要集中在軟體工程師
- 資料科學等其他領域的就業狀況不明
- 建議認真考慮者直接去問 program 要數據

## 適合誰

1. **已有 CS/CE 相關學士**，且自律到能獨立自學的人
2. **願意在入學前自學一整個大學部 CS 學位**的人（極少見）

## 不適合誰

- 沒相關背景又沒打算大量補課的人 → 會超級痛苦
- 想靠這學位去美國工作的**國際學生** → 線上學位不發簽證、沒 OPT，無法赴美就業
- 無法每週穩定撥出 15–25 小時的人 → 會嚴重落後

## 個人對照（Benben 的情況）

| 考量      | OMSCS                       | 台灣在職專班                                  |
| --------- | --------------------------- | --------------------------------------------- |
| 互動支援  | 偏少，孤軍奮戰              | 有實體互動、同儕壓力                          |
| 數學底子  | 可發揮（應數系背景）        | 同樣可發揮                                    |
| 學習風格  | 自學為主                    | 較符合喜歡討論的風格                          |
| 目標領域  | AI/ML（需先補 CS 核心課程） | AI/數據科學（成大AI資訊、交大資電、中央資工） |
| 簽證/就業 | 線上無簽證                  | 在職進修，直接在台灣發展                      |
| 費用      | ~$8,950 USD（約 28 萬台幣） | 視學校而定                                    |
| 每週工時  | 核心課 15–25 hrs/wk         | 視學校而定，通常有實體課可問                  |

**結論**：OMSCS 雖然便宜，但省掉的是「互動與支援」，而我重視數學底子 + 應用，這種孤軍奮戰的模式可能不適合我的學習風格。台灣在職專班雖然貴一些，但有實體互動和同儕壓力，可能更適合。
