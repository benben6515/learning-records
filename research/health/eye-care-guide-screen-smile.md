# 眼睛保養指南 — 重度螢幕用眼 × SMILE 雷射手術後

> 對象：前端開發者，上班 + 下班全天盯螢幕，已做 SMILE 雷射近視手術
> 整理日期：2026-07-18（初版）·2026-07-18 補強（加入 Doctor 賴影片 + ddgs 查證）
> 依據：AAO（美國眼科醫學會）、AOA（美國驗光學會）、Cochrane Review、AREDS2、Nature Eye 等共識

## 一句話總結

你的眼睛同時背了兩個風險因子——**全天螢幕造成的疲勞 + 乾眼**，以及 **SMILE 術後角膜結構改變帶來的長期照護需求**。保養的核心不是買一堆保健品，而是「**習慣 > 營養 > 補充品**」：把 20-20-20、環境光線、眨眼、定期追蹤這四件事做到位，效果遠勝葉黃素。

## Part 1：先搞懂你正在對眼睛做什麼

### 電腦視力症候群（CVS / Digital Eye Strain）

長時間盯螢幕會造成的問題，不是「藍光燒壞眼睛」（這是迷思，見下），而是：

| 症狀               | 成因                                                         |
| ------------------ | ------------------------------------------------------------ |
| 眼睛乾澀           | 盯螢幕時**眨眼次數從每分鐘 ~15 次掉到 5–7 次**，淚液蒸發太快 |
| 視力模糊、對焦困難 | 睫狀肌長時間維持近距離對焦，肌肉疲勞（調視痙攣）             |
| 畏光、流淚         | 角膜上皮因乾燥受刺激的代償反應                               |
| 頭痛、肩頸緊       | 姿勢不良 + 用眼過度的連帶效應                                |
| 視力「感覺變差」   | 多半是暫時性疲勞，不是近視回來了                             |

關鍵數字：眨眼頻率下降是 CVS 最大的單一成因，而 SMILE 術後你本來就更容易乾眼——兩者疊加，乾眼會是你最常遇到的問題。

### 藍光迷思（要先破除，才不會亂花錢）

- **藍光會不會傷眼？** 3C 螢幕的藍光強度遠低於陽光。Doctor 賴（放射腫瘤科醫師）從「能量與劑量」角度強調：實驗室裡造成視網膜細胞傷害的強光暴露，跟日常手機/平板/電腦螢幕的藍光劑量**完全不是同一個等級**。目前沒有高品質證據顯示日常螢幕藍光會造成黃斑部病變或永久傷害。
- **濾藍光眼鏠有用嗎？** Cochrane 2023 年系統性回顧（**17 個隨機對照試驗**，由墨爾本大學主導）結論：濾藍光眼鏠對眼睛疲勞、眼睛健康、睡眠品質**「可能沒有差別」**。來源：<https://www.cochrane.org/about-us/news/blue-light-filtering-spectacles-probably-make-no-difference-eye-strain-eye-health-or-sleep>。不需要為了「防藍光」特別去配。
- **藍光真正影響的是睡眠（機制清楚）**：藍光會刺激視網膜上的**ipRGCs（內在光敏視網膜神經節細胞）**，這些細胞直接影響**褪黑激素分泌**與生理時鐘。所以濾藍光功能的正確用法是「**晚上開 Night Shift / 夜覽模式幫助睡眠**」，不是白天防護。
- **真正讓你眼睛累的是：用眼時間長 + 距離太近 + 不眨眼 + 螢幕太亮/太暗 + 頻閃**。

## Part 2：螢幕用眼 SOP（CP 值最高、效果最大）

這部分是全部指南裡 ROI 最高的。做到這些，比吃任何保健品都有效。

### 黃金法則：20-20-20 vs 30-10-120

有兩個版本，用途不同，不要搞混：

| 原則          | 內容                                                                                         | 適用                                | 出處                        |
| ------------- | -------------------------------------------------------------------------------------------- | ----------------------------------- | --------------------------- |
| **20-20-20**  | 每 20 分鐘，看 20 呎（6m）外，持續 20 秒                                                     | 成人減少**眼睛疲勞**                | AOA（美國驗光學會）         |
| **30-10-120** | 近距離用眼 **30 分鐘** → 休息 **10 分鐘**（要看遠方不是換滑手機）→ 每天戶外活動 **120 分鐘** | 兒童/青少年**預防近視**、成人也適用 | Doctor 賴影片／近視防控研究 |

**給你的建議（成人 SMILE 術後）**：

- 上班時落實 **20-20-20**（高頻小休息，防疲勞）。
- 下班/週末補 **30-10-120** 的精神：用眼 30 分鐘就真的離開螢幕 10 分鐘（不是換滑手機），週末盡量累積戶外時間。
- 為什麼有效：讓睫狀肌放鬆、重新對焦到無限遠，恢復彈性。
- 工具：macOS 內建沒有，可以用 `Time Out`（免費）、或 `stretchly`（開源跨平台）、或直接設整點鬧鐘。
- 看遠方時**刻意多眨幾下**，順便補淚液。

**誠實提醒**：20-20-20 雖然是 AAO/AOA 官方建議，但學界也有人質疑它缺乏嚴謹療效證據（見 _The '20/20/20 Rule' – When Good Intentions…_ 一文）。不過它免費、無副作用、即使效果有限也沒壞處，仍是目前最被廣泛接受的低成本護眼習慣。

### 螢幕距離與擺放

| 項目     | 建議                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 螢幕距離 | **50–70 公分**（一個手臂長），越大螢幕可以越遠                                                 |
| 螢幕高度 | 螢幕**上緣與視線平齊或略低**，讓眼睛自然往下 15–20 度看 → 眼皮略蓋、減少眼球暴露面積、降低蒸發 |
| 雙螢幕   | 主螢幕正前方，副螢幕角度 < 35 度，避免頭頸轉動                                                 |
| 字體大小 | 寧可放大，不要瞇眼。瞇眼會擠壓眼球、加速疲勞                                                   |

### 環境光線

- **避免螢幕比背景亮太多或暗太多**：亮度對比是疲勞主因。
- 白天：窗戶在側邊，不要在螢幕正後方（反光）或正對螢幕（刺眼）。
- 夜晚：**不要關燈看螢幕**。放一盞環境燈（偏暖色 < 4000K），讓螢幕亮度與環境接近。
- 螢幕反光：用霧面螢幕或抗反光膜，比任何濾鏡有效。

### 主動眨眼訓練

這是大多數人忽略的：

- **完全眨眼**：很多人眨眼是「半眨」，眼皮沒完全閉合，下層淚液根本沒抹勻。
- 練習「**輕閉→緊閉→睜開**」三拍，每小時做 5–10 下，強迫淚腺分泌。
- SMILE 術後特別重要：你的角膜神經被切斷過，淚液反射較弱，更要**主動**眨。

## Part 3：SMILE 術後長期照護（你的專屬重點）

### 先說手術特性

SMILE（Small Incision Lenticule Extraction）用飛秒雷射在角膜內切出一片「透鏡」再從小切口（~2mm）取出。和 LASIK 比：

|              | SMILE                | LASIK               |
| ------------ | -------------------- | ------------------- |
| 角膜瓣       | **無**（小切口）     | 有（掀瓣）          |
| 乾眼風險     | 較低，但**仍會發生** | 較高                |
| 瓣膜移位風險 | 無                   | 有（撞擊時）        |
| 角膜神經切斷 | 周邊切口仍會切斷神經 | 較多                |
| 術後運動限制 | 較少                 | 較多（前 1-3 個月） |

**重點：SMILE 沒有瓣膜移位風險，但「乾眼」和「角膜神經修復」是長期課題。** 神經約需 6–12 個月重新生長，期間乾眼感最明顯。

### SMILE 術後長期注意事項

#### 1. 乾眼管理（最重要，沒有之一）

- 術後乾眼高峰 1–3 個月，但**部分人會持續 6–12 個月甚至更久**，少數變成慢性。
- 你的「全天螢幕」會把乾眼放大，務必認真處理（見 Part 4 人工淚液）。
- **環境濕度**：辦公室冷氣房通常太乾（相對濕度常 < 40%），放個桌上型加濕器或對著出風口避開。

#### 2. 揉眼睛是大忌

- 雖然 SMILE 無瓣膜，但**術後前 6 個月劇烈揉眼仍可能影響角膜形狀**（少數報告角膜擴張）。
- 眼睛癢時用人工淚液沖，不要揉。睡覺可戴護目鏡避免無意識揉。
- 長期來說，揉眼本來就和**圓錐角膜、近視加深**有關，術後更要戒。

#### 3. 紫外線防護

- 術後角膜對 UV 較敏感，過度曝曬會影響癒合、增加角膜混濁（Haze）風險（SMILE 機率低於 PRK，但仍存在）。
- **白天戶外務必戴太陽眼鏡**，選 UV400、偏光款式。開車、騎車、登山尤其重要。
- 雪地、海邊、高海拔的 UV 反射強，更要注意。

#### 4. 運動與活動限制

| 時間        | 可做                     | 要避免                                     |
| ----------- | ------------------------ | ------------------------------------------ |
| 術後 1 週   | 散步、輕度辦公           | 流汗運動（汗水入眼易感染）、化妝、游泳     |
| 1 週–1 個月 | 慢跑、健身房（避免汗水） | 游泳、泡溫泉、三溫暖、球類（撞擊風險）     |
| 1–3 個月    | 大部分運動恢復           | 搏擊、拳擊等直接撞擊眼睛的運動（永久避免） |
| 3 個月後    | 全部恢復                 | 拳擊、角力等高撞擊運動建議永久戴護目鏡     |

- 游泳務必等滿 1 個月 + 戴蛙鏡；自然水域（海、溪、湖）建議等 3 個月，水質污染風險高。

#### 5. 定期追蹤排程

| 時間                                          | 檢查重點                         |
| --------------------------------------------- | -------------------------------- |
| 術後 1 天、1 週、1 個月、3 個月、6 個月、1 年 | 角膜癒合、視力穩定度、乾眼、眼壓 |
| 之後每年 1 次                                 | 一般成人眼科健檢                 |
| 任何異常                                      | 立即回診（見下方警訊）           |

#### 6. 警訊（出現立刻回診）

- **突發性視力下降**（不是疲勞那種漸進模糊）
- **劇烈眼痛**（不是乾澀癢）
- **嚴重畏光、持續紅眼**
- **異常分泌物（黃綠色）**
- **飛蚊突然變多、看到閃光**（視網膜警訊，雖與 SMILE 無直接關係，但近視族本就是視網膜剝離高風險群）

## Part 4：人工淚液與乾眼對策（SMILE 術後必讀）

### 人工淚液選擇

| 種類                                        | 適用                                | 注意                                                      |
| ------------------------------------------- | ----------------------------------- | --------------------------------------------------------- |
| **不含防腐劑** 單支裝（人工淚液、玻璃酸鈉） | **術後首選**，每天用 4 次以上者必選 | 開封 24 小時內用完                                        |
| 含防腐劑瓶裝（多含 BAK / Polyquad）         | 偶爾用、次數少者可接受              | **BAK 長期使用會傷角膜上皮**，術後避免；Polyquad 相對安全 |

> **BAK 毒性的證據（2026-07-18 補強）**：Nature 旗下 _Eye_ 期刊 2021 年回顧指出，**BAK（benzalkonium chloride）用於約 70% 的眼科製劑**，會對結膜與角膜上皮細胞造成細胞毒性，導致角膜染色、淚液破裂時間縮短、OSD 症狀分數升高——是醫源性乾眼的主因之一。來源：<https://www.nature.com/articles/s41433-021-01668-x>。2025 年 _Scientific Reports_ 動物實驗進一步確認 BAK 會造成實質角膜損傷。**結論：SMILE 術後乾眼期，務必選無防腐劑單支裝，不要貪便宜用含 BAK 的瓶裝。**
> | 高黏稠度凝膠 / 軟膏 | 睡前用，重度乾眼 | 白天用會模糊視線 |
> | **脂質型**（含油脂） | 蒸發型乾眼（瞼板腺功能障礙） | 螢幕族常是這型 |
> | 血清滴劑 | 嚴重乾眼，需自費抽血製作 | 醫師評估後才用 |

**給你的建議**：

- 主力用**不含防腐劑單支裝的玻尿酸鈉（0.1–0.3%）**，一天 4 次（早、午、下班、睡前）。
- 常見品牌：愛麗淚液（Hyalein）、淚然（Tears Natural）、視舒坦（Systane）無防腐劑版。
- 熱敷眼罩（40°C，10 分鐘）每週 2–3 次，改善瞼板腺油脂分泌，對蒸發型乾眼有效。

### 熱敷怎麼做才對

1. 溫度 38–42°C（不要太燙，眼皮皮膚薄）。
2. 閉眼熱敷 10 分鐘。
3. 輕壓上下眼皮邊緣 5–10 下。
4. 用棉花棒沾人工淚液清潔睫毛根部。

## Part 5：營養與補充品（證據等級誠實版）

這部分很多人過度期待。我把證據強度誠實分級。

### 有實證支持的（但效果有限，且是針對特定疾病）

| 營養素                                     | 證據等級                                                  | 適用對象             | 你的情況                                                       |
| ------------------------------------------ | --------------------------------------------------------- | -------------------- | -------------------------------------------------------------- |
| **葉黃素 + 玉米黃素（Lutein+Zeaxanthin）** | AREDS2 研究（NIH 主導）：能**減緩**老年性黃斑部病變惡化   | 中老年、已有黃斑病變 | 你 30 歲、無病變，**預防效果未證實**，吃了不會壞事但不期待奇蹟 |
| **Omega-3（EPA+DHA）**                     | 部分研究顯示能改善乾眼，但證據不一；Cochrane 認為效果有限 | 乾眼症患者           | 你乾眼明顯，可適量補充（每日 1000mg），**從食物吃更實在**      |
| **維生素 A / C / E**                       | 缺乏會傷眼，但現代人很少缺；過量反而有害                  | 營養缺乏者           | 正常飲食就夠，不要亂吞高劑量                                   |

### 沒有實證 / 過度炒作的

| 項目                           | 實話                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| **蝦紅素（Astaxanthin）**      | 抗氧化能力強，但**人體臨床證據薄弱**，多為細胞/動物實驗。號稱「護眼聖品」多為行銷。 |
| **山桑子（Bilberry）**         | 二戰飛行員吃藍莓傳說，**缺乏嚴謹臨床證據**。                                        |
| **高單價「護眼配方」保健食品** | 多是葉黃素 + 一堆添加物賣貴，不如單純葉黃素 + 均衡飲食。                            |
| **魚肝油**                     | 過量維生素 A 中毒風險，不要亂吃。                                                   |

### 從食物攝取（最實在）

| 營養素            | 食物                                                 |
| ----------------- | ---------------------------------------------------- |
| 葉黃素 / 玉米黃素 | **深綠色蔬菜**（菠菜、羽衣甘藽、地瓜葉）、蛋黃、玉米 |
| Omega-3           | 鯖魚、鮭魚、秋刀魚、亞麻籽、核桃                     |
| 維生素 A          | 胡蘿蔔、南瓜、地瓜、肝臟（適量）                     |
| 維生素 C          | 芭樂、奇異果、甜椒、花椰菜                           |
| 花青素            | 藍莓、紫高麗菜、葡萄皮                               |

**結論**：与其買保健品，不如每天一份深綠色蔬菜 + 一週兩次深海魚。要補充就選單純葉黃素（10–20mg/日，含 zeaxanthin），平價品牌即可。

## Part 6：螢幕與工作環境硬體設定

這是前端開發者可以「設定一次受用永久」的部分。

### macOS 顯示器設定

| 設定                | 建議                                           | 路徑                |
| ------------------- | ---------------------------------------------- | ------------------- |
| 亮度                | 與環境光接近，不要全亮                         | 系統設定 > 顯示器   |
| True Tone           | **開啟**（自動適應環境色溫，減少疲勞）         | 系統設定 > 顯示器   |
| 夜覽（Night Shift） | 晚上 8 點後自動開，色溫偏暖                    | 系統設定 > 顯示器   |
| Dark Mode           | 暗環境下用深色模式（但白天亮環境反而建議淺色） | 系統設定 > 外觀     |
| 對比度              | 可在「輔助使用 > 顯示器」微調增強對比          | 系統設定 > 輔助使用 |
| 字體大小            | 編輯器、終端機字體 **不小於 14–16px**          | 各 IDE 設定         |

### IDE / 終端機（nvim）

- `set linespace=2`（行距加寬，閱讀舒適）。
- 配色避免高對比飽和色（如純紅配純綠），用柔和的 Solarized / Gruvbox / Nord。
- 背景**不要純黑**（#000），用深灰（#1e1e2e 之類）減少與文字對比過強。
- 你記憶中喜歡暗紫色系，這剛好——暗背景 + 中明度前景最不刺眼。

### 螢幕硬體選擇

- **霧面（matte）優於鏡面**：抗反光，長時間用眼差很多。Mac 的鏡面螢幕強烈建議貼霧面膜。
- 解析度：Retina 以上，字體邊緣平滑減少對焦負擔。
- 更新率：外接螢幕選 **120Hz+**（ProMotion），滑動殘影少，眼睛追蹤輕鬆。
- 尺寸：27 吋以上可以拉遠距離，比 24 吋貼臉看好。

### ⚠️ PWM 頻閃（被忽略的隱形殺手，Doctor 賴影片精華）

這是很多人「買了高級螢幕眼睛反而更酸、偏頭痛」的元兇，也是這支影片最有價值的新資訊。

**什麼是 PWM 調光？**
很多 OLED 與高階螢幕為了維持色彩表現，不用「降低電流」的方式變暗，而是用 **PWM（脈衝寬度調變）**——快速開關背光，靠「開關時間比例」讓你看起來變暗。這在敏感族群眼裡是**高頻閃爍**，雖然意識上感覺不到，但眼睛肌肉和大腦會疲勞。

**怎麼判斷？**

- 用相機對著螢幕拍（快門調快），會看到波浪狀橫紋 = 有 PWM。
- 查規格表 / 評測網站（如 Rtings、Notebookcheck）的 flicker 測試。
- 實測網站：<https://testufo.com/ghosting>（看殘影）、<https://www.testufo.com/>（測更新率/頻閃）。

**選購建議（長時間工作者務必注意）**

| 規格                    | 說明                   | 建議               |
| ----------------------- | ---------------------- | ------------------ |
| **DC 調光**             | 靠降低電流變暗，無頻閃 | **首選**           |
| **Flicker-Free**        | 廠商標示的無頻閃認證   | 優先選             |
| **高頻 PWM（>3120Hz）** | 閃太快影響不到大部分人 | 次選               |
| **低頻 PWM（<1000Hz）** | 敏感族群會頭痛、眼酸   | **避免長時間用**   |
| OLED 螢幕               | 色彩好但多為 PWM       | 前端工作要確認型號 |

**Mac / 手機現況**：MacBook 的 mini-LED（Liquid Retina XDR）多數亮度下無頻閃問題，但低亮度下仍有少量 PWM；iPhone OLED 低亮度都有 PWM。如果你看螢幕特別容易疲勞或偏頭痛，這是第一個要查的。

**結論**：買螢幕前，先查它是不是 DC 調光或高頻 PWM，比查「有沒有濾藍光」重要十倍。

## 誠實 ROI 反思

說實話，這份指南裡**最有用的 20% 是**：

1. 20-20-20 + 主動眨眼（免費、效果最大）
2. 不含防腐劑人工淚液規律點（一個月幾百塊）
3. 環境光線對齊、螢幕距離調對（一次設定永久受用）
4. 定期眼科追蹤（早期發現問題）
5. **選對螢幕（DC 調光 / 高頻 PWM > 濾藍光）**——如果你用螢幕會偏頭痛，這是第一個要查的，CP 值極高

**最被高估的 20% 是**：

1. 葉黃素等保健品（AREDS2 只證實對「已有 AMD」患者有效，健康年輕人預防效果未證實）
2. 濾藍光眼鏡（Cochrane 2023 / 17 RCT 認為沒用）
3. 蝦紅素、山桑子等行銷炒作成分（人體臨床證據薄弱）
4. 昂貴的「護眼螢幕貼膜」（霧面膜就好）

你已經做了 SMILE，這是一筆不小的投資，術後照護的 ROI 在於「**養成習慣**」而非「**買東西**」。把上面四件免費的事做到位，你這雙眼睛可以用很久。
