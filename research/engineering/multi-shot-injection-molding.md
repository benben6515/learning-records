## 一、術語定義與製程家族總覽

### 1.1 名稱歧異：多射到底指什麼？

業界對「多射」的稱呼極多且常有誤導：**two-shot、twin-shot、dual-shot、2K（德文 Kunststoff 之縮寫）、two-color（雙色）、double-shot、bi-injection、multi-shot、multi-component（多組分）、overmolding（包覆成型）** 等，不同廠商講法不一。

嚴格來說，這些名稱橫跨了數種不同的製程，必須先區分清楚：

| 製程                                     | 核心機制                                   | 澆口       | 常見名稱                        |
| ---------------------------------------- | ------------------------------------------ | ---------- | ------------------------------- |
| **多射（狹義）**                         | 一機一模具，週期內依序/同步射出多種材料   | **不同澆口** | 2K / two-shot / multi-component |
| **共射出**                               | 兩材料經同軸噴嘴注入同一澆口，形成皮芯結構 | **同一澆口** | co-injection / sandwich molding |
| **包覆成型（廣義）**                     | 基材與覆層可在兩副模具、兩台機台間轉移完成 | 不同模具    | overmolding / insert molding    |
| **單純多料筒換色**                       | 只是配備多料筒的單射機，一次只射一種材料   | —           | 不是真正的多射                  |

> **本文採用 PlasticsToday / MGS 的嚴謹定義**：多射 = **一台射出機 + 一副模具（或一套模具系統），在單一週期內生產出含兩種以上塑膠材料的成品**。

### 1.2 為什麼要多射？——四大價值主張

依 MGS（美國最大多射方案商之一）的歸納，多射為產品加值的方式有四類：

1. **軟觸感**：手工具、牙刷、刮鬍刀、筆桿的軟膠握把
2. **功能性**：直接模塑密封墊、O-ring、防水圈，取代人工組裝密封件
3. **永久性圖案/色彩**：以不同顏色樹脂成型，不會磨損脫落（對比印刷/噴塗）
4. **模內組裝**：不同射次射出的部件在模內即完成組合（甚至做出可動組件）

### 1.3 多射模具的根本工程挑戰

無論哪種變形，多射模具的核心難題只有一個——**「如何為第二次射出騰出空間」**。塑膠射入的空間由鋼材包圍，第二射的材料要有地方去，就必須「讓鋼材移動」。由此衍生三個子挑戰：

1. **空間隔離**：如何在同一副模具內為不同材料形成獨立模穴空間？
2. **動態轉換**：如何在射出之間移動/旋轉模具結構，改變模穴形態？
3. **精密時序與密封**：多個射出單元的動作與模具運動需毫秒級同步，結合面要完美密封防溢料

依「騰出空間」的方式，可分為三大流派（PlasticsToday 分類）：

| 流派                     | 機制                     | 射出方式 |
| ------------------------ | ------------------------ | -------- |
| **共用模芯**             | 旋轉盤/轉盤旋轉模芯側    | **同步** |
| **模芯+模穴鋼材更換**    | 模內索引板或機器人移轉   | 同步     |
| **模芯伸縮**             | 模芯迴轉/滑塊後退讓位    | **依序** |

## 二、五大轉移機構詳解

### 2.1 旋轉盤式— 業界最主流

#### 工作原理

- 模具佈局：**動模側（模芯）有一套完全相同的模芯；定模側（模穴）有兩組不同的模穴鋼材**——一組給第一射（基材），一組給第二射（覆材）
- 旋轉機構可內建於**機台動模板**（專用多射機，如 FCS FB-2C、KraussMaffei、Engel duo 系列），或內建於**模具**（油壓缸或齒條驅動，適合不常做多射的成型廠改裝）
- 循環步驟：
  1. 模具閉合，第一射與第二射**同時射出**（第一射射新基材，第二射射在上一輪的基材上）
  2. 開模，成品留在動模側模芯上
  3. **動模側旋轉 180°**，第一射成品對位到第二射模穴
  4. 閉合、射出、冷卻、頂出成品——同時第一射站又射出新基材，進入下一循環

#### 穴數邏輯

| 每模成品數 | 動模側模芯        | 定模側模穴                          |
| ---------- | ----------------- | ----------------------------------- |
| 1 件       | 2 個（完全相同）  | 2 個（1 個第一射 + 1 個第二射）     |
| 2 件       | 4 個（完全相同）  | 4 個（2 個第一射 + 2 個第二射）     |
| N 件       | 2N 個（完全相同） | 2N 個（N 個第一射 + N 個第二射）     |

> 注意：旋轉盤式的**模具總穴數是成品穴數的兩倍**，但每循環產出 N 件成品。需**兩組獨立頂出板**——只頂出已完成雙射的成品，未完成的留在模芯上進入第二射站。

#### 三色/四色擴充

旋轉 120° 即三色（3 站），90° 即四色（4 站）。FCS 的 FB-3C 三色機即採此原理。

#### 優缺點

- ✅ **循環時間最快**——雙射同步進行，總週期由冷卻最長的材料決定
- ✅ 製程穩定、重現性佳，機台剛性支撐大件旋轉
- ❌ 需專用多射機或改裝旋轉盤，資本投資高
- ❌ 模穴偏置（第一射站與第二射站各在模板一側），**無法充分利用機台噸位**
- ❌ 幾何彈性受限：第二射只能作用於與模芯接觸的那一面

### 2.2 模內索引板式

#### 工作原理

- 旋轉機構做在**模具內部**：兩組模芯安裝在一塊可旋轉 180° 的中央索引板上
- 驅動方式：伺服馬達、油壓缸或齒條齒輪
- 循環步驟：第一射完成 → 開模 → 索引板**頂起第一射成品**（成品不被頂出，而是被脫料板托住）→ 旋轉 180° → 將第一射成品**精確放置到第二射模芯鋼材上** → 閉模、同步雙射

#### 與旋轉盤式的本質差異

索引板可以做**模芯與模穴兩側的第二射特徵**——旋轉盤式做不到（旋轉盤式第二射只發生在模穴側）。成品設計需有讓脫料板「抓住、搬運、精確放置」的特徵；第一射可**嵌入**第二射，材料能注入、繞過、貫穿第一射。

#### 優缺點

- ✅ 設計彈性最大——可做非對稱、複雜幾何；可加入冷卻站等中間工站
- ✅ 某些情況可裝在**標準單射機**上運轉，省下專用機投資
- ❌ 模具機構複雜、造價高、維護難
- ❌ 內部旋轉機構使循環時間略長於旋轉盤式
- ❌ **對位精度要求極高：0.01–0.02 mm**——任何誤差都會造成溢料或模具損傷

### 2.3 模芯迴轉／後退式— 不旋轉的方案

#### 工作原理

- 完全**不需要旋轉機構**，成品從頭到尾不離開原模穴
- 循環步驟：第一射成型並固化 → 模具**微開或保持閉合** → 油壓/機構驅動抽出特定模芯段或滑塊 → 騰出的空間形成第二射模穴 → 閉模射出第二射
- 如同一支伸縮原子筆：第一射成型筆身，抽回筆尖後騰出內部空間，第二射填入

#### 優缺點

- ✅ 模具最簡單、最便宜；一副模具每循環都是成品（穴數不需加倍）
- ✅ 可在**帶抽芯功能的標準機**上運轉，門檻最低
- ❌ **射出為依序進行**——循環時間 = 兩射之和 + 第一射額外冷卻，可達同步式的 **兩倍以上**
- ❌ 幾何限制嚴格：第二射只能在第一射**相鄰**位置，**無法包覆對側**（無法封裝/包覆）
- 適合：密封圈直接成型在外殼上、硬質握把上局部軟膠層、墊圈/環帶類

### 2.4 滑塊平移式

與 core-back 同族：第一射後，滑塊沿分模面平移，將成品或模穴段從第一射位置移到第二射位置（水平移動而非旋轉）。適合長條形或旋轉不便的製品，機構設計介於旋轉盤與 core-back 之間。

### 2.5 機器手臂移轉式— 偽 2K

- 用一副模具、兩套流道系統，**機器手臂或人工**把第一射成品搬運到第二射位置
- 最極端的形式就是**兩副模具在兩台機台間移轉**——此時嚴格來說已是 overmolding 而非 2K
- ✅ 設備投資最低（標準機即可）、彈性最大
- ❌ 循環時間長、人力成本、搬運刮傷與對位精度風險
- 適合原型、小批量、或第一射後需長時間冷卻/處理的產品

### 2.6 立方模具— 多射的天花板

#### 工作原理

- 中央有一個**可 90° 步進旋轉的四面部立方體**（垂直軸旋轉），形成多個分模面的疊模結構
- 四個工站（A/B/C/D）可同時進行不同製程：
  - 站 1：第一射
  - 站 2：第二射（或冷卻）
  - 站 3：第三射／模內組裝／貼標
  - 站 4：頂出成品
- 每次旋轉 90°，四站同步作業

#### 技術優勢（FOBOHA 數據）

- **鎖模力可減半**（疊模原理：投影面積重疊，力互相抵銷）
- **穴數可加倍**、循環時間顯著縮短
- 單機可完成極複雜的多色多工序製品（如多色瓶蓋、化妝品蓋）

#### 模內組裝——立方模具的獨門應用

- 站 1 同時射出兩種不同零件 → 站 2 進行高精度組裝 → 站 3 包覆第三種材料 → 站 4 頂出**已組裝完成**的組件
- 可做出**模內活動組件**（in-mold assembly, IMA）——例如射出後即可旋轉/滑動的組件

#### 進階變形：Double Cube

- 兩個**同步反向旋轉**的立方體置於模具兩半之間，等於一套設備內含兩副獨立模具，在三個分模面上以 90° 步進同時作業
- 可同時進行：多色射出、貼標、模內組裝、成品頂出

#### 優缺點

- ✅ 產出效率最高、單機完成複雜工序、鎖模力減半
- ❌ **造價最昂貴、機構最複雜**；模具高度高，需大開模行程機台
- 主要供應商：**FOBOHA**（德國，翹楚）、**Roth Greve**、部分日系模具廠

## 三、共射出／三明治成型

### 3.1 與多射的本質差異

共射出**不轉移工件、不分開模穴**——兩種材料從**同一個澆口**依序或同步注入，靠「噴泉流動」自然形成 **皮層—芯層—皮層** 的三明治結構。

### 3.2 兩種注入模式

| 模式     | 機制                                                             | 順序               |
| -------- | ---------------------------------------------------------------- | ------------------ |
| **依序** | 兩射出單元經切換閥先後注入同一澆口                                 | 皮→芯 或 皮→芯→皮  |
| **同步** | 兩單元接**同軸噴嘴**同時注入；高黏度皮材沿模壁流動包覆，低黏度芯材在中間流動，噴泉流效應維持皮芯分明 | 皮芯同時成型       |

### 3.3 典型材料組合

| 皮層       | 芯層            | 目的                       |
| ---------- | --------------- | -------------------------- |
| PP / 新料  | 回收 PP         | 節料、循環經濟（外觀全新料）|
| PC         | ABS             | 外觀+成本平衡              |
| PET / HDPE | 回收料          | 包裝容器                   |
| PP         | 發泡 PP         | 減重、隔熱                 |
| PET        | **EVOH**        | **阻氧層**（食品/藥品包裝）|
| PA         | 玻纖強化 PA     | 性能/成本分區              |

### 3.4 設計要點與缺陷

- **芯層體積佔比 20–80%** 可調（實務多在 40–70%）
- 壁厚建議 1–3 mm，不超過 5 mm；公差 ±0.1 mm
- 典型缺陷：
  - **芯層突破**：芯材衝破皮層露出表面——需降低射壓、增加皮層射量
  - 皮層厚度不均 → 表面痕、熔接痕
  - 皮芯收縮率差 → 翹曲
  - 多穴流動不平衡 → 各穴皮芯比例不一
- 優勢：**無法精確定位兩種材料的分佈區域，只能控制層厚比例**——要「看得見的雙色」請用多射，要「看不見的分層」用共射

## 四、機台配置與選型策略

### 4.1 第二射出單元的安裝型式

多射機本質 = 標準機 + 第二（第三）射出單元 + 控制整合。第二射出單元配置：

| 型式                 | 說明                                             | 適用                                     |
| -------------------- | ------------------------------------------------ | ---------------------------------------- |
| **平行式**           | 兩射出單元並排水平，各自對應定模一側模穴         | 大型件、汽車件（Engel e-twin、KM MX）    |
| **垂直式（L 型）**   | 第二單元垂直裝在定模板上方/側面                   | 中小型件，節省佔地                       |
| **機台搭載可攜式**   | 第二單元裝在移動/固定模板上，可拆移到其他機台     | 小射量第二射（手持件類）                 |
| **落地水平式**       | 獨立落地水平單元 + 支撐架                         | 大射量第二射（>1 lb），體積如一台 80 噸機 |

- 垂直大單元可高出機台 **5 英尺以上**；落地式連支架相當於掛一台 80 噸機在主機旁
- 第二單元需自有電源、人機介面、控制器，經 **SPI 機器人或 Euromap 67 介面**與主機整合
- 驅動選擇：伺服（節能、精密）vs 油壓（體積小、易維修）——目前旋轉盤銷售以電動為絕對主流，可攜射出單元油壓仍佔一定比例

### 4.2 專用機 vs 改裝機的決策（MGS 準則）

| 情境                                         | 建議                     |
| -------------------------------------------- | ------------------------ |
| 年運轉 **> 5,000 小時** 且產品壽命 **≥ 3 年** | **專用雙色機**           |
| 單穴小批量、首次嘗試多射                     | 標準機 + 旋轉盤/可攜單元改裝 |

專用機風險：交期長（常比模具更久）、產品停產後設備閒置（white elephant）、單點故障完全停線。
改裝機優勢：第二單元故障可替換或移機，靈活調度。

### 4.3 機台其他配合條件

- 旋轉盤厚度會**吃掉開模行程**：需確認機台有足夠容模空間（rotary platen + 開模 + 取件機器人）
- 立方模具模具高度大：需大開模距機台
- 疊模/立方可**減半鎖模力需求**（投影面積疊加抵銷）
- 需多組獨立料筒溫控、多點壓力監控的控制器

## 五、模具設計關鍵課題

依資深模具專欄作家 Randy Kerkstra（PlasticsToday）整理的實務要點：

### 5.1 對位與定位

- 旋轉盤式：模具必須**精確對中**旋轉盤中心——否則旋轉 180° 後導柱、導套、封閉面全部錯位損毀。模具與模板都需設計定位器

### 5.2 封閉——防溢料的生命線

- 第二射模穴鋼材必須**壓入**第一射成品，阻止第二射材料溢到不該去的地方
- **Crush 量：0.003–0.005 in（0.08–0.13 mm）** 的凸起封閉鋼材
- 第一射**厚壁處收縮大**，需局部增加 crush 補償（加鋼或減料）

### 5.3 支撐——第一射抗壓

- 第二射施加**數千磅**的模穴壓力在第一射塑膠上（不只壓鋼材！）
- 第一射在第二射模穴內必須有足夠鋼材支撐，否則被壓潰變形 → 溢料 + 廢品
- Core-back 式同樣需要：肋條或倒勾固定第一射、抵抗第二射壓力；驅動油壓缸要夠粗壯，否則製程窗口極窄

### 5.4 噸位偏置

- 旋轉盤式模穴分居模板兩側（偏心），**機台噸位無法全額利用**——選機時噸位要留餘裕

### 5.5 製程窗口管理

- 兩射互相牽連：常見錯誤是用第一射參數去補第二射的問題（或反之）
- Crush 不足、支撐不足、鋼材撓曲、油壓缸過小——都會迫使調機者「用參數繞路」，埋下品質與報廢風險

### 5.6 維護重點（旋轉類模具）

- 旋轉機構軸承/驅動磨耗、**旋轉接頭洩漏**、精密對位與鎖定機構保養——任何鬆動都會閃模損毀

## 六、材料接合技術

### 6.1 三種接合機制

| 機制             | 原理                                                 | 強度與特性                             |
| ---------------- | ---------------------------------------------------- | -------------------------------------- |
| **化學鍵合**     | 兩材料分子級鍵結，界面形成「膠合樹脂皮層」            | **最強**，近乎單一材料的結合力         |
| **熔接**         | 熱與壓力使兩表面熔融變形而黏著                       | 弱於化學鍵合，可靠度較低               |
| **機械互鎖**     | 靠成品幾何設計（孔、倒勾、溝槽）把兩材料鎖在一起     | 不依賴材料相容性，強度取決於幾何設計   |

實務上 melt bond 通常再輔以機械互鎖提升壽命。

### 6.2 「不接合」反而是特色——刻意設計的弱接合

- **易撕封**：弱熔接暫時黏住，使用者可撕開防拆封條露出孔口
- **模內組裝**：兩種**互不相黏**的材料 + 互鎖幾何 → 射出後即為**可旋轉/滑動**的活動組件（如模內活動鉸鏈、滾輪）

### 6.3 TPE 多組分接合相容性（Kraiburg TPE 應用工程部）

- **TPE + PP**：最成熟標準組合
- 依配方不同，TPE 可接合：**PA6 / PA66 / PA12（含玻纪）、PC、ABS、PC/ABS**
- 特殊配方可接合：**POM、PBT、PARA、EPDM**
- **玻璃纖維強化尼龍是出了名的難接合基材**；某些色母/添加劑會顯著影響接合強度
- → **樹脂供應商必須在產品設計初期就介入**，材料組合的接合履歷多為經驗累積，試錯成本極高

### 6.4 接合強度評估

- 標準：**DIN ISO 813-2**（90° 剝離測試）
- 評估重點：不只看數值，還要看**破斷模式**——黏著破壞（界面分離，不佳）vs 內聚破壞（材料本體撕裂，代表接合成功）

### 6.5 常見硬軟組合

| 基材（第一射）   | 覆材（第二射） | 應用                 |
| ---------------- | -------------- | -------------------- |
| PP               | TPE/TPU        | 牙刷、工具握把、密封 |
| ABS / PC/ABS     | TPU            | 3C 外殼軟觸、鍵帽    |
| PA66（含 GF）    | 耐候 TPE       | 汽車密封、連接器     |
| PC / PMMA（透明）| PC（不同色）   | 車燈雙色燈殼/透鏡    |
| 熱塑基材         | **LSR**        | 醫療密封、防水圈     |

## 七、應用案例

### 7.1 汽車車燈——多射技術的旗艦戰場

- **FCS（富強鑫）技術文件**：轉盤式雙色機（FB-2C／FB-R 系列）廣為車燈業採用，應對雙色前燈/尾燈的射出問題（溢料、色差、結合線）
- **Porsche Macan 尾燈系統**：Hella 開發的 LED 光帶尾燈，以多射技術對齊光條，實現無縫多色燈殼
- 典型結構：
  - 透明 PC 透鏡 + PC 色殼雙射
  - 硬質 PC 燈殼 + LSR/軟膠密封三射
  - 紅/琥珀/透明三色尾燈透鏡（三色機 + 旋轉 120°）

### 7.2 消費品

| 產品       | 多射方案                                       |
| ---------- | ---------------------------------------------- |
| 牙刷       | PP 手柄 + TPE 軟握把（旋轉盤式海量生產）       |
| 手工具握把 | 硬質基材 + 軟膠包覆                            |
| 刮鬍刀     | 多色多材質一體成型                             |
| 鍵帽       | ABS 底 + 透光 PC 字（永久性圖案，不會磨掉）    |
| 化妝品蓋   | 立方模具多色瓶蓋（FOBOHA 主戰場）              |

### 7.3 密封與醫療

- **模塑密封墊**：外殼直接射出 TPE/LSR 密封圈，取代人工插入的硫化橡膠圈——Kraiburg 指出此為 2K 最強成長動能（效率+可靠度+可回收）
- **LSR + 熱塑複合**：醫療器械握把、診斷設備外殼、吸入器組件；需專用 LSR 計量混合單元與冷流道

### 7.4 循環經濟

- 共射出皮芯結構：回收料做芯、新料做皮——外觀與食品安全由新料皮層把關
- 多射做單材化密封：以同系材料（如 PP+TPE）設計，回收時不需拆解

## 八、製程比較總表與選擇流程

### 8.1 六大製程比較

| 製程       | 轉移方式     | 射出方式 | 循環時間 | 模具成本 | 機台需求             | 幾何能力           | 典型應用                 |
| ---------- | ------------ | -------- | -------- | -------- | -------------------- | ------------------ | ------------------------ |
| **旋轉盤** | 動模旋轉 180° | 同步     | ★最快    | 中       | 專用機/改裝旋轉盤    | 第二射限單面        | 牙刷、車燈、握把、雙色件 |
| **索引板** | 模內旋轉板   | 同步     | 快       | 高       | 可用標準機           | 最強（芯穴兩側）    | 複雜/非對稱多色件        |
| **模芯迴轉** | 模芯/滑塊後退 | **依序** | ★最慢（2 倍+） | ★最低 | 標準機 + 抽芯        | 限相鄰位置，不能包覆 | 密封圈、墊圈、環帶       |
| **滑塊平移** | 滑塊水平移動 | 依序     | 中       | 中       | 標準機 + 抽芯        | 長條件、局部包覆   | 條狀密封、按鍵           |
| **機器人移轉** | 手臂/人工搬運 | 依序     | 慢       | 低       | 標準機               | 任意（含跨機台）   | 原型、小批量、嵌件類     |
| **立方模具** | 四面體 90° 旋轉 | 同步   | ★★極快   | ★★最高   | 大行程專用機         | ★★最強（含模內組裝）| 多色瓶蓋、複雜組件、IMA  |

（★ = 該欄位中的極端值；★★ = 全表之最）

### 8.2 選擇流程建議

```
第二射是否需包覆第一射對側？ ──否──→ Core-back / 滑塊（標準機即可）
        │是
第二射是否需作用於模芯側？ ──否──→ 旋轉盤式（主流、最快）
        │是
是否需要 >2 種材料/模內組裝/極高產量？
        │是──→ 立方模具
        │否──→ 索引板式
（若只需分層不需定位 → 共射出）
（若批量極小 → 機器人移轉 / 兩副模具 overmolding）
```
