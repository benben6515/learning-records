## 一、基本原理與工作流程

### 1.1 射出成型概述

射出成型（Injection Molding）是製造塑膠製品最重要的加工方法之一，其原理是將熱塑性（thermoplastic）或熱固性（thermosetting）塑膠材料加熱至熔融狀態，再以高壓射入模具的模穴（cavity）中，經冷卻固化後得到具有特定形狀與尺寸的製品。

整個過程中，**射出裝置（Injection Unit）** 與 **鎖模裝置（Clamping Unit）** 是機台兩大核心子系統，前者負責塑化與射出，後者負責固定模具並承受射出壓力。

### 1.2 射出成型完整週期（Injection Molding Cycle）

射出成型的一個完整週期由以下階段依序組成：

#### 階段一：關模（Mold Closing）

鎖模機構將移動模板（moving platen）推向固定模板（fixed platen），使模具閉合。鎖模力（clamping force / tonnage）必須大於射出時模穴內的壓力，否則模具會被撐開而產生溢料（flash / 溢邊）。曲肘式（toggle）機構在此階段提供機械增力效果。

#### 階段二：射出／充填（Injection / Filling）

螺桿（screw）在射出油缸或伺服電機的推動下向前推進，將料筒（barrel）前端已蓄積的熔融塑膠以高壓高速經噴嘴（nozzle）射入模具模穴。

- **射出壓力**：通常 10,000–30,000 PSI（69–207 MPa），工程塑膠可能需要 35,000+ PSI（241+ MPa）
- **射出速度**：取決於零件幾何形狀與材料流動特性
- **轉換點（Transfer Position）**：當模穴填充至 **95–98%** 時，由速度控制切換為壓力控制，這稱為 **科學成型（Scientific Molding / Decoupled Molding）**

#### 階段三：保壓／補縮（Holding / Packing）

射出完成後，持續施加保壓力（packing pressure），約為射出壓力的 **50–80%**，用以補償塑膠在冷卻過程中的收縮。保壓階段持續直到澆口（gate）冷卻凝固為止。此時料筒前端會保留約 **10% 的射出量** 作為緩衝墊（cushion），防止螺桿前端直接撞擊料筒底部。

#### 階段四：冷卻／塑化（Cooling / Plasticizing）

模具內製品持續冷卻，同時螺桿開始旋轉：

- 螺桿旋轉將來自料斗（hopper）的新塑料顆粒向前輸送
- 在料筒加熱帶與剪切摩擦熱的共同作用下，塑料逐漸熔融
- 熔融塑膠被推至螺桿前端，推動螺桿後退，蓄積下一個射出量
- 模具冷卻水路中循環冷卻水（或油）加速製品固化

#### 階段五：開模與頂出（Mold Opening & Ejection）

- 模具打開
- 頂出機構（ejector system）將成品從模穴中推出
- 機器手臂（robot arm）從側面或上方取出成品
- 清理模具（若有需要），進入下一個循環

### 1.3 循環時間

| 階段           | 典型時間佔比         | 說明                                     |
| -------------- | -------------------- | ---------------------------------------- |
| 射出／充填     | 極短（< 1 秒）       | 實際充填時間往往不到 1 秒                |
| 保壓／補縮     | 1–10 秒              | 取決於澆口尺寸與材料凝固速度             |
| 冷卻           | 最大佔比（10–60 秒） | 與製品壁厚直接相關，是循環時間的瓶頸     |
| 開模／頂出     | 1–5 秒               | 取決於模具行程與頂出機構複雜度           |
| **總循環時間** | **2 秒 – 2 分鐘**    | 薄壁小件可 < 5 秒；厚壁大件可超過 2 分鐘 |

現代全電動與油電混合機台相比傳統油壓機台，循環速度可提升約 **20%**。

### 1.4 成型過程中不可避免的表面痕跡

射出成型製品會在以下位置留下永久的加工痕跡：

- **分模線（Parting Line）**：模具兩半的交界處
- **澆口痕（Gate Mark）**：澆口與製品連接處
- **流道痕（Sprue / Runner Mark）**：主流道與分流道切除後的痕跡
- **頂針痕（Ejector Pin Mark）**：頂針與製品接觸處

## 二、主要構造與核心部件

### 2.1 射出裝置（Injection Unit）

射出裝置負責將塑膠原料塑化、計量，並以高壓高速射入模具。

#### 2.1.1 料斗（Hopper）

位於料筒後端上方，儲存塑膠顆粒（pellets / granules），並以重力或強制加料裝置將原料送入料筒。料斗也提供原料的預熱與乾燥功能，因為許多塑膠（如 PC、PET、Nylon）對濕氣極為敏感，含水量過高會導致材料降解與成品脆化。

#### 2.1.2 料筒（Barrel / Cylinder）

- 容納螺桿的圓柱形筒體，外部纏繞加熱帶（heater bands）
- 料筒容量通常為最大射出量的倍數：
  - **柱塞式**：4–8 倍
  - **螺桿式**：2–3 倍
- 分為多個溫控區域（通常 3–6 區），每區配備熱電偶（thermocouple）進行 PID 閉迴路溫度控制
- 料筒直徑範圍：**15 mm – 200 mm+**

#### 2.1.3 螺桿（Reciprocating Screw）

螺桿是射出成型機最核心的部件，兼具三大功能：**輸送、熔融塑化、射出**。

**螺桿三區設計：**

| 區域                                        | 功能                                   | 特徵                                               |
| ------------------------------------------- | -------------------------------------- | -------------------------------------------------- |
| **進料區（Feed Zone）**                     | 接收並向前輸送塑膠顆粒                 | 螺紋深度深且均一，溝槽容積最大                     |
| **壓縮區（Compression / Transition Zone）** | 壓縮並熔融塑膠                         | 螺紋深度逐漸變淺，塑膠在此受到剪切與外部加熱而熔化 |
| **計量區（Metering Zone）**                 | 完成熔融均質化，定量的熔融塑膠送往噴嘴 | 螺紋深度最淺且固定，確保穩定輸出                   |

**螺桿設計關鍵參數：**

- **長徑比（L:D Ratio）**：
  - 一般用途：**20:1 至 24:1**（最常見）
  - 短螺桿（熱敏感材料）：**15:1 至 18:1**
  - 長螺桿（工程塑膠、需更好混鍊）：**25:1 至 30:1**
  - 兩段式排氣螺桿：**36:1**（增加排氣區）

- **壓縮比（Compression Ratio）**：
  - 定義：進料區螺紋深度與計量區螺紋深度之比
  - 低壓縮比（**2.0:1**）：熱敏感材料（PVC、PC）
  - 中壓縮比（**2.5:1**）：一般用途（PP、PE、PS、ABS）
  - 高壓縮比（**3.0:1**）：結晶性材料（Nylon、POM）

- **螺桿材料**：通常採用氮化鋼或鍍層合金鋼，表面硬度需達 HRC 60+，以抵抗塑膠的磨耗

#### 2.1.4 噴嘴（Nozzle）

連接料筒前端與模具的主流道襯套（sprue bushing），將熔融塑膠射入模具。噴嘴尖端的孔徑（nozzle orifice）影響射出壓力損失與流速，需根據製品需求選擇。噴嘴本身配有獨立加熱器以維持熔膠溫度。

噴嘴類型包括：

- **開放式噴嘴（Open Nozzle）**：最常見，結構簡單
- **針閥式噴嘴（Needle Shut-off Nozzle）**：可防止熔膠垂滴（drool），適用於低黏度材料

#### 2.1.5 止逆閥（Check Valve / Non-return Valve）

安裝在螺桿前端，射出時封閉防止熔膠向後回流，確保射出壓力有效傳遞到模具。

### 2.2 鎖模裝置（Clamping Unit）

鎖模裝置負責固定模具、提供足夠的鎖模力，並驅動開模／頂出動作。

#### 2.2.1 模板（Platens）

通常採用 **三板設計**：

- **固定模板（Fixed Platen / A板）**：固定不動，安裝模具的定模（母模）
- **移動模板（Moving Platen / B板）**：沿哥林柱滑動，安裝模具的動模（公模）
- **尾板（Rear Platen）**：連接鎖模油缸或曲肘機構

典型模板尺寸（以 Cincinnati Milacron 機台為例）：

| 機型      | 鎖模力     | 模板尺寸                           |
| --------- | ---------- | ---------------------------------- |
| Babyplast | 6.6 tons   | 2.95" × 2.95" (75 × 75 mm)         |
| Powerline | 330 tons   | 40.55" × 40.55" (1,030 × 1,030 mm) |
| Maxima    | 4,400 tons | 122.0" × 106.3" (3,099 × 2,700 mm) |

#### 2.2.2 哥林柱（Tie Bars）

連接固定模板與尾板的粗大圓柱（通常 4 根），負責：

- 導引移動模板的滑動方向
- 承受鎖模力時的拉伸應力
- 決定機台可容納的最大模具尺寸

部分現代機台採用**無哥林柱設計（Tie-barless）**，提供更大的模具安裝空間與更佳的靈活性。

#### 2.2.3 鎖模機構類型

| 類型                           | 機構                 | 特點                                             |
| ------------------------------ | -------------------- | ------------------------------------------------ |
| **曲肘式（Toggle）**           | 連桿機構產生機械增力 | 鎖模速度快、鎖模力穩定、成本較低；**目前最主流** |
| **直壓式（Direct Hydraulic）** | 液壓缸直接施加壓力   | 鎖模力可精確控制、行程可調；速度較慢、能耗較高   |
| **直鎖式（Electric Toggle）**  | 伺服電機驅動曲肘     | 全電動機台標配，精密控制                         |

曲肘式鎖模原理：透過多級連桿的幾何增力作用，在小油缸行程下即可產生巨大的鎖模力。當連桿接近水平（死點位置）時，鎖模力達到最大值。

### 2.3 模具系統（Mold / Die）

#### 2.3.1 模具基本結構

```
噴嘴 → 主流道（Sprue）→ 分流道（Runner）→ 澆口（Gate）→ 模穴（Cavity）
```

| 組件                 | 功能                                          |
| -------------------- | --------------------------------------------- |
| **主流道（Sprue）**  | 連接噴嘴與分流道的錐形流道，與噴嘴同軸        |
| **分流道（Runner）** | 主流道到澆口的過渡流道，將熔膠分配到各模穴    |
| **澆口（Gate）**     | 分流道與模穴的連接口，控制射出速度與壓力傳遞  |
| **模穴（Cavity）**   | 賦予製品最終形狀的空腔                        |
| **排氣孔（Vent）**   | 設在模穴末端，排出空氣防止困氣燒焦            |
| **導向元件**         | 導柱與導柱孔，確保模具精確對位                |
| **頂出機構**         | 頂針（ejector pin）、頂板，將成品從模穴中脫出 |
| **抽芯機構**         | 用於製品側面有孔或倒勾時的側向抽芯            |
| **冷卻水路**         | 在模穴周圍鑽孔通入冷卻水，加速製品固化        |

#### 2.3.2 模具材質

| 材質                              | 硬度      | 壽命               | 適用場景                       |
| --------------------------------- | --------- | ------------------ | ------------------------------ |
| **淬硬工具鋼（Hardened Steel）**  | HRC 50–60 | 1,000,000+ 件      | 大量量產                       |
| **預硬鋼（Pre-hardened Steel）**  | HRC 38–45 | 100,000–500,000 件 | 中大量量產                     |
| **鋁合金（Aluminium 7075/2024）** | —         | 10,000–100,000+ 件 | 原型件、小批量                 |
| **鈹銅合金（Beryllium-Copper）**  | —         | —                  | 需要高散熱效率的區域（嵌入件） |

#### 2.3.3 多穴模具

模穴數可從 1 穴到 **128+ 穴**（如瓶蓋製品），多穴模具可大幅提高產能，但也增加模具複雜度與成本。

### 2.4 加熱與溫控系統

- **料筒加熱帶**：3–6 區獨立 PID 溫控，溫度範圍 **150°C – 320°C**
- **噴嘴加熱器**：維持噴嘴溫度與料筒前端一致
- **模具溫控**：經由冷卻水路控制模溫，部分特殊材料（如工程塑膠）需模具加熱
- **模具溫度機（Mold Temperature Controller / Thermocontroller）**：精確控制模溫，影響成品外觀、尺寸穩定性和生產效率

### 2.5 操控系統（Control System）

- 監控所有參數：射出壓力、射出速度、料筒溫度、模具溫度、螺桿位置、鎖模力
- 現代機台採用**閉迴路伺服控制**
- **科學成型（Scientific Molding / Decoupled Molding）**（由 RJG Inc. 提出）：
  - 充填階段：以**速度控制**填充至 95–98% 模穴容積
  - 保壓階段：切換為**壓力控制**進行補縮
  - 尺寸精度可控制在 **千分之一英吋** 以內
- 機器手臂整合：自動取出成品、放置嵌件

### 2.6 冷卻系統

冷卻水分配管裝有三送三回接頭（管徑通常 3/8"），各有水閥可獨立控制水量。一般需每年保養一次。冷卻效率直接影響循環時間。

## 三、分類與機型

### 3.1 按驅動系統分類

#### 3.1.1 油壓式射出成型機（Hydraulic）

- **歷史**：最早的射出機類型，直到 1983 年日本才推出第一台全電動機
- **鎖模力範圍**：**< 5 tons 至 > 9,000 tons**（全噸位覆蓋）
- **優點**：
  - 高鎖模力輸出能力
  - 機台堅固耐用
  - 適合大型製品
  - 初始成本較低
- **缺點**：
  - 精度較低
  - 能源消耗較高（油壓泵持續運轉）
  - 噪音較大
  - 液壓油洩漏的環境問題
  - 需定期更換液壓油與保養

#### 3.1.2 全電動式射出成型機（All-Electric / Electric Machine Technology）

- **歷史**：1983 年由 Milacron / FANUC / Nissei 推出第一台全電動機（Roboshot）
- **鎖模力範圍**：通常 **5 – 550 tons**（中小噸位為主；大型全電動機已有但較少見）
- **核心設計**：使用 **3 個獨立伺服電機**：
  1. 驅動螺桿旋轉（塑化）
  2. 驅動螺桿軸向移動（射出）
  3. 驅動鎖模機構（曲肘開合模）
- **優點**：
  - **能源效率高**：每公斤塑膠生產節省約 **0.73 kWh**
  - 精度高（伺服閉迴路控制）
  - 運轉安靜
  - 循環速度快（比油壓機快約 **20%**）
  - 無液壓油，環保清潔
  - 維護成本低
- **缺點**：
  - 初始機台成本高（比油壓機貴 **30–60%**）
  - 大噸位能力受限
- **主要市場**：日本（市場佔有率最高）、精密成型應用

#### 3.1.3 油電混合式射出成型機（Hybrid / Servo-Hydraulic）

- **設計理念**：結合油壓與電動的優點
- **常見架構**：
  - 伺服驅動射出裝置 + 液壓鎖模裝置
  - 或相反
- **特性**：
  - 能源效率接近全電動機（伺服泵只在需要時運轉）
  - 噸位範圍比純電動更寬：**< 5 tons 至 > 3,000 tons**
  - 成本介於油壓與全電動之間
  - 兼具高精度與大噸位能力
- **市場趨勢**：全球市場快速成長中

#### 3.1.4 三種機型綜合比較

| 參數     | 油壓式                 | 全電動式             | 油電混合式         |
| -------- | ---------------------- | -------------------- | ------------------ |
| 能源效率 | 基準（100%）           | 節省 **50–70%**      | 接近全電動（略低） |
| 精度     | 較低                   | **最高**（伺服控制） | 高                 |
| 噪音     | 較大                   | **安靜**             | 中等               |
| 循環速度 | 較慢                   | **最快**（+20%）     | 中快               |
| 噸位範圍 | **< 5 – > 9,000 tons** | 5 – 550 tons（主流） | < 5 – > 3,000 tons |
| 初始成本 | **最低**               | 最高（+30–60%）      | 中等               |
| 維護成本 | 較高（油品更換）       | **較低**             | 中等               |
| 環保性   | 油洩漏、熱能散失       | **最佳**             | 改善中             |
| 主要市場 | 全球（日本除外）       | 日本、精密應用       | 全球成長中         |
| 鎖模機構 | 液壓／曲肘             | 伺服曲肘             | 伺服液壓           |

### 3.2 按射出裝置類型分類

| 類型                              | 說明                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------- |
| **螺桿式（Reciprocating Screw）** | **現代主流**。螺桿旋轉塑化，前進射出。塑化效果好，1946 年起普及                  |
| **柱塞式（Ram / Plunger）**       | 最早的形式，以柱塞直接推動塑膠通過加熱管。塑化能力差，壓力損失大，目前已極少使用 |
| **螺旋式（Progressive Screw）**   | 螺桿僅旋轉不前進，另配柱塞負責射出。塑化與射出分離                               |
| **微量射出機（Micro Injection）** | 專為微射出成型設計，成品重量 < 1 克或具 μm 級微結構                              |

### 3.3 按機台方向分類

| 類型                   | 說明                                                                     |
| ---------------------- | ------------------------------------------------------------------------ |
| **臥式（Horizontal）** | **最常見**，模具水平開合，適用於大多數應用                               |
| **立式（Vertical）**   | 模具垂直開合，利用重力輔助嵌件插入成型（insert molding），適用於特殊應用 |

### 3.4 按功能分類

| 類型                                      | 說明                                                               |
| ----------------------------------------- | ------------------------------------------------------------------ |
| **標準單色機**                            | 單一材料單次射出                                                   |
| **雙色／多色機（Two-shot / Multi-shot）** | 配備兩個或多個射出裝置，可在同一循環中射出不同材料或顏色           |
| **嵌件成型機（Insert Molding）**          | 先將金屬或其他嵌件放入模具，再射出塑膠將其包覆                     |
| **氣輔射出成型機（Gas-Assisted）**        | 射出塑膠後注入氮氣，形成中空結構，減少製品重量與翹曲               |
| **液體矽膠射出機（LSR Machine）**         | 專為液體矽膠（Liquid Silicone Rubber）設計，需特殊的射出與溫控系統 |

## 四、關鍵技術參數與規格

### 4.1 鎖模力（Clamping Force / Tonnage）

鎖模力是射出成型機最核心的規格參數，表示機台能提供的最大模具夾緊力。

**計算公式：**

```
鎖模力 = 製品投影面積 × 射出壓力 × 安全係數
```

**快速估算法：**

| 方法                      | 數值                                           |
| ------------------------- | ---------------------------------------------- |
| 經驗法則                  | **4–5 tons / in²**（一般塑膠）                 |
| 精確範圍                  | **1.8 – 7.2 tons / cm²**（取決於材料流動特性） |
| 高流動性材料（如 PP、PE） | 較低值                                         |
| 高黏度／工程塑膠          | 較高值                                         |
| 薄壁製品                  | 需更高射出壓力 → 更大鎖模力                    |

**常見鎖模力範圍與應用：**

| 鎖模力範圍          | 應用場景                                         |
| ------------------- | ------------------------------------------------ |
| < 50 tons           | 微型零件、醫療微件、電子連接器                   |
| 50 – 200 tons       | 一般消費品、家用電器零件、玩具                   |
| 200 – 500 tons      | 汽車零件、電子外殼、工業零件                     |
| 500 – 1,000 tons    | 大型零件、汽車保險桿、垃圾桶                     |
| 1,000 – 4,000+ tons | 汽車內飾板、大型托盤、建材                       |
| > 4,000 tons        | 超大型製品、特殊工業應用（最大可達 9,000+ tons） |

### 4.2 射出量（Shot Size / Shot Capacity）

射出量定義為每次射出可注入模具的最大熔膠量（通常以重量或體積表示）。

| 規格       | 範圍                                      |
| ---------- | ----------------------------------------- |
| 重量單位   | 通常以 **克（g）** 或 **盎司（oz）** 表示 |
| 最小射出量 | **~ 4 g**（0.13 oz，如 Babyplast 機台）   |
| 一般範圍   | **14 g – 25 kg**（0.5 oz – 55 lb）        |
| 最大射出量 | **> 30 kg**（1,054+ oz，如超大型機台）    |

**注意**：實際射出量應為最大射出量的 **20–80%**。過低則塑化效果不佳；過高則緩衝墊不足，壓力傳遞不穩定。

### 4.3 射出壓力（Injection Pressure）

| 參數           | 數值                                       |
| -------------- | ------------------------------------------ |
| 一般熱塑性塑膠 | **10,000 – 30,000 PSI**（69 – 207 MPa）    |
| 工程塑膠       | **20,000 – 35,000+ PSI**（138 – 241+ MPa） |
| 保壓壓力       | 射出壓力的 **50–80%**                      |
| 模穴壓力       | 通常低於射出壓力（因管路壓力損失）         |

### 4.4 射出速率（Injection Speed）

- 薄壁製品需高射出速率防止提前冷卻
- 厚壁製品需較低射出速率避免噴流痕（jetting）
- 多段射出速度控制是現代機台的標準功能

### 4.5 循環時間（Cycle Time）

見第 1.3 節的詳細分析。核心瓶頸是**冷卻時間**，與製品壁厚的平方成正比。

### 4.6 塑化能力（Plasticizing Capacity）

單位時間內螺桿能熔融的塑膠量（kg/h 或 oz/s），影響可達到的最短循環時間。

### 4.7 空循環時間（Dry Cycle Time）

機台在不射出材料情況下完成一次開合模動作的時間，反映機台的機械速度。

### 4.8 模具安裝尺寸

| 參數                          | 說明                                       |
| ----------------------------- | ------------------------------------------ |
| 拉桿間距（Tie Bar Spacing）   | 決定模具的最大寬度與高度                   |
| 模板尺寸（Platen Size）       | 通常大於拉桿間距                           |
| 模厚範圍（Mold Height Range） | 機台可容納的模具厚度範圍                   |
| 鎖模行程（Clamp Stroke）      | 模板最大移動距離，影響可生產的最大製品深度 |
| 最大開模距（Max Daylight）    | 模具完全打開時兩板間的距離                 |
| 頂出行程（Ejector Stroke）    | 頂針的最大移動距離                         |

**典型規格對比（Cincinnati Milacron 機台）：**

| 參數     | Babyplast (6.6t) | Powerline (330t) | Maxima (4400t)   |
| -------- | ---------------- | ---------------- | ---------------- |
| 模板尺寸 | 75 × 75 mm       | 1,030 × 1,030 mm | 3,099 × 2,700 mm |
| 鎖模行程 | 110 mm           | 599 mm           | 3,398 mm         |
| 最小模厚 | 30 mm            | 201 mm           | 800 mm           |
| 射出量   | 4–14 g           | 227–964 g        | 11.7–29.9 kg     |

### 4.9 模具溫度控制範圍

| 參數       | 範圍                           |
| ---------- | ------------------------------ |
| 冷卻水溫控 | 5°C – 90°C（冷水機）           |
| 熱油溫控   | 最高 200°C（工程塑膠需高模溫） |
| 模溫均勻性 | ± 1–2°C（精密成型要求）        |

### 4.10 材料加工溫度參考

| 材料                | 比重 (SG)  | 熔點／加工溫度        | 備註               |
| ------------------- | ---------- | --------------------- | ------------------ |
| Epoxy（環氧樹脂）   | 1.12–1.24  | 120°C (248°F)         | 熱固性             |
| Phenolic（酚醛）    | 1.34–1.95  | 120°C (248°F)         | 熱固性             |
| Polyethylene（PE）  | 0.91–0.965 | 110–117°C (230–243°F) | 最常見的熱塑性塑膠 |
| Polystyrene（PS）   | 1.04–1.07  | 170°C (338°F)         | 通用級塑膠         |
| Nylon（PA）         | 1.01–1.15  | 194–265°C (381–509°F) | 工程塑膠，吸濕性強 |
| Polypropylene（PP） | 0.90–0.91  | 160–220°C             | 通用級，低比重     |

## 七、近年技術趨勢與發展

### 7.1 工業 4.0 / 智慧製造（Industry 4.0 / Smart Manufacturing）

射出成型產業正在全面進入數位化轉型，主要技術包括：

#### (1) IoT 感測與數據採集

- 機台內建溫度、壓力、位置、速度感測器，每秒數百筆數據
- 模具內建 **模內感測器**（In-mold Sensors）： cavity pressure、mold temperature、flow front detection
- 資料通訊協議：**OPC-UA**（統一架構）、**Euromap 23 / Euromap 82**（歐洲機械標準）
- MQTT 協議用於雲端數據傳輸

#### (2) 數位孿生（Digital Twin）

- 在虛擬環境中建立機台 + 模具 + 製程的完整數位模型
- 模擬軟體：**Moldex3D**（台灣科盛科技）、**Moldflow**（Autodesk）、**Sigmasoft**
- 用途：澆口優化、冷卻分析、翹曲預測、排程模擬
- 實際效益：縮短試模時間 **30%–50%**，降低模具修改成本

#### (3) MES 整合（Manufacturing Execution System）

- 機台直連 MES 系統，即時追蹤：生產數量、良率、OEE、能耗
- 自動產生 SPC（統計製程管制）報告
- 完整的生產追溯（Traceability）：原料批號 → 成型參數 → 品檢結果

#### (4) OEE 監控與預測性維護

- **OEE**（Overall Equipment Effectiveness）目標：>85%
- 透過 AI 分析震動、溫度、電流數據，預測螺桿磨損、油封老化、伺服馬達故障
- 計劃性維護替代反應性維護，減少非計畫停機 **30%–50%**

| 海天國際     | 海天智造 + **iHSMobile**             |

### 7.2 AI 智慧成型（AI-Powered Molding）

#### AI 成型優化

- **自適應控制**（Adaptive Control）：系統根據模內感測器回饋自動調整射出速度、保壓壓力、保壓時間
- 典型應用：補償環境溫度變化、原料批次差異、模具溫度漂移
- KraussMaffei 的 **APIC**、Engel 的 **iQ weight control** 是代表性技術

#### AI 品檢

- **AOI**（Automated Optical Inspection）：機器視覺自動偵測缺點
- AI 深度學習模型：識別短射（Short shot）、毛刺（Flash）、縮水（Sink mark）、熔接痕（Weld line）、氣泡（Bubble）
- 檢測速度：每件 <0.5 秒，準確率 >99.5%

#### AI 參數自動調優

- 機器學習模型根據歷史數據自動建議最佳參數組合
- 減少試模（Trial run）次數，縮短調機時間 **40%–60%**

### 7.3 微型射出成型（Micro Injection Molding）

#### 定義與應用

- **微型射出**定義：零件重量 <1 g，或特徵尺寸 <0.5 mm
- 應用領域：醫療微器件（微型導管尖、微齒輪）、光學微鏡片、電子微型連接器、MEMS 封裝

#### 技術要求

| 參數     | 微型射出要求               | 一般射出     |
| -------- | -------------------------- | ------------ |
| 射出量   | 0.01–5 g                   | 10–10,000 g  |
| 射出速度 | 500–1,000 mm/s             | 50–300 mm/s  |
| 射出精度 | ±0.01 mm                   | ±0.05–0.1 mm |
| 溫度控制 | ±0.5°C                     | ±2–5°C       |
| 模具溫控 | 精密熱媒油（±1°C）或電加熱 | 一般冷水機   |

#### 代表機台

- **BABYPLAST**（義大利）：鎖模力 5–15 噸，射出量 0.01–15 g——全球唯一專門做微型機的品牌
- **Arburg ALLROUNDER**（德國）：30–35 噸微型機配置
- **Engel e-mac 50**：50 噸級全電動機，適合精密小微件
- **JSW J-ELII 30**：30 噸全電動，光學/醫療微器件

### 7.4 多物料射出成型（Multi-Material / Multi-Component Molding）

> 📌 **深度研究**：本節為概覽。轉移機構詳解（旋轉盤／索引板／core-back／立方模具）、共射出、機台選型、材料接合技術，詳見專文 **[《多射／多組分射出成型深度研究報告》](./multi-shot-injection-molding.md)**

#### 主要技術類型

| 技術             | 英文名                  | 說明                                         | 典型應用                              |
| ---------------- | ----------------------- | -------------------------------------------- | ------------------------------------- |
| **雙色成型**     | Two-shot / Bi-injection | 兩種材料在同一模具內先後射出                 | 車燈透鏡、雙色按鍵、電器外殼          |
| **包覆成型**     | Overmolding             | 先射出基材（硬膠），再在上方射出覆層（軟膠） | 手機外殼（硬膠+軟膠）、工具握把、牙刷 |

| **液態矽膠成型** | LSR Molding             | 先射出塑膠基材，再射出 LSR 密封              | 醫療器材密封、嬰兒奶嘴、手機防水      |

#### 機台配置

- **旋轉式**（Rotary）：模具旋轉 180°（雙色）或 120°（三色）
- **平移式**（Translation）：模具水平移動
- **芯迴轉式**（Core Back）：模芯旋轉
- **專用機品牌**：富強鑫 FB-2C/FB-3C、KraussMaffei MX 系列、Engel e-twin、Arburg ALLROUNDER K

### 7.5 全電動與複合機（Electric & Hybrid Machines）

#### 驅動方式比較

| 驅動方式                        | 能耗                   | 精度     | 維護             | 速度       | 價格 |
| ------------------------------- | ---------------------- | -------- | ---------------- | ---------- | ---- |
| **全油壓**（All-Hydraulic）     | 高（100% 基準）        | 中       | 高（油路複雜）   | 高         | 最低 |
| **全電動**（All-Electric）      | **低（50%–70% 節能）** | **最高** | **低（無油路）** | 高（射出） | 最高 |
| **油電複合**（Hybrid）          | 中（約 70%–85%）       | 高       | 中               | 最高       | 中高 |
| **伺服油壓**（Servo-Hydraulic） | 中低（約 60%–80%）     | 高       | 中               | 高         | 中   |

#### 全電動機的技術優勢

1. **精度最高**：AC 伺服馬達直接驅動，位置控制精度 ±0.01 mm
2. **節能**：只有在動作時才消耗電力，待機耗電接近零
3. **乾淨**：無液壓油洩漏風險，**適合無塵室和醫療應用**
4. **低噪音**：運轉噪音比油壓機低 **10–15 dB**
5. **重現性**：批次間品質一致性最佳

#### 複合機的定位

- 大型機（>1,000 噸）仍以油壓/複合為主，因大型伺服馬達成本過高
- 中小型機（<600 噸）全電動趨勢明確
- 複合機提供「大鎖模力 + 電動射出精度」的最佳平衡

### 7.6 環保與永續（Sustainability / Eco-friendly）

#### 回收材料射出成型

- **rPET**（回收 PET）：來自寶特瓶回收，用於食品容器、瓶胚、纖維
- **rPP / rPE**：來自塑膠袋、容器回收
- **挑戰**：回收材料分子量降低，導致機械強度下降 10%–30%；需要調整成型參數
- **解決方案**：使用 **鏈延長劑**（Chain Extender）提升分子量；比例控制（Virgin:Regrind = 80:20 至 50:50）

#### 生物可分解塑膠

- **PLA**（聚乳酸）：最常見，來自玉米澱粉，適合食品容器、餐具
- **PHA**（聚羥基烷酸酯）：微生物發酵生產，海洋可降解
- **PBAT**：柔性材料，常與 PLA 共混提升韌性
- **挑戰**：加工溫度窗口窄、熱穩定性差、結晶速度慢
- **Negri Bossi Canbio 系列**：業界少數專門為生質塑膠開發的機種

#### 能源效率提升

- 全電動機較傳統油壓機節能 **50%–70%**
- Engel 研究數據：升級全電動機可增加產量 **20%** 同時降低能耗
- 模溫機節能、冷水塔水循環利用
- 回收水系統：過濾後冷水塔水可循環使用

#### 循環經濟設計

- **單材設計**（Monomaterial Design）：整個產品使用同一種塑膠，回收時不需分離材料
- **自動回收系統**：將澆口、流道廢料自動粉碎回收，回填比例可達 **20%–50%**
- 領先廠商可將填埋廢料降至 **<1%**
- 設計考量：減少材料種類混用、標示塑膠材質代碼、避免金屬嵌件（阻礙回收）

### 7.7 薄壁高速成型（Thin-Wall High-Speed Molding）

- **定義**：壁厚 ≤0.5 mm（極端案例可達 0.3 mm）的高速射出成型
- **應用**：飲料杯、便當盒、食品容器、IC 載帶
- **技術要求**：
  - 射出速度 **300–1,000 mm/s**（超高壓高速）
  - 填充時間 <0.3 秒
  - 循環時間 2–4 秒
  - 高速鎖模（閉模時間 <0.5 秒）
- **代表機台**：Engel speed 系列、海天高速機、博創 B-SPEED 系列

### 7.8 液態矽膠射出成型（LSR Injection Molding）

- **LSR**（Liquid Silicone Rubber）：雙組分 A/B 液態矽膠，混合後在模具中固化
- **特性**：耐高溫（-50°C 至 +250°C）、生物相容性佳、柔軟、透明可著色
- **應用**：嬰兒奶嘴、醫療密封件、手機防水圈、汽車墊圈、觸控面板密封、廚具
- **機台配置**：需專用 **LSR 計量混合單元**（Metering Unit）；冷料道（Cold Runner）避免材料在流道中固化
- **代表機台**：Engel（LSR 專用方案）、KraussMaffei SR 系列、Arburg（LSR+塑膠雙組分）

### 7.9 增材製造 + 射出成型混合（Hybrid AM + IM）

- **3D 列印模具**（3D Printed Mold）：用金屬 3D 列印（SLM/DMLS）製造冷卻水路複雜的模具，結合 **共形冷卻**（Conformal Cooling）技術
- **Arburg freeformer**：業界唯一直接用標準塑膠粒進行 3D 列印的技術（APF：Arburg Plastic Freeforming）
- **快速試模**：以軟鋼或鋁合金 3D 列印模具進行小批量試產，驗證設計後再製造正式模具
- **混合生產**：少量多樣訂單用 3D 列印生產，大量標準件用射出成型

## 八、模具設計基礎知識

### 8.1 模具基本結構

一副標準射出模具（Injection Mold）主要由以下結構組成：

```
┌─────────────────────────────────────────────────┐
│  定模 / 母模（Fixed Half / A-Side）              │
│  ┌───────────────────────────────────────────┐  │
│  │  定位環（Locating Ring）                    │  │
│  │  澆口套（Sprue Bushing）                    │  │
│  │  流道系統（Runner System）                  │  │
│  │  冷卻水路（Cooling Channels）               │  │
│  │  模穴（Cavity）— 成型產品的外形              │  │
│  └───────────────────────────────────────────┘  │
├────────────────── 分模面（Parting Line）─────────┤
│  ┌───────────────────────────────────────────┐  │
│  │  模芯（Core）— 成型產品的內部結構            │  │
│  │  頂出機構（Ejection System）               │  │
│  │  冷卻水路（Cooling Channels）               │  │
│  │  導柱 / 導套（Guide Pins / Bushings）      │  │
│  └───────────────────────────────────────────┘  │
│  動模 / 公模（Moving Half / B-Side）             │
└─────────────────────────────────────────────────┘
```

**基本術語對照**：

| 英文                 | 中文      | 說明                       |
| -------------------- | --------- | -------------------------- |
| Cavity               | 模穴      | 成型產品外觀形狀的部分     |
| Core                 | 模芯      | 成型產品內部結構的部分     |
| Parting Line (P/L)   | 分模面    | 模具開合的分界線           |
| Fixed Half (A-Side)  | 定模/母模 | 安裝在射出機固定側的模具   |
| Moving Half (B-Side) | 動模/公模 | 安裝在射出機移動側的模具   |
| Ejector Plate        | 頂出板    | 驅動頂出銷推出成品的板     |
| Guide Pin            | 導柱      | 確保模具開合精度的導向零件 |

### 8.2 澆口設計（Gate Design）

澆口是熔融塑膠從流道進入模穴的最後通道。澆口的設計直接影響填充品質、外觀和外觀缺陷。

#### 澆口類型與選擇

| 澆口類型       | 英文                    | 特徵                           | 適用場景             | 去除方式         |
| -------------- | ----------------------- | ------------------------------ | -------------------- | ---------------- |
| **直澆口**     | Direct / Sprue Gate     | 直接從主流道進入，壓力損失最小 | 大型件、單穴模具     | 手工/機械剪切    |
| **邊澆口**     | Edge Gate               | 在分模面上從流道邊緣進入       | 一般零件             | 自動剪切         |
| **薄膜澆口**   | Film Gate               | 寬而薄的澆口，均勻充填         | 平板件、薄壁件       | 自動剪切         |
| **扇形澆口**   | Fan Gate                | 澆口由窄變寬呈扇形             | 大面積平板、避免流痕 | 自動剪切         |
| **潛伏式澆口** | Submarine / Tunnel Gate | 從分模面以下潛入模穴           | 自動脫澆口，不需剪切 | 自動脫落         |
| **點澆口**     | Pin-point Gate          | 極小的圓形澆口（Ø0.3–2mm）     | 多穴模具、外觀要求高 | 自動斷開         |
| **針閥澆口**   | Valve Gate              | 機械銷控制開閉，精確控制填充   | 多穴精密件、外觀件   | 機械關閉（無痕） |
| **熱澆口**     | Thermal Gate            | 保持高溫，冷卻時凍結封閉       | 熱流道系統           | 凍結後自動斷開   |

#### 澆口設計原則

1. **位置選擇**：設在產品最厚處，確保充填順序由厚到薄
2. **尺寸設計**：澆口厚度約為零件壁厚的 **40%–60%**，寬度為厚度的 **2–3 倍**
3. **數量決定**：大型零件或多點充填需要多個澆口
4. **外觀考量**：外觀面不可留澆口痕跡，需用潛伏式或針閥式澆口
5. **流動平衡**：多穴模具的每個澆口必須流量平衡（Flow Balance），確保每穴同時充滿

### 8.3 流道系統（Runner System）

流道是熔融塑膠從噴嘴（Nozzle）到澆口之間的通道。

#### 冷流道（Cold Runner）

```
噴嘴 → 主流道（Sprue） → 分流道（Runner） → 澆口（Gate） → 模穴
```

- **主流道**（Sprue）：從噴嘴到分流道的錐形通道，退模斜度 1°–3°
- **分流道**（Runner）：連接主流道與各澆口的通道
  - 常用截面形狀：**圓形**（最佳流動）、**梯形**（常用）、**U 形**
  - 分流道直徑：通常 3–10 mm，取決於零件大小和材料流動性
- **冷料井**（Cold Slug Well）：在主流道盡端的擴大凹槽，捕捉冷料前端

**冷流道優缺點**：

- ✅ 模具成本低、結構簡單
- ✅ 換色/換料容易
- ❌ 每次循環產生流道廢料（約佔射出量的 **20%–40%**）
- ❌ 需要分離、粉碎、回收流道廢料

#### 熱流道（Hot Runner）

- **原理**：流道系統內建加熱器，維持熔膠在成型溫度不固化
- **核心組件**：**分流板**（Manifold）+ **熱澆嘴**（Hot Nozzle）
- **優點**：
  - 消除流道廢料，**節省材料 10%–30%**
  - 縮短循環時間 **5%–20%**（不需等待流道冷卻）
  - 適合全自動化生產（不需人工去澆口）
  - 適合多穴模具（平衡性更好）
- **缺點**：模具成本高（熱流道系統約 **1,500–5,000 USD/穴**）、維護複雜、換色需大量清料

#### 熱流道類型

| 類型           | 英文             | 說明                                       |
| -------------- | ---------------- | ------------------------------------------ |
| **熱式澆口**   | Thermal Gate     | 澆口始終開放，靠熔膠凍結封閉               |
| **針閥式澆口** | Valve Gate       | 機械銷（氣動或伺服驅動）控制開閉，外觀最佳 |
| **外殼式**     | External Bushing | 經濟型混合方案                             |

**熱流道技術參數**：

- 分流板溫度：200–320°C（取決於樹脂種類）
- 溫度與料管溫差：±5–15°C
- 壽命：良好維護下可達 **>100 萬次循環**

**主要熱流道供應商**：Husky（加拿大）、Mold-Masters（加拿大/英國）、Yudo（韓國）、INCOE（美國）、Günther（德國）、Synventive（美國）、熱流道（台灣）

### 8.4 冷卻系統（Cooling System）

冷卻時間通常佔整個射出循環的 **50%–70%**，是決定生產效率的關鍵。

#### 傳統冷卻水路

- 材質：不鏽鋼或銅管
- 冷卻介質：冷水（20–30°C）或熱媒油（80–160°C）
- 管徑：通常 **Ø6–12 mm**
- 水路間距：管徑的 **2–3 倍**
- 冷卻水路距模穴表面：管徑的 **1–1.5 倍**
- 水流量：維持 **Reynolds number > 4,000**（紊流）以確保熱傳效率

#### 共形冷卻（Conformal Cooling）

- 利用 **金屬 3D 列印（SLM/DMLS）** 製造隨模穴表面形狀的冷卻水路
- 優勢：
  - 冷卻更均勻，減少翹曲（Warpage）**30%–50%**
  - 縮短循環時間 **20%–40%**
  - 傳統鑽孔無法到達的區域也能冷卻
- 缺點：成本高（約為傳統模具的 2–3 倍）、3D 列印後需後處理

#### 模溫控制設備

| 設備                  | 冷卻/加熱範圍                   | 用途                             |
| --------------------- | ------------------------------- | -------------------------------- |
| **冷水機**（Chiller） | 5–30°C                          | 一般 PP、PE、PS 成型             |
| **模溫機**（TCU）     | 30–200°C（水）/ 200–350°C（油） | PC、PA、POM 等高溫材料           |
| **高溫熱媒油機**      | 200–350°C                       | PEEK、LCP 等超高溫工程塑膠       |
| **急冷急熱**（RHCM）  | 室溫↔200°C 快速切換             | 消除熔接痕、改善外觀（汽車面板） |

#### 冷卻設計要點

1. 水路需均勻分佈在模穴與模芯兩側
2. 進水與出水溫差控制在 ±1–2°C
3. 厚肉區域需要更密集的冷卻
4. 避免死水區（水路太長或彎曲太多）
5. 使用 Baffles / Bubblers（擋板/起泡器）冷卻深孔型模芯

---

### 8.5 頂出機構（Ejection System）

頂出機構負責將冷卻固化後的成品從模芯上脫離。

#### 頂出機構類型

| 類型         | 英文                           | 結構與用途                                            |
| ------------ | ------------------------------ | ----------------------------------------------------- |
| **頂出銷**   | Ejector Pin                    | 最常用。圓柱形銷，穿過模芯頂出成品。標準尺寸 Ø1–25 mm |
| **頂出板**   | Ejector Plate / Stripper Plate | 整塊平板頂出，適合大型薄壁件、外殼件                  |
| **套筒頂出** | Ejector Sleeve                 | 套在型芯銷上的管狀頂出，適合環形零件（齒輪、管件）    |
| **脫料板**   | Stripper Plate                 | 與模穴面平行的板，整體推出成品，不留頂出痕            |
| **氣壓頂出** | Air Ejection                   | 壓縮空氣吹出，適合深杯形、薄壁件                      |
| **旋轉頂出** | Rotary / Unscrewing            | 螺紋脫模，內螺紋/外螺紋零件用。需齒輪/馬達驅動        |
| **斜銷**     | Lifter / Angle Pin             | 側面凹槽/孔的脫模，開模時斜銷帶動滑塊側向移動         |

#### 頂出設計原則

1. 頂出力需均勻分佈，避免成品變形
2. 頂出銷盡量設在成品肉厚較大處
3. 外觀面不可留頂出痕（A 面用脫料板或氣壓頂出）
4. 頂出行程需超過成品最大深度 **5–10 mm**
5. 頂出速度與壓力需可分段控制（低速啟動 → 正常速度）

### 8.6 模具與射出機的配合

#### 機台選型要點

| 模具參數     | 配合射出機參數                | 說明                                               |
| ------------ | ----------------------------- | -------------------------------------------------- |
| **投影面積** | 鎖模力（Clamping Force）      | 鎖模力 ≥ 投影面積 × 模穴壓力 × 安全係數（1.1–1.3） |
| **模穴容積** | 射出量（Shot Size）           | 射出量需為模穴容積的 **1.2–2.0 倍**（含流道）      |
| **模具厚度** | 模厚調整（Tie Bar Spacing）   | 模厚需在機台的 Min–Max 模厚範圍內                  |
| **拉桿間距** | 拉桿內徑（Tie Bar Clearance） | 模具長寬需小於拉桿內徑                             |
| **定位環**   | 定位孔（Locating Ring）       | 直徑需與機台噴嘴定位孔匹配                         |
| **頂出孔**   | 頂出桿孔（Ejector Hole）      | 頂出板需與機台頂出桿對齊                           |
| **模具重量** | 機台承重（Platen Load）       | 定模/動模重量不可超過模板最大承重                  |

#### 模穴壓力估算

- **一般塑膠**：模穴壓力 500–1,000 kg/cm²（50–100 MPa）
- **工程塑膠**：模穴壓力 1,000–1,500 kg/cm²（100–150 MPa）
- **薄壁/高速**：模穴壓力 1,500–2,500 kg/cm²（150–250 MPa）

**範例計算**：

> 100 × 100 mm 零件（投影面積 1,000 cm²），PP 材料（模穴壓力 600 kg/cm²）
> 所需鎖模力 = 1,000 × 600 × 1.2 = 720,000 kg = **720 噸**
> → 選擇 800–1,000 噸射出機

### 8.7 模具材質

| 材質                        | 用途               | 特性                          |
| --------------------------- | ------------------ | ----------------------------- |
| **P20**（預硬鋼）           | 一般生產模具       | HRC 28–36，易加工，不需熱處理 |

| **Aluminum 7075**           | 試模/少量生產      | 輕量、易加工、導熱好，壽命短  |
