# 韓文動詞基礎

## 一、動詞分類

韓文動詞字典形全部以 **-다** 結尾，去掉 -다 後得到**詞幹（어간）**。變化規則取決於詞幹最後一個母音。

| 類型 | 特徵 | 變化規則 |
|------|------|----------|
| **規則動詞** | 大多數動詞 | 詞幹母音決定 -아/어요 |
| **ㅂ 不規則** | 詞幹以 ㅂ 結尾 | ㅂ → 우/오（如：가볍다→가벼워요） |
| **ㄷ 不規則** | 詞幹以 ㄷ 結尾 | ㄷ → ㄹ（如：듣다→들어요） |
| **ㅅ 不規則** | 詞幹以 ㅅ 結尾 | ㅅ 消失（如：짓다→지어요） |
| **르 不規則** | 詞幹以 ㄹㄹ 結尾 | 르 → ㄹ러/ㄹ라（如：부르다→불러요） |
| **ㄹ 不規則** | 詞幹以 ㄹ 結尾 | ㄹ 在 ㄴ/ㅂ/ㅅ 前消失（如：알다→압니다） |
| **하다 動詞** | 以 하다 結尾 | 特殊變化：해요/했습니다 |

> ★ 韓文不規則動詞比日文多，但常用不規則只有 ㅂ、ㄷ、ㅅ、르 四種，先記這幾個就好

## 二、基本變化規則

### 詞幹提取

字典形 -다 = 詞幹

> 먹다 → 먹 / 가다 → 가 / 만들다 → 만들 / 하다 → 하

### -아/어요（親近體・現在式）

日常最常用的敬語形式：

| 詞幹母音 | 接法 | 例 |
|----------|------|----|
| ㅏ, ㅗ | -아요 | 가→가**아요**→가**와요** / 만나→만나**요** |
| 그 외 | -어요 | 먹→먹**어요** / 읽→읽**어요** |
| 하다 | 해요 | 하→**해요** |

**母音縮約（常見）：**

| 原型 | 縮約 | 說明 |
|------|------|------|
| 가아요 | 가요 | ㅏ+아 → ㅏ |
| 만나요 | 만나요 | ㅏ+아 → ㅏ（不縮） |
| 먹어요 | 먹어요 | ㅓ+어 → ㅓ |
| 쓰어요 | 써요 | ㅡ+어 → ㅓ |
| 배우어요 | 배워요 | ㅜ+어 → ㅜ |

### -ㅂ니다/습니다（格式體・正式敬語）

用於正式場合、新聞、演講：

| 詞幹母音 | 接法 | 例 |
|----------|------|----|
| ㅏ, ㅗ | -ㅂ니다 | 가→갑**니다** |
| 그 외 | -습니다 | 먹→먹**습니다** |
| 하다 | 합니다 | 하→**합니다** |

### -았/었어요（過去式）

詞幹 + 았/었 + 어요：

| 詞幹母音 | 接法 | 例 |
|----------|------|----|
| ㅏ, ㅗ | -았어요 | 갔→갔**어요** / 만났→만났**어요** |
| 그 외 | -었어요 | 먹었→먹었**어요** |
| 하다 | 했어요 | 했→**했어요** |

### -ㄹ 거예요（未來式）

詞幹 + ㄹ 거예요：

> 가다 → 갈 거예요 / 먹다 → 먹을 거예요 / 하다 → 할 거예요

### 否定

| 方式 | 結構 | 例 |
|------|------|----|
| 앞（短否定） | 안 + 動詞 | 안 먹어요（不吃） |
| -지 않다（長否定） | 動詞 + 지 않다 | 먹지 않아요（不吃） |
|못 + 動詞 | 못 + 動詞 | 못 먹어요（不能吃） |

---

> ★ 判斷 -아/어요 的快速方法：看詞幹最後一個母音
> ㅏ or ㅗ → **-아요**（如：가다→가요, 오다→오요）
> 其他 → **-어요**（如：먹다→먹어요, 읽다→읽어요）
> 하다 → **해요**（特殊，要記）
>
> ★ 不規則動詞遇到元音時才變：遇到 ㄴ/ㅂ/ㅅ 前不變（如：앉다→앉습니다）
