# 日文動詞基礎

## 一、動詞分類

日文動詞分為三類，決定了所有變化規則：

| 類別 | 別名 | 特徵 | ます形變化 |
|------|------|------|-----------|
| **五段動詞** | Group 1 / U-verbs | 結尾在 u 段（く、す、つ、む、ぶ、ぬ、ぐ、る、う） | 結尾→い段 + ます |
| **一段動詞** | Group 2 / Ru-verbs | 結尾是 **iru / eru** | る→ます |
| **不規則動詞** | Group 3 | 只有 する、来る（くる） | する→します、くる→きます |

> ★ 注意：有些動詞結尾看似 iru/eru，但其實是**五段動詞**（例如：帰る、入る、知る、走る、切る），後方以 ★ 標記

## 二、基本變化規則

### ます形（丁寧形・肯定現在）

| 類別 | 規則 | 例 |
|------|------|----|
| 五段 | 最後一個字改い段 + ます | 書く → 書**きます** |
| 一段 | 去掉る + ます | 食べる → 食べ**ます** |
| 不規則 | する→します、来る→来ます(きます) | 勉強する → 勉強**します** |

**五段結尾對照表：**

| 結尾 | ます形 | 例（辞書形→ます形） |
|------|--------|---------------------|
| く | きます | 書く→書きます |
| ぐ | ぎます | 泳ぐ→泳ぎます |
| す | します | 話す→話します |
| つ | ちます | 待つ→待ちます |
| ぬ | にます | 死ぬ→死にます |
| ぶ | びます | 遊ぶ→遊びます |
| む | みます | 読む→読みます |
| る | ります | 作る→作ります |
| う | います | 買う→買います |

### ました（丁寧形・過去肯定）

ます → ました

> 例：食べます → 食べ**ました** / 行きます → 行き**ました**

### ません（丁寧形・現在否定）

ます → ません

> 例：食べます → 食べ**ません** / 行きます → 行き**ません**

### ませんでした（丁寧形・過去否定）

ます → ませんでした

> 例：食べます → 食べ**ませんでした** / 行きます → 行き**ませんでした**

### て形（連接・請求・進行形）

| 類別 | 規則 | 例 |
|------|------|----|
| 一段 | る→て | 食べる→食べて |
| 不規則 | する→して、来る→来て(きて) | 勉強する→勉強して |
| 五段 | 見下表 | 書く→書いて |
| 五段（例外） | 行く→行って | 行く→行**って** |

**五段て形結尾對照表：**

| 結尾 | て形 | 例 |
|------|------|-----|
| く | いて | 書く→書**いて** |
| ぐ | いで | 泳ぐ→泳**いで** |
| す | して | 話す→話**して** |
| つ | って | 待つ→待**って** |
| ぬ | んで | 死ぬ→死**んで** |
| ぶ | んで | 遊ぶ→遊**んで** |
| む | んで | 読む→読**んで** |
| る | って | 作る→作**って** |
| う | って | 買う→買**って** |

### ない形（否定普通形）

| 類別 | 規則 | 例 |
|------|------|-----|
| 一段 | る→ない | 食べる→食べ**ない** |
| 不規則 | する→しない、来る→来ない(こない) | 勉強する→勉強**しない** |
| 五段 | 最後改あ段 + ない（う→わない） | 書く→書**かない** |
| 五段（例外） | ある→ない（特殊） | ある→**ない** |

**五段ない形結尾對照表：**

| 結尾 | ない形 | 例 |
|------|--------|-----|
| く | かない | 書く→書**かない** |
| ぐ | がない | 泳ぐ→泳**がない** |
| す | さない | 話す→話**さない** |
| つ | たない | 待つ→待**たない** |
| ぬ | なない | 死ぬ→死**なない** |
| ぶ | ばない | 遊ぶ→遊**ばない** |
| む | まない | 読む→読**まない** |
| る | らない | 作る→作**らない** |
| う | わない | 買う→買**わない** |

## 四、常用助詞搭配（動詞片語）

### を（動作對象）

| 片語 | 中文 |
|------|------|
| ご飯を食べる | 吃飯 |
| 水を飲む | 喝水 |
| 本を読む | 讀書 |
| 映画を見る | 看電影 |
| 音楽を聞く | 聽音樂 |
| 手紙を書く | 寫信 |
| 服を着る | 穿衣服 |
| 料理を作る | 做菜 |
| 部屋を掃除する | 打掃房間 |

### に（目的地・時間・對象）

| 片語 | 中文 |
|------|------|
| 学校に行く | 去學校 |
| 家に帰る | 回家 |
| 9時に起きる | 9點起床 |
| 友達に会う | 見朋友 |
| 先生に聞く | 問老師 |
| 駅に着く | 到車站 |
| 東京に出かける | 去東京（外出） |

### で（地點・方法・手段）

| 片語 | 中文 |
|------|------|
| レストランで食べる | 在餐廳吃 |
| 駅で待つ | 在車站等 |
| 電車で行く | 搭電車去 |
| 日本語で話す | 用日文說 |
| ペンで書く | 用筆寫 |
| バスで帰る | 搭公車回家 |

### へ（方向）

| 片語 | 中文 |
|------|------|
| 東京へ行く | 往東京去 |
| 家へ帰る | 回家（方向） |

### を（移動經過）

| 片語 | 中文 |
|------|------|
| 道を歩く | 在路上走 |
| 橋を渡る | 過橋 |
| 公園を散歩する | 在公園散步 |

| 片語 | 中文 |
