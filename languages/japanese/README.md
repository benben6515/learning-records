# Learning Japanese

`basic/` basic 50(46) Japanese symbols

## 日文五十音？韓文四十音？

### 日文五十音

日文的「五十音」是指**假名表**（五十音圖），包含：

- 平假名 46 個基本字（あいうえお...）
- 片假名 46 個基本字（アイウエオ...）

雖然叫「五十音」，但實際上現代日文只有 46 個基本音（古代確實接近 50 個，後來有些音消失了）。這 46 個音是固定的「音節」，每個假名代表一個完整的發音單位。

### 韓文「四十音」？

韓文其實**沒有「四十音」這個正式說法**。可能是因為：

- 韓文有 24 個基本字母（14 子音 + 10 母音）
- 加上雙子音（ㄲㄸㅃㅆㅉ）和複合母音（ㅐㅒㅔㅖ等），總共約 40 個字母
- 有些教材為了類比日文五十音，就說「韓文四十音」

但這個比喻**不太恰當**，因為：

### 本質不同

- **日文假名**：每個假名 = 一個固定音節（如「か」永遠讀 ka）
- **韓文字母**：是拼音文字，字母要**組合**才成音節（ㄱ+ㅏ = 가）

### 組合數量差異

韓文的 24 個基本字母可以組合出上千種音節，而日文五十音就是固定那些。

所以如果有人說「韓文四十音」，他們可能是指「韓文的基本字母」，但這個說法容易造成誤解。正確來說應該是「韓文字母（한글/hangul）」或「韓文子母音」。
