## 弱點軌跡

- **已過關**：動名詞/不定詞、despite/in spite of、whose、倒裝（結構）、need + V-ing、混合條件句、wish 過去願望、過去完成式、片語動詞（10-29 驗收 7/8）、助動詞後動詞形狀（11-04 一輪收掉）、did/has 時態選擇（11-04 收掉）
- **曾犯的系統性錯誤**：
  - would 誤放進 if/wish 子句（已修正，11-04 又踩一次，第 3 次）
  - 過去的願望用簡單過去式而非 had + p.p.（已修正；11-04 隔日又退化，見下）
  - 兩個過去動作該用過去完成式標記先發生者（已修正）
  - **隔日退化現象**：11-03 全過 → 11-04 綜合只剩 5/10（had+p.p.、need+V-ing、No sooner 時態全回退）。規則一天就生鏽 → 每日 5 分鐘掃 deck 比每週一次長複習有效
  - 助動詞後動詞形狀：did I ~~woke~~、have I ~~saw~~、~~were~~ the waiter（11-04 確立並收掉，deck §08）
  - 不規則三態自創形：leaved / saw 當 p.p. / losen / writen（11-04，deck §08 #3）
  - 假設 were 誤搬到真實過去：Not only ~~were~~ the waiter（11-04，判斷法：真的發生過嗎？）
- **待加強**：不規則三態熟練度（written 雙 t 這類拼字）；其餘全過關
- **待加強（11-05 驗收現回退）**：
