## 弱點軌跡

- **已過關**：動名詞/不定詞、despite/in spite of、whose、倒裝（結構）、need + V-ing、混合條件句、wish 過去願望、過去完成式、片語動詞（10-29 驗收 7/8）、助動詞後動詞形狀（11-04 一輪收掉）、did/has 時態選擇（11-04 收掉）
- **曾犯的系統性錯誤**：
  - would 誤放進 if/wish 子句（已修正，11-04 又踩一次，第 3 次）
  - 過去的願望用簡單過去式而非 had + p.p.（已修正；11-04 隔日又退化，見下）
  - 兩個過去動作該用過去完成式標記先發生者（已修正）
  - **隔日退化現象**：11-03 全過 → 11-04 綜合只剩 5/10（had+p.p.、need+V-ing、No sooner 時態全回退）。規則一天就生鏽 → 每日 5 分鐘掃 deck 比每週一次長複習有效
  - 助動詞後動詞形狀：did I ~~woke~~、have I ~~saw~~、~~were~~ the waiter（11-04 確立並收掉，deck §08）
  - 不規則三態自創形：leaved / saw 當 p.p. / losen / writen（11-04，deck §08 #3）
  - 假設 were 誤搬到真實過去：Not only ~~were~~ the waiter（11-04，判斷法：真的發生過嗎？）
- **待加強**：不規則三態熟練度（written 雙 t 這類拼字）；其餘全過關
- **待加強（11-05 驗收現回退）**：
  - **had + p.p. 家族回退**：wish 過去願望選了簡單過去式（bought）、No sooner 第四踩（did start）——與混合條件句同款「隔幾天就回退」模式，需要間隔重練而非一次補課
  - **rise/raise 二犯**（再選 raised，10-29、11-05）→ **11-12 首次過關**（has risen）
  - **Seldom 倒裝**（新點：cheatsheet 觸發詞清單上有但沒套用，選 had have）
- **待加強（11-12 驗收現回退）**：
  - **wish 過去遺憾第 3 次回退**：寫 didn't eat（deck §01 #19）——此家族最頑固，後果在現在、遺憾在過去 → had + p.p.
  - **No sooner 第 5 踩**：倒裝對、時態淺（did the meeting begin），口訣「No sooner 開頭手先寫 had」（deck §03 #8）
  - **Seldom 倒裝二犯**：這次倒裝沒觸發且時態錯（I saw），兩步口訣「先倒裝、再挑時態：無時間錨 → have + p.p.」（deck §04 #11）
  - **historic 二犯**（又選 historical，deck §07 #10）
- **11-12 過關**：rise/raise、混合條件句（would be 守住）、need to V、複數+冠詞、since + 現在完成式、call off——11-11 寫作新家族題目型全守住
