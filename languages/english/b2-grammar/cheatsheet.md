# B2 語法速覽（Cheatsheet）

## 條件句　[深入](topics/01-conditionals-wish.md#三種條件句)

| 型 | If 子句 | 主句 | 意思 |
|---|---|---|---|
| 第一（真實） | 現在式 | will + V | 未來可能發生 |
| 第二（與現在相反） | 過去式 | would + V | 現在不是這樣 |
| 第三（與過去相反） | had + p.p. | would have + p.p. | 過去沒發生 |

- 第二條件句 be 一律 **were**：If I were you
- 混合型：過去條件 + 現在結果 → If you **had worked** last year, you **would be** better off **now**

## wish　[深入](topics/01-conditionals-wish.md#wish-假設語氣)

| 願望時間 | 形式 |
|---|---|
| 現在 | wish + 過去式（I wish I knew） |
| 過去 | wish + **had + p.p.**（I wish I had known） |
| 未來／別人 | wish + would + 原形 |

- 判斷：事實現在還能改變嗎？不能 → had + p.p.
- would rather + 人 + 過去式 = 現在願望：I'd rather you **didn't say**

**鐵律：would 只住主句，永遠不進 if/wish 子句。**（would 是結果，不是條件）

## 動名詞 vs 不定詞　[深入](topics/02-gerund-infinitive.md)

- 只接 **V-ing**：suggest、deny、admit、avoid、enjoy、finish、mind、keep、consider、risk、practice
- 只接 **to-V**：want、decide、hope、promise、refuse、agree、afford、manage
- 雙義動詞（to-V = 還沒做，V-ing = 已做）：remember / stop / forget / try / regret（regret **to inform** 遺憾通知）
- **need + V-ing = 需被**：The report needs finishing = to be finished
- **to 是介系詞 → 接 V-ing**：look forward to / be used to / object to（to 後能接名詞 = 介系詞）
- used to + V 過去習慣 ≠ be used to + V-ing 習慣於

## 過去完成式　[深入](topics/03-past-perfect.md)

- 兩個過去動作，**先發生的加 had**：By the time we arrived, the train **had left**.
- 情態 + have + p.p.：**should have** 本應沒做 / **shouldn't have** 不該做了 / **could have** 本可以 / **must have** 一定是 / **might have** 可能是
- Hardly **had** S + p.p. ... **when** + 過去簡單式
- No sooner **had** S + p.p. ... **than** + 過去簡單式

## 倒裝　[深入](topics/04-inversion.md)

否定副詞放句首 → **助動詞提到主詞前**：Hardly **had she left** ...

- 觸發詞：Never / Rarely / Seldom / **Not only...but also** / **Hardly...when** / **No sooner...than** / Not until / Only then
- 只看句首第一個字（She hardly ever complains → 不倒裝）
- 助動詞帶時態：過去完成用 had，一般過去用 did

## 片語動詞　[深入](topics/05-phrasal-verbs.md)

介詞意象：**up** 完成·養大·出現｜**off** 取消·分離·下降｜**down** 減少·故障·拒絕｜**out** 爆發·發送·熄滅·用完

- **allow for** 事前預留 ≠ **account for** 事後解釋、佔比
- put up with 忍受｜put off 延期｜take after 像長輩｜bring up 養育
- fall off 下降｜cut down on 減少｜break down 拋錨｜break through 突破

## 雜項　[深入](topics/06-misc.md)

- **despite / in spite of + 名詞**；although + 子句（無 despite of）
- **whose + 名詞** = 所有格，人物皆可（考試首選，of which 結構固定）
- make 被動還原 to：He was made **to** tell
- consist of 不用被動：The committee **consists of** ...
