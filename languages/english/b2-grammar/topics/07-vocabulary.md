# B2 字彙：混淆對、不可數、搭配詞

> **一句話**：同根不同義背對比；不可數三不；及物動詞後面保持乾淨。
> 速覽 → [cheatsheet §字彙](../cheatsheet.md#字彙)｜自測 → [review-deck §07](../review-deck.md#07-字彙)

## 核心規則

### 混淆形容詞對

背對比＋一句例句，考試考「背沒背」。

| 對 | A | B |
|---|---|---|
| considerable / considerate | **considerable** 相當大的：a considerable **amount** of money | **considerate** 體貼的：It's considerate **of you** to call. |
| economic / economical | **economic** 經濟的（學科、體系）：economic growth | **economical** 省錢划算的：an economical **car** |
| sensible / sensitive | **sensible** 明智的：a sensible **decision** | **sensitive** 敏感的：be sensitive **to** criticism |
| historic / historical | **historic** 有歷史意義的：a historic **moment** | **historical** 有關歷史的：historical **novels** |
| effective / efficient | **effective** 有效的（達到效果）：effective **medicine** | **efficient** 效率高的（不浪費）：an efficient **system** |

### 不可數名詞

三不：**不加複數 s、不加 a/an、不配 many/few**。

| 錯 | 對 |
|---|---|
| informations / advices | information / advice |
| furnitures / equipments / luggages | furniture / equipment / luggage |
| damages（財物損害） | damage |
| knowledges / researches | knowledge / research |
| homeworks / progresses | homework / progress |

- 計量用 **a piece of**：a piece of advice、two pieces of information、a piece of furniture。
- **damages ≠ damage**：damages 是法律用語「賠償金」。He won $10,000 in **damages**.
- 三個「傷害」分工：

| 字 | 對象 | 例 |
|---|---|---|
| damage | 物 | The storm caused serious **damage** to the harbor. |
| injury | 人（意外受傷） | He suffered a back **injury**. |
| wound | 人（刀、槍外傷） | The soldier treated the **wound**. |

### 及物動詞不加介系詞

這族動詞**直接接受詞**，後面加 about/on/to 都是錯：

| 動詞 | ✓ | ✗ | 對照 |
|---|---|---|---|
| discuss | discuss **the plan** | discuss about the plan | talk **about** the plan |
| enter | enter **the room** | enter into the room | go **into** the room |
| marry | marry **her** | marry with her | get married **to** her |
| attend | attend **the meeting** | attend to the meeting | be present **at** the meeting |
| reach | reach **the station** | reach to the station | arrive **at** the station |
| answer | answer **the question** | answer to the question | reply **to** the question |

記法：這些字本身是「動詞＋介系詞」壓縮成一個字（discuss ≈ talk about），再加介系詞就重複。

### 及物 / 不及物動詞對

| 不及物（自己動） | 及物（對東西做） |
|---|---|
| **rise** rise-rose-**risen**：Prices rise. The sun rises. | **raise** raise-raised-raised：raise your hand / raise prices |
| **lie**（躺）lie-lay-**lain**：He lay on the floor. | **lay**（放下）lay-laid-laid：lay the baby on the bed. |

- **raise** 跟「舉、養」有關：raise a family 養家、raise a question 提出問題。
- lie 的過去式是 lay，最容易混 — 看意思不看拼法：躺 → lie 系，放 → lay 系。
- 數量題（the number of、prices、sales）主詞自己動 → 一律 rise / increase / fall / drop。

### 固定搭配：take 這一族

| 搭配 | 意思 |
|---|---|
| **take this opportunity** to-V | 藉此機會（正式書信常見） |
| take a chance | 冒險賭一把 |
| take place | 舉行、發生（不用被動） |
| take part in | 參與 |
| take care of | 照顧 |

四個「機會」分工：

| 字 | 用法 |
|---|---|
| opportunity | 好時機：**take / seize / miss** the opportunity **to-V** |
| chance | 帶運氣成分：have a chance **to-V**、take a chance（冒險） |
| possibility | 不接 take：There's a possibility **of** rain / **that** it will rain |
| occasion | 場合，用 on：**on this occasion**、on rare occasions |

## 判斷法與陷阱

- 形容詞對沒有可靠規則，**句型是線索**：It's + 形容詞 + **of 人** → 描述人品（considerate、kind、generous 這族）；形容數量、金額 → considerable。
- 不可數判斷：問「能不能數？」advice、information 沒辦法一份份數 → 不可數；計量用 a piece of。
- 及物不及物判斷：**動詞後面有沒有受詞？** 有 → raise / lay；自己漲、自己躺 → rise / lie。
- **attend 兩個形式都存在，意思分工**：attend + 活動 = 出席（無介系詞）；attend **to** = 照顧、處理。選項兩個都「對」時考意思。
- 題目空格前是 **take this** → 幾乎都是 opportunity；possibility 走 there is；occasion 走 on。
- damages 見到先問意思：財物損害 ✗（不可數 damage），賠償金 ✓。
