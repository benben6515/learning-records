# 條件句與 wish 假設語氣

> **一句話**：條件與願望都走假設語氣，**would 只住主句**。
> 速覽 → [cheatsheet §條件句](../cheatsheet.md#條件句)｜自測 → [review-deck §01](../review-deck.md#01-假設語氣與條件句)

## 核心規則

### 三種條件句

形式要**前後一致**，主句形態決定子句形式。

| 類型 | If 子句 | 主句 | 意思 |
|---|---|---|---|
| 第一（真實） | 現在式 | will + V | 未來可能發生 |
| 第二（與現在事實相反） | 過去式 | would + V | 現在不是這樣 |
| 第三（與過去事實相反） | had + p.p. | would have + p.p. | 過去沒發生 |

例句：

- If it **rains**, I **will stay** home.
- If I **had** time, I **would help** you.（現在沒時間）
- If I **had had** time, I **would have helped** you.（當時沒幫成）

第二條件句 be 動詞一律用 **were**：If I **were** you, ...

### 混合條件句（Mixed Conditional）

條件與結果時間不同：過去的條件 + 現在的結果（最常考）。

- If you **had worked** harder last year, you **would be** in a better position **now**.
- If she **had met** the deadline yesterday, she **would be** on holiday now.

### wish 假設語氣

wish 後面永遠用假設語氣（表示與事實相反）。看時間點選形式：

| 願望的時間 | 形式 | 例句 |
|---|---|---|
| 現在（與現實相反） | wish + 過去式 | I wish I **had** more money.（現在沒錢） |
| 過去（已發生，遺憾） | wish + **had + p.p.** | I wish I **had studied** harder. |
| 未來／別人行為（抱怨） | wish + would + 原形 | I wish it **would stop** raining. |

限制：wish + would 只用於**別人的行為**或外部事物（天氣），不能說 I wish I would...

### would rather

也走假設語氣：

- would rather + **人 + 過去式** = 現在/未來的願望：
  I'd rather you **didn't say** anything.（希望現在別說，不是指過去）
- would rather + have + p.p. = 過去的願望：I'd rather you **had told** me.
- 同一主詞省略直接接原形：I'd rather **not tell** anyone.

### 鐵律：would 只住在主句

**would 是結果，不是條件。** 永遠不出現在 if 子句或 wish 子句。

| | if/wish 子句 | 主句 |
|---|---|---|
| 對過去 | had + p.p. | would have + p.p. |
| 對現在 | 過去式 | would + V |

- ✗ If I would have known... → ✓ If I **had** known..., I **would have** come.
- ✗ I wish I would have studied... → ✓ I wish I **had** studied.

## 判斷法與陷阱

- **主句形態決定子句形式**：主句出現 would have + p.p. → 子句用 had + p.p.；主句 would + V → 子句用過去式。
- wish 判斷：問「願望的事實現在還存在嗎？」
  - 現在仍成立（我現在不知道）→ 過去式：I wish I **knew** how to fix this.
  - 只關於過去（當時沒做）→ had + p.p.：I wish I **had known** you were coming.
- 時間訊號字：**yesterday、last week、when I was younger、earlier** → had + p.p.
  沒有時間訊號就問「這件事現在還能改變嗎？」不能 → had + p.p.
- 混合型：if 子句看**動作發生的時間**，主句看**結果存在的時間**，各自選形式。
