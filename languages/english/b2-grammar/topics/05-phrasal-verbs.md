# 片語動詞（Phrasal Verbs）

> **一句話**：介詞意象決定意思大方向；整組背 + 一句例句最穩。
> 速覽 → [cheatsheet §片語動詞](../cheatsheet.md#片語動詞)｜自測 → [review-deck §05](../review-deck.md#05-片語動詞)

## 核心規則

### 介詞邏輯：記意象，不逐字翻譯

介詞 = 空間意象，決定片語意思的大方向。動詞相同時，**介詞決定意思**。

#### UP（往上）→ 完成、增加、養大、出現

| 意象 | 例子 |
|---|---|
| 做完、做徹底 | eat up 吃光 / clean up 清乾淨 / set up 設立 |
| 數量、程度往上 | speak up 大聲點 / grow up 長大 / bring up 養育（把小孩養大） |
| 出現、露面 | show up 現身 / turn up 出現 / come up 被提出 |

#### OFF（離開）→ 取消、分離、中斷、下降

| 意象 | 例子 |
|---|---|
| 事件被拿走 = 取消/延期 | put off 延期 / call off 取消 |
| 東西脫離本體 | take off 脫掉、起飛 / cut off 切斷（電力、通話）/ break off 中斷（關係） |
| 數量往下掉 | fall off 下降 / drop off 減少 |

#### DOWN（往下）→ 減少、故障、記下、拒絕

| 意象 | 例子 |
|---|---|
| 程度壓低 | cut down (on) 減少 / turn down 轉小聲 / calm down 冷靜下來 |
| 機器垮掉 | break down 拋錨、故障 |
| 落筆下來 = 記錄 | write down / note down 記下 |
| 把提議壓下去 = 拒絕 | turn down an offer 拒絕 |

turn down 一詞兩義（轉小聲、拒絕）都走「往下壓」意象。

#### OUT（往外）→ 爆發、分發、熄滅、用完

| 意象 | 例子 |
|---|---|
| 突然爆出來 | break out 爆發 / come out 出版、真相出來 |
| 往外發送 | hand out 發放 / give out 分發 |
| 火往外滅掉 | put out 撲滅 / go out 熄滅 |
| 裡面的用完 | run out (of) 用完 / sell out 售完 |

#### 其他常見介詞

| 介詞 | 意象 | 例子 |
|---|---|---|
| in（進來） | 收進來、賺進 | take in 收留、欺騙 / bring in 引進、賺進 |
| on（接觸、繼續） | 穿上、繼續、引發 | put on 穿上、體重增加 / carry on 繼續 / bring on 引發 |
| over（移交） | 接手、轉移 | take over 接管 / hand over 移交 |
| through（穿透） | 經歷全程、突破 | go through 經歷 / break through 突破 |

### 已學詞組定義（依動詞分組）

- **look**：look for 尋找 / look after 照顧 / look into 調查 / look up to 尊敬 / look forward to + V-ing 期待
- **put**：put off 延期 / put up with 忍受 / put up 提供住宿 / put on 穿上 / put out 撲滅
- **take**：take after 長相個性像長輩 / take over 接管 / take up 開始從事（嗜好）/ take in 收留、欺騙 / take off 脫掉、起飛
- **bring**：bring up 養育、提出 / bring on 引發（疾病）/ bring in 引進
- **break**：break down 故障、崩潰 / break through 突破（名詞 breakthrough）/ break out 爆發 / break up 分手、解散 / break off 中斷
- **cut**：cut down on 減少 / cut off 切斷 / cut out 戒除
- **fall**：fall off 下降 / fall out (with) 吵架鬧翻 / fall behind 落後
- **turn**：turn down 轉小聲、拒絕 / turn up 出現、轉大聲 / turn out 結果是

### 易混淆對

| 片語 | 意思 | 例句 |
|---|---|---|
| **allow for** | 事先考慮到、為...預留（還沒發生的狀況） | The schedule should allow for delays. |
| **account for** | 解釋（已發生的事）、佔（比例）、對...負責 | Bad weather accounted for the delay. / The region accounts for 40% of sales. |

| 片語 | 意思 |
|---|---|
| count on | 依賴、指望 |
| make up for | 補償 |

## 判斷法與陷阱

- **allow for = 事前留餘地；account for = 事後找原因**。題目問預留/預料 → allow for；問解釋/佔比 → account for。
- look forward to 的 **to 是介系詞** → 接 V-ing（細節見 [02-gerund-infinitive.md](02-gerund-infinitive.md)）。
- 介詞邏輯約**八成**適用，例外（如 put up with = 忍受）靠整組背。
