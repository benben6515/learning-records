## 現實時間軸

Cambridge 估計 B1→B2 約需 **200 小時**有效學習。每天 30 分鐘認真做 → 約 **8–12 個月**到 B2。B2→C1 需要大量真實輸入，無法只靠課本。

## 四塊拼圖

### 1. 文法系統化（敢用 → 用對）

主系統（cheatsheet + deck）已涵蓋：條件句、wish、倒裝、過去完成式、動名詞 vs 不定詞。
尚缺、待補進主系統的：

- 現在完成式全家福：have done / have been doing / **for** + 期間 vs **since** + 起點
- 被動語態：be + p.p.（is considered / is seen as）
- 關係子句：which / that（whose 已在 deck）
- 第二、第三條件句熟練度（結構已過關，隔日回退中，見 README 弱點軌跡）

書：*English Grammar in Use*（藍色中級本），優先做上述缺的區塊。

### 2. 字彙：單字 → 搭配詞（collocation）

- 不背 risk，背 **pose a risk / a potential risk / risk assessment**
- 新詞整組記（詞組不是單字）
- 目標：主動字彙 2,500 → 4,000+ 字族（word families）

### 3. 寫作結構（B2 議論文及格線）

- 每段第一句 = 主題句（topic sentence）：先說這段要講什麼，再給例子
- 學 hedge 緩和語氣：it seems that / to some extent —— B2 的標誌
- 寫作因為開頭不能單獨成句（sentence fragment 扣分）

### 4. 每天真實輸入

- 影集 + **英文字幕**，每天 20 分鐘
- VoiceTube（雙字幕、分級，台灣工具）
- Write & Improve（Cambridge 免費寫作批改，直接回 CEFR 等級）

## B2→C1 預習（到 B2 再啟動）

1. 精準度（nuance）：problem / issue / matter 差在哪
2. 名詞化（nominalization）：they decided quickly → their quick decision
3. 語域切換（register）：同一件事寫出正式版 + 口語版

## 一週節奏（每天約 30 分鐘）

| 天 | 任務 |
|---|---|
| 週一～五 | 3–5 句英文日記（產出）+ 掃 [review-deck](review-deck.md) 5 分鐘（既有習慣） |
| 週三 | VoiceTube / 影集 20 分鐘（英字幕） |
| 週六 | *English Grammar in Use* 一個單元（優先：完成式、被動語態） |
| 週日 | Write & Improve 寫 80 字短文，追蹤 CEFR 等級變化 |

## 錯誤日誌原則

寫作錯誤與語法題錯誤同樣集中在 [review-deck](review-deck.md)（遮答案格式）。寫作前掃一眼自己的錯題，**同樣的錯不犯第二次**——比多背 100 個單字升級更快。
