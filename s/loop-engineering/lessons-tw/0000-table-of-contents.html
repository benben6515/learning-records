《Loop Engineering》課程目錄

一條路：從「為什麼別再自己 prompt」走到「能講清楚 loop 怎麼可靠地運作」。

這門課沿一條主軸走：先掌握典範轉移（loop 是什麼、與 harness 的差別），建立六個 primitives 的詞彙表；再學讓 loop 真正可靠的兩根支柱（maker/checker、state on disk）與 skills；最後看自主等級、風險與生產模式。每一課都短短的、可獨立完成，並附隨堂測驗。知識先行，之後才動手。

Phase A — 典範轉移

  1. 01 Loop Engineering 是什麼：別再自己 prompt 從「逐句 prompt」到「設計會驅動 agent 的系統」；harness vs loop。 ~6 分鐘 · 隨堂測驗
  2. 02 六個 Primitives（＋Memory） loop 的零件詞彙表：排程／worktree／skills／MCP／sub-agent／state。 規劃中

Phase B — 讓 loop 真的可靠

  1. 03 Maker / Checker：實作者不評分自己的作業 sub-agent 分工的結構性原則；`/goal` 把它套用在停止條件上。 規劃中
  2. 04 State on Disk：模型會忘，repo 不會 為什麼 `STATE.md` 是 loop 的脊椎——跨 session 的持久記憶。 規劃中
  3. 05 Skills：把 intent 寫在外面 付清 intent debt——慣例、build、與「我們不這樣做」寫一次、每次讀。 規劃中

Phase C — 經營、風險與模式

  1. 06 自主等級 L1 → L2 → L3 先 report-only，再 assisted，最後 unattended——分階上線的邏輯。 規劃中
  2. 07 兩種債與一個陷阱 comprehension debt、orchestration tax，與 cognitive surrender——loop 不會刪掉你。 規劃中
  3. 08 七個 Patterns 與 Loop Ready score daily triage、pr babysitter、ci sweeper……；以及「能不能上線」的評分。 規劃中
怎麼開始 第一次走，從第 01 課開始即可。課程會依你的進度一堂堂長出來——每一課都落在你「稍微踮腳就搆得到」的範圍。
