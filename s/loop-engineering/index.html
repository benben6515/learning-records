Loop Engineering（驅動 AI Agent 的迴圈工程）

從「自己逐句 prompt agent」升級成「設計會編排 agent 的系統」。From prompting agents to designing the loops that drive them.

Boris Cherny（Anthropic Claude Code 負責人）說他現在不再 prompt Claude，而是「寫 loop」。這門課先建立完整的心智模型：loop engineering 是什麼、harness 與 loop 的差別、六個 primitives、讓 loop 可靠的兩根支柱（maker/checker 與 state on disk）、自主等級 L1→L2→L3，以及它「不會刪掉你」的風險。植基於 Cobus Greyling、Addy Osmani 與 cobusgreyling/loop-engineering repo。
