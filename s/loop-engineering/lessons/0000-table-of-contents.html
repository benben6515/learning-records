The Loop Engineering Course Index

One route: from "why stop prompting" to "how a loop stays reliable."

The course follows one spine: first the paradigm shift (what a loop is, vs a harness) and the vocabulary of the six primitives; then the two pillars that make a loop actually reliable (maker/checker, state on disk) plus skills; finally autonomy levels, risk, and production patterns. Each lesson is short, self-contained, and has a quiz. Knowledge first; hands-on later.

Phase A — The paradigm shift

  1. 01 What is Loop Engineering: stop prompting From prompting turn-by-turn to designing the system that drives agents; harness vs loop. ~6 min · quiz
  2. 02 The Six Primitives (+ Memory) The loop's parts: scheduling / worktree / skills / MCP / sub-agent / state. planned

Phase B — What makes a loop actually work

  1. 03 Maker / Checker: never grade your own homework The structural principle behind sub-agent splits; `/goal` applies it to the stop condition. planned
  2. 04 State on Disk: the model forgets, the repo doesn't Why `STATE.md` is the loop's spine — durable memory across sessions. planned
  3. 05 Skills: write the intent on the outside Paying down intent debt — conventions, build, and "we don't do it this way," once. planned

Phase C — Operating, risk & patterns

  1. 06 Autonomy levels L1 → L2 → L3 Report-only first, then assisted, then unattended — the logic of phasing. planned
  2. 07 Two debts and a trap comprehension debt, orchestration tax, and cognitive surrender — the loop doesn't delete you. planned
  3. 08 Seven patterns & the Loop Ready score daily triage, pr babysitter, ci sweeper…; and the "is it ship-ready?" score. planned
How to start If this is your first time through, start with Lesson 01. The course grows one lesson at a time, each pitched at the edge of what you can already do.
