Seven Patterns and the Loop Ready Score

Turn the ideas into copyable production loops, and the score that says whether you can ship.

This is the last lesson. The first seven built a mental model — what a loop is, the six parts, the two pillars, autonomy levels, risks. This one lands them: copyable production patterns, plus a Loop Ready score that tells you whether you can ship. After this lesson you have the vocabulary to read any real loop.

A pattern is a "copyable production loop"; the Loop Ready score is the objective measure of "can you let go." Pick one pattern, start at L1.

What's a pattern

A pattern is a copyable production loop — each with its own cadence, autonomy level, and token cost. The picking rule is simple: one concern, one primary loop; overlapping loops need coordination (don't let them fight over the same branch in the same hour).

The Loop Ready score: an objective 0–100 measure

"Can I let go" isn't a feeling. loop-audit scores your project 0–100 on Loop Readiness, backed by 20+ signals. Key facts:

  • It maps the score to autonomy levels — L0/L1/L2/L3 each correspond to different sections of the design checklist (the table from Lesson 06).
  • The highest-weighted signals are the verifier and state — 14 points each, tied for highest. This is the quantitative proof of the "two pillars" from Lessons 03 and 04.
  • L3 is mechanically blocked until loop-budget.md + loop-run-log.md + a LOOP.md budget section exist.
  • Autonomy is not a one-way ratchet — you can and should demote.
A high score doesn't mean you can let go A cautionary story: a team ran loop-init + loop-audit to 92, and the report-only Daily Triage genuinely surfaced value. Then on day 6 they upgraded it to a CI sweeper at 15 minutes — with no separate verifier, no branch allowlist, and no hard daily token cap. A high score is necessary, not sufficient.

Red flags on the checklist (stop and fix)

  • The same PR has had >3 automated fix attempts without progress.
  • The verifier is the same session as the implementer.
  • No state file — the loop has amnesia every run.
  • Notifications fire on every run regardless of findings.
  • Auto-merge enabled with no path allowlist.
