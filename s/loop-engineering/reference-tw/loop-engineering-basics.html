Loop Engineering 基礎小抄

一頁壓縮：paradigm、harness vs loop、六 primitives、loop 解剖、L1/L2/L3、風險。

一句話定義

取代那個「自己 prompt agent」的你。loop＝遞迴目標：你定義目的，agent 用 sub-agent＋外部記憶迭代到完成或交回給你。你設計一次，不再逐句 prompt。

Harness vs Loop（別搞混）

Harness（馴具）Loop（迴圈）
範圍單一 agent、單次 session跨 session、反覆跑
組成工具／context／權限／規則harness ＋ 排程 ＋ 狀態 ＋ 驗證鏈
解決「這一次 run」跑得好「在時間上編排」這些 run

六個 Primitives（＋Memory）

Primitive職責形式／例子
排程心跳；沒有它就只是一次性 run/loop、cron、GitHub Actions、/goal
Worktree並行不互踩的隔離 checkout每 agent 一棵 worktree，用完清理
Skills意圖的持久記憶；付 intent debtSKILL.md：慣例、build、「不這樣做」
Connectors（MCP）從評論員變操作員開 PR、更新 Linear、貼 Slack、查 DB
Sub-agentmaker/checker 分工explorer→implementer→verifier
＋ State跨 session 持久脊椎STATE.md／Linear board

最小可行 loop＝排程 ＋ 一個 triage skill ＋ 一個 state 檔；再依價值一個個加。

Loop 解剖（一次 run）

排程→ Triage skill→ 讀寫 STATE
Worktree→ 實作 sub-agent→ 驗證 sub-agent
MCP／Git／Ticket→ Human Gate？→ 提交／PR 或 交回給人
實作者絕不評分自己的作業——驗證 sub-agent 是你能放手的本錢

自主等級 L1 → L2 → L3

等級做什麼建議
L1只報告（report-only）第一週就從這裡開始
L2協助修復（assisted）有 verifier 後再升
L3無人看管（unattended）最後才上；token 會爆

風險：loop 不會刪掉你

三個會被放大的問題 Intent debt：每次冷啟動，缺漏被自信猜測填滿 → 用 skills 還債。
Comprehension debt：loop 出貨愈快、你懂愈少 → 去讀它寫了什麼。
Cognitive surrender：放任跑、不再有意見 → 用判斷力設計 loop，別用它逃避思考。
Orchestration tax：並行 agent 的人力成本；worktree 拿掉機械碰撞，你仍是天花板。

`/goal` vs `/loop`

  • /loop＝依 cadence 重跑（每 N 分鐘／小時）。
  • /goal＝跑到某可驗證條件成立為止，且由「另一個」模型檢查是否完成（maker/checker 套用在停止條件）。
