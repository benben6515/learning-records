Backend Fluency — 課程目錄

前端工程師 → 全端，Node + TypeScript。觀念先於框架、框架次之、不容許魔法。每天約 30 分鐘——每課一個緊湊觀念，加一個拿得走的勝利。

課程

  1. 01 不用框架寫伺服器 用純 node:http 打造真正的 HTTP 伺服器——從此不再好奇 Express 藏了什麼。 約 30 分鐘 · node:http · 動手做
  2. 02 一個執行緒，多個請求 事件迴圈（event loop）：一個 JavaScript 函式如何服務數百個連線——以及一個同步大戶如何凍結全部。 約 30 分鐘 · 事件迴圈 · 動手做
  3. 03 不用框架做路由排程中 路徑、方法與內文解析全手寫——然後把 Express 當老朋友相認，而不是陌生人。 約 30 分鐘 · 路由
  4. 04 把 REST 語意做對排程中 方法、狀態碼、冪等性——把錯誤訊息做成前端能信賴的合約。 約 30 分鐘 · API 設計
  5. 05 資料持久化：檔案 → SQLite → PostgreSQL排程中 資料到底存在哪：schema、SQL 與 migration——SQL 還沒變成你的之前，不碰 ORM 魔法。 多課單元 · 資料
  6. 06 驗證：Session vs Token排程中 呼叫者是誰？雜湊、Cookie vs JWT，以及把事情做對的 OWASP 基礎。 約 30 分鐘 · 安全

參考卡

  • HTTP 解剖與 curl 速查表——請求／回應結構、方法、狀態碼、標頭，以及讓它們現形的 curl 指令。
  • 事件迴圈速查表——六步驟模型、四條規則、阻塞 API 黑名單，與 30 秒驗證法。
