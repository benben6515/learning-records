# Mission: Backend Fluency — Frontend Dev → Full-Stack on Node + TypeScript

## Why
The learner is a frontend developer whose work increasingly needs backend contributions, and who wants to stop treating the server as a black box. The concrete outcome: design, build, and defend backend features (APIs, data, auth, deployment) in **Node.js + TypeScript** — the stack already shared with the frontend — and grow into a genuinely full-stack developer.

## Success looks like
- Build a REST/JSON API from scratch with Node + TypeScript where **no layer is magic**: routing, validation, errors, and status codes can all be explained down to `node:http`.
- Explain confidently what happens between a browser `fetch()` and a route handler — TCP, HTTP messages, the event loop, middleware.
- Own a data layer: design a relational schema, write SQL queries, run migrations, and know when a cache or queue is warranted.
- Ship it: run the service locally against a real database, deploy to a public URL, and secure it (auth, secrets, OWASP basics).
- Review a backend pull request with informed opinions (the "work needs it" angle).

## Constraints
- **Time: ~30 minutes/day.** Daily micro-sessions; hands-on coding beats videos.
- **Stack locked to Node.js + TypeScript.** No polyglot detours until the fundamentals are solid.
- Starts from "written a few endpoints" — concepts first, frameworks second. Every abstraction we adopt must first be built or dissected by hand.
- Workspace is public (GitHub Pages). Keep state files generic and scrubbed of personal context.

## Out of scope
- Other languages/frameworks (Go, Python, Java, Spring) — possibly later.
- Kubernetes, microservices, large-scale infra — until fundamentals are second nature.
- Frontend frameworks — already strong; use only as API clients.
- GraphQL — only after REST semantics are internalised.
