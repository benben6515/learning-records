Backend Fluency — Course Index

Frontend dev → full-stack on Node + TypeScript. Concepts first, frameworks second, no magic allowed. One tight idea and one tangible win per lesson, ~30 minutes a day.

Lessons

  1. 01 A Server With No Framework Build a real HTTP server with raw node:http — and never wonder what Express is hiding again. ~30 min · node:http · hands-on
  2. 02 One Thread, Many Requests The event loop: how one JavaScript function serves hundreds of connections — and how one sync hog freezes them all. ~30 min · event loop · hands-on
  3. 03 Routing Without a Framework A real route table with params, body parsing, validation, and an error net — your first true REST endpoint. ~35 min · routing · hands-on
  4. 04 REST Semantics Done Rightqueued Methods, status codes, idempotency, and errors as a contract your frontend can trust. ~30 min · API design
  5. 05 Persistence: Files → SQLite → PostgreSQLqueued Where data actually lives: schema, SQL, and migrations — no ORM magic until SQL is yours. multi-lesson · data
  6. 06 Auth: Sessions vs Tokensqueued Who is calling? Hashing, cookies vs JWTs, and the OWASP basics of doing it safely. ~30 min · security

Reference sheets

  • HTTP Anatomy & curl Cheat Sheet — request/response structure, methods, status codes, headers, and the curl commands that reveal them.
  • The Event Loop Cheat Sheet — the six-step model, the four rules, the blocking-API blacklist, and the 30-second proof.
  • The Minimal Node API — the annotated 55-line skeleton: route table, matcher, body reader, error net, and the Express mapping.
