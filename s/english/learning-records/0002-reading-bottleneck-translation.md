# Reading bottleneck confirmed: translating to the first language

Reading is mostly **dev docs**, with a confirmed habit of **silently translating English → first language** while reading. This is the classic L2 fluency bottleneck — every sentence takes two trips (English in → first language → meaning) instead of one (English → meaning directly).

### Why it matters beyond reading
The same translate-to-first-language habit is what **freezes speaking**: composing in the first language, then converting. So fixing it in reading has direct spillover to the #1 mission goal (speaking + confidence). Reading fluency is treated here as *input fluency that fuels output*, consistent with MISSION (reading is "input fuel", not a primary target).

### Agenda it sets
- Teach **chunk reading** (2–4 words per eye-fixation) and **direct comprehension** (no translation), practised on dev-doc-style prose already understood conceptually — ideal, because meaning can be self-checked against existing knowledge.
- Core drill: **repeated reading** (3 timed passes → measurable wpm gain). Nation (2006): ~98% vocabulary coverage needed for comfortable unassisted reading; ~95% for gist. Slowness is largely *decoding* half-known words, not eye speed.
- Supporting rules: the 3× lookup rule; read at the right level (extensive reading at i+1).
- Delivered as Lesson 02 (interactive wpm drill + comprehension check) + reading-fluency reference sheet.
