# Baseline & mission established

Self-reported starting level: **B1–B2** English. The learner's motivations (career, formal study, personal growth, a possible major life transition) all converge on one need: **productive fluency** — speaking, writing, and the confidence to use English without first translating from the first language. Technical/coding English is already handled fluently (front-end web dev), so reading/listening and technical vocabulary are strengths, not gaps.

The weak spots named precisely: **speaking, writing, confidence** — all *output* skills. This sets the floor for what to teach next: the focus is **production**, not more input or grammar rules. The time budget is **~15 min/day**, which fixes the design of every lesson and habit (micro-sessions, spacing, retrieval). The environment is **solo-first** (not immersed), so habits must work alone first.

### Implications
- The zone of proximal development is **B2 productive fluency → C1**: spontaneous, unscripted speaking and writing on familiar → professional topics.
- Lesson 01 introduces **shadowing** as the foundational daily solo speaking habit (fits 15 min, hits speaking + confidence, research-backed).
- Writing will follow (daily free-writing sprint with agent feedback — tight loop, since writing is the one skill the agent can correct directly).
- Technical English is off-limits as a "gap"; it's a strength to exploit for input material.
