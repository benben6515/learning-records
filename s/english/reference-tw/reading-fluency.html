讀得更快，靠的是讀得更聰明

閱讀速度的重點不在於讓眼睛動得更快——而在於直接認得，而不是逐字解碼。讀東西時把這張卡放在旁邊。

你為什麼慢（三個真正的原因）

  1. 在「解碼」，不是在「認字」。每個你只有半熟的字都是減速坡——大腦把它拼出來，而不是瞬間認得。
  2. 翻譯成中文。英文進來 → 中文 → 意義，每句兩趟。流暢的讀者是 英文 → 意義，一趟搞定。
  3. 一個字一個字讀。你的眼睛每次停留可以抓 2–4 個字。如果你每個字都停，閱讀速度會比應有的慢上 2–4 倍。

解法：三個習慣

  • 以意義群組閱讀。讓眼睛落在片語群組上（「when you type / a web address」），而不是單字。
  • 容忍空白。不要每個生字都停——從上下文猜，繼續往前。
  • 建立即認字彙。你瞬間認得的字越多，讀得越快。Nation（2006）：要舒適地不查字典閱讀，大約需要認得 98% 的字。

練習：重複閱讀（3 次）

  1. 挑一段你約略懂 95% 的短文（約 200 字）。
  2. 第 1 次：為意思而讀。不要停。計時。
  3. 第 2 次：把同一篇再讀一次。計時。
  4. 第 3 次：再讀一次，追求流暢。計時。

你的每分鐘字數（wpm）會在幾次之間跳升——那個躍進，就是「自動化」的感覺。每週挑一篇短文練幾次，幾個月後你的第一次速度就會爬升。

保護理解力的兩條規則

  • 3× 規則。只有當一個字出現 3 次以上、或擋住整句意思時才查。否則繼續往前。
  • 讀適合的難度。如果你一直查字，表示文章太難——換簡單一點的。輕鬆的閱讀培養速度；艱難的閱讀培養挫折。
