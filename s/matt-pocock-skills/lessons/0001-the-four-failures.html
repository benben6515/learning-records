The Four Failure Modes

Four ways an AI session goes wrong — and the skill that fixes each.

Every skill in the Matt Pocock set is a fix for one of four ways an AI coding session goes wrong. Before learning any single skill, learn the four — they're the map the rest of the course is drawn from.

The four

  1. Misalignment — the agent didn't do what you wanted. You thought it understood; the output proved it didn't. The commonest failure of all.
  2. Verbosity / no shared language — the agent uses 20 words where 1 will do, because no one taught it the project's jargon.
  3. The code doesn't work — you're aligned, but the output is still broken. There's no feedback loop telling the agent what its code actually does.
  4. A ball of mud — the codebase is hard to change. Agents accelerate entropy, so without deliberate design care it compounds fast.
The pattern None of these are cleverness problems. Each is a communication or feedback problem. The fixes are disciplines borrowed from decades of software engineering — interview relentlessly, write the language down, run the code, invest in design — made repeatable as skills.

When you can classify any situation into one of these four, you know which skill to reach for. That's the whole game.
