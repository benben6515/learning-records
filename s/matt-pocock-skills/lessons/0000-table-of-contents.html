The Matt Pocock Skills Course Index

Seven lessons, one route: from idea to ship, driven by a spec.

This course isn't a box of disconnected commands. It's a single route that almost every piece of work travels — mental map → entry point → two artefacts → spec → tickets → the architecture consumer. Each lesson is a stage on that route. Read them in order and you'll hold the shape of the whole system.

grill-with-docs → to-spec → to-tickets → implement → code-review
idea  ⟶  ship  ·  written with CONTEXT.md + ADRs, then consumed by improve-codebase-architecture
