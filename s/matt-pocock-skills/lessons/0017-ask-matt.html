Ask Matt & Routers

The router over the user-invoked skills — the cure for cognitive load.

You don't remember every skill, so ask. /ask-matt is the router over the user-invoked skills in the repo — it maps every skill and how they relate, so you don't have to hold it all in your head.

Why a router exists at all

This is a cognitive-load decision, from the writing-for-agents reference (renamed from writing-great-skills, 2026-07). Every skill spends one of two loads:

ModeCostFires
Model-invokedKeeps a description in the window every turn — context loadOn its own, when the task fits
User-invokedStrips that description; you must remember it exists — cognitive loadOnly when you type it

Most of the Matt Pocock skills are user-invoked, which is why cognitive load is the pressure the whole system is built to manage. When user-invoked skills multiply past what you can hold in your head, the cure is a router skill that names the others and when to reach for each.

ask-matt is that router It is the direct cure for the cognitive load the user-invoked skills pile up. When you cannot remember which skill fits, type /ask-matt and it routes you over the whole set.

What ask-matt knows

The map (covered across this course):

  • The main flow — idea→ship, with the prototype branch and the size branch.
  • On-ramps — triage, diagnosing-bugs, wayfinder.
  • Codebase health — improve-codebase-architecture (survey) + codebase-design (bench).
  • Vocabulary layers — domain-modeling (domain words) + codebase-design (module shape), running underneath.
  • Phase boundaries — at the gap between phases, five options in a fixed order: Continue → /clear → /handoff → subagent → /compact.
  • Standalone — grill-me, grilling, prototype, research, to-questionnaire, wizard, wait-what, teach, writing-for-agents, resolving-merge-conflicts.

The rule that keeps the router honest

From the repo's CLAUDE.md: whenever a skill is added, renamed, removed, or changes how it fits the flows, ask-matt's SKILL.md must be re-read and updated so the map stays accurate. A new skill it never mentions, or a stale one it still routes to, is a router that lies. This is the maintenance discipline that makes the router trustworthy over time.

When to reach for it

Whenever you are unsure which skill or flow fits the moment. Type /ask-matt; it routes you. It is not a step in a chain — it is the index you consult when you cannot remember the map.

Ask your teacher Stuck or curious? Ask a follow-up question — anything unclear is fair game.
