The Mental Map

Before the loop, the map. One idea you can hold in your head.

Your mission is to drive your own project's work from a fuzzy idea all the way to a shipped change. Before any single skill, you need the shape of the whole system — because every skill is just a stage on one route.

The one idea

The Matt Pocock skills are not a toolbox of disconnected commands. They form a single path that almost all work travels:

grill-with-docs → to-spec → to-tickets → implement → code-review
idea  ⟶  ship  ·  with domain-modeling writing CONTEXT.md + ADRs the whole way

Read it left to right. You start with an idea, sharpen it by interview (grill-with-docs), freeze it into a spec (to-spec), split it into buildable tickets (to-tickets), build each one (implement), and review before you commit (code-review). Spec-driven development is the middle stretch — grill-with-docs → to-spec → to-tickets — and that is what we're learning first.

The rule that breaks most people Keep grill-with-docs → to-spec → to-tickets in one unbroken context window. The grilling, the spec, and the tickets must build on the same thinking — so don't compact or clear the conversation until the tickets exist. Then each implement starts fresh, working from its ticket alone. If you near the smart zone (~120k tokens) before the tickets, hand off — don't grind on degraded reasoning.

Why this matters for you

You're already comfortable driving an agent. The skill that separates people who fumble these tools from people who ship with them isn't knowing what each command does — it's knowing where you are on the route, and the single discipline of one continuous window, then compartmentalised builds. Hold the map and that rule, and the rest is detail you can look up.

Your tangible win — say these out loud

  1. Name the five stages of the main flow, in order.
  2. Point to which stretch counts as "spec-driven."
  3. State the one context-hygiene rule and when you're allowed to clear context.

If you can answer all three without checking, you've got the map. The rest of this course fills in the stages — starting with the entry point, grill-with-docs.
