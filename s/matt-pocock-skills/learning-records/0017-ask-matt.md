# Ask Matt & routers — the cure for cognitive load

The learner can explain why a router exists: most skills in the set are user-invoked (description stripped, must be remembered), so the pressure is cognitive load on the user — and `ask-matt` is the index that holds the map. This matters because it is the recovery path whenever fluency fails.

**Evidence:** correctly named cognitive load (not context load) as what a router cures; typed `ask-matt` when unsure which skill fits; required re-reading and updating `ask-matt`'s SKILL.md when skills are added/renamed/removed (a router that lies is useless); stated the user-invoked cost; recited the phase-boundary options in fixed order (Continue → `/clear` → `/handoff` → subagent → `/compact`); and defined a lying router as one that never mentions new skills or still routes to stale ones.

**Implications:** ready for Lesson 18 — the meta skills: teach & writing-for-agents.
