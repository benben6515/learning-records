The Four Failure Modes

The spine of the whole skills set. Every skill is a fix for one of these.

Every skill in the Matt Pocock set is a fix for one of four ways an AI coding session goes wrong. Classify the situation and you know the skill. From the README — “Why These Skills Exist”.

#Failure modeRoot causeFix (skill)Anchored in
1 Misalignment
The agent didn’t do what you want.		 “No-one knows exactly what they want.” You think the dev understands; you see what’s built and realize it didn’t. Communication gap. /grill-me (no codebase, stateless)
/grill-with-docs (has codebase, stateful)		 The Pragmatic Programmer — Thomas & Hunt
2 Verbosity / no shared language
The agent uses 20 words where 1 will do.		 The agent is dropped in and told to figure out jargon as it goes. No ubiquitous language to anchor on. /grill-with-docs builds CONTEXT.md + ADRs as it grills. /domain-modeling sharpens terms. Domain-Driven Design — Eric Evans
3 The code doesn’t work
Aligned on what to build, but it still produces crap.		 No feedback loop. Without feedback on how code actually runs, the agent flies blind. /tdd — red-green-refactor, one vertical slice at a time. /diagnosing-bugs — tight feedback loop first, then hypothesize. The Pragmatic Programmer — “the rate of feedback is your speed limit”
4 A ball of mud
Codebase is complex and hard to change; entropy accelerates.		 Agents can radically speed up coding, so they also accelerate software entropy. No one’s investing in design. /to-spec quizzes your module choices first. /improve-codebase-architecture for periodic upkeep. /codebase-design vocabulary (deep modules). Extreme Programming — Kent Beck (“invest in design every day”)
A Philosophy of Software Design — Ousterhout (“the best modules are deep”)

The pattern

Each failure mode is a communication or feedback problem, not a cleverness problem. The fixes are not “use a better prompt” — they’re disciplines (interview relentlessly, write the language down, run the code, invest in design) borrowed from decades of software engineering, made repeatable as skills.

When you can classify any situation into one of these four, you know which skill to reach for.
