Matt Pocock 技能目錄

依官方 repo（mattpocock/skills）分類，附一句話中文說明。技能名即為呼叫名稱。

共 28 個穩定技能，分為 Engineering（工程）、Productivity（生產力）、Misc（雜項）、Personal（個人）四類；另有開發中與已棄用者列於末段。每一個都由它自己的 SKILL.md 權威定義。

本工作區目前學的是其中的規格驅動主幹——ask-matt → grill-with-docs → to-spec → to-tickets → implement——由 domain-modeling 撰寫文件、improve-codebase-architecture 消化。見 流程圖。

使用者觸發（user-invoked）：只在「你打字輸入」時觸發（disable-model-invocation）。　 模型觸發（model-invoked）：模型可憑觸發詞自行抓取。

Engineering — 工程（日常程式工作）

使用者觸發

技能一句話說明
ask-matt問「我的情況該用哪個技能或流程」，是本 repo 所有 user-invoked 技能的入口路由。
grill-with-docs一場窮追不捨的訪談，把計畫或設計磨利，同時就地建立專案領域模型（更新 CONTEXT.md 與 ADR）。
triage讓議題走過一套分級角色的狀態機（分類、驗證、必要時盤問），寫出代理可直接施工的簡報。
improve-codebase-architecture掃描程式庫尋找深化機會，以視覺化 HTML 報告呈現，再就你挑中的項目盤問到底。
setup-matt-pocock-skills為此 repo 設定議題追蹤器、分級標籤詞彙與領域文件版面；每個 repo 跑一次。
to-spec把當前對話綜合成一份規格並發布到議題追蹤器——不訪談，只綜合已談定的內容。
to-tickets把計畫／規格／對話拆成一套曳光彈票，每張宣告自己的阻塞邊，發布到設定的追蹤器。
implement依規格或一組票實作工作，在預先約定的接縫驅動 /tdd，並在提交前以 /code-review 收尾。
wayfinder把一件大到單一工作階段塞不下的工作，規劃成議題追蹤器上的決策票地圖，逐一解開直到路徑清晰。

模型觸發

技能一句話說明
prototype做一個拋棄式原型來回答設計問題：用終端機程式驗證狀態／邏輯，或用可切換的 UI 變體探索介面。
diagnosing-bugs診斷難纏 bug 與效能回歸的紀律化迴圈：重現 → 最小化 → 假設 → 儀器化 → 修復 → 回歸測試。
research針對高信任主要來源調查一個問題，把發現寫成帶引用的 Markdown 檔，以背景代理執行。
tdd以紅—綠—重構迴圈做 TDD；一次一道垂直切片地開發功能或修 bug。
domain-modeling主動建立並磨利專案的領域模型——挑戰用語、用情境壓力測試、就地更新 CONTEXT.md 與 ADR。
codebase-design設計「深模組」的共用紀律與詞彙：小介面、乾淨接縫、透過介面可測。
code-review自某基準點起對 diff 做雙軸審查——標準（是否符合 repo 規範＋Fowler 壞味道基線）與規格（是否如實實作原始 issue／PRD），以並行子代理執行。
resolving-merge-conflicts逐一 hunk 處理進行中的 git merge／rebase 衝突，依兩側各自的原始意圖求解，再完成操作——絕不 --abort。

Productivity — 生產力（通用工作流程）

使用者觸發

技能一句話說明

In-progress — 開發中（尚不穩定）9

Matt 仍在實驗、隨時可能變動的技能；認識即可，先別依賴。

技能一句話說明
batch-grill-me一次拋出所有「前緣」問題的窮追訪談，一輪一輪進行。
claude-handoff把當前對話交給一個能立即接手的全新背景代理。
loop-me針對我想建立的工作流程規格，在工作區內盤問我。
setup-ts-deep-modules把 dependency-cruiser 接進 TypeScript repo，讓每個 package 成為深模組——實作藏在子資料夾，只能透過入口檔觸及。
to-questionnaire把一個你無法完全回答的決策，轉成給別人填寫的問卷。
wizard產生一個互動式 bash 精靈，帶人類走過手動程序——開 URL、抓值、逐步確認，並寫 .env 與 GitHub Actions。
writing-beats把原料組成一段拍點旅程，在每個拍點依靠某詞前先把該詞奠基。
writing-fragments挖掘原始碎片，尚未有結構。
writing-shape把原料逐段塑形成一篇文章。
