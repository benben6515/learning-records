Matt Pocock 技能目錄

依官方 repo（mattpocock/skills）分類，附一句話中文說明。技能名即為呼叫名稱。

共 31 個穩定技能，分為 Engineering（工程）、Productivity（生產力）、Misc（雜項）三類；另有開發中者列於末段。每一個都由它自己的 SKILL.md 權威定義。

本工作區目前學的是其中的規格驅動主幹——ask-matt → grill-with-docs → to-spec → to-tickets → implement——由 domain-modeling 撰寫文件、improve-codebase-architecture 消化。見 流程圖。

使用者觸發（user-invoked）：只在「你打字輸入」時觸發（disable-model-invocation）；職責是編排。 模型觸發（model-invoked）：模型可憑觸發詞自行抓取；承載可重複使用的紀律。
使用者觸發的技能可以呼叫模型觸發的技能，但絕不呼叫另一個使用者觸發的技能。

Engineering — 工程（日常程式工作）

使用者觸發

技能一句話說明
ask-matt問「我的情況該用哪個技能或流程」——本 repo 所有技能的路由器。
grill-with-docs窮追不捨的訪談，同時就地建立專案領域模型：磨利術語、內嵌更新 GLOSSARY.md 與 ADR。
triage讓議題走過分級角色的狀態機；產出附代理簡報（agent brief）的代理可施工議題。
improve-codebase-architecture掃描程式庫尋找深化機會，以視覺化 HTML 報告呈現，再就你挑中的項目盤問到底。
setup-matt-pocock-skills為此 repo 設定議題追蹤器、分級標籤詞彙與領域文件版面；每個 repo 跑一次。
to-spec把當前對話綜合成一份規格並發布到議題追蹤器——不訪談，只綜合已談定的內容。
to-tickets把計畫／規格／對話拆成一套曳光彈票，每張宣告自己的阻塞邊——本地一票一檔文字，或真追蹤器上的原生阻塞連結。
implement依規格或一組票實作工作，在預先約定的接縫驅動 /tdd，並在提交前以 /code-review 收尾。
implement-spec新增一次跑完整份規格：把票讀成任務圖，在就緒的frontier上於各自 worktree 派實作子代理並行施工，全部落在一條整合分支上，最後以 /code-review 收尾。逐票 /implement 的並行替代方案。
retro新增回顧一個寫程式的 session——主流程的最後一步，在 code-review 之後——對代理的環境（而非程式碼）提出改進：導覽指針、自動檢查、coding standards、steering files、工具經濟。機械性違規變成確定性檢查；CODING_STANDARDS.md 只留給判斷題。
wayfinder把一件大到單一工作階段塞不下的工作，規劃成議題追蹤器上的決策票地圖，逐一解開直到路徑清晰。

模型觸發

技能一句話說明
prototype做一個拋棄式原型來回答設計問題：狀態／邏輯問題給單一可分享 HTML 檔，UI 問題給同一條路由上可切換的數個截然不同變體。
diagnosing-bugs診斷難纏 bug 與效能回歸的紀律化迴圈：建立會在此 bug 上轉紅的回饋迴圈 → 最小化 → 假設 → 儀器化 → 修復 → 回歸測試。
research針對高信任主要來源調查一個問題，把發現寫成帶引用的 Markdown 檔留在 repo 裡；以背景代理執行。
tdd以紅 → 綠迴圈做 TDD；一次一道垂直切片地開發功能或修 bug（重構屬於審查階段）。
domain-modeling主動建立並磨利專案的領域模型：對照詞彙表挑戰術語、用邊界情境壓力測試、內嵌更新 GLOSSARY.md 與 ADR。
codebase-design設計「深模組」的共用紀律與詞彙：小介面後藏大量行為、放在乾淨接縫上、透過介面可測。
code-review自某基準點起對 diff 做雙軸審查——標準（repo 規範＋Fowler 壞味道基線）與規格（是否如實實作原始 issue／spec）——以並行子代理執行。
pr新增pull request 本文該有的形狀（模型觸發，代理寫 PR 時自動套用）：以最小視覺呈現改動的 Summary、改前／改後的證據、單向／雙向門的合併風險判定。
wizard升等產生互動式 bash 精靈，帶人類走過只有人類能做的步驟：開基礎設施、設憑證或 CI secrets、逛陌生第三方後台、跑一次性遷移或切換。

Productivity — 生產力（通用工作流程）

使用者觸發

技能一句話說明
grill-me被窮追不捨地訪談你的計畫或設計，直到設計樹每一條分支都被解開。無狀態——不留文件軌跡。
handoff把當前對話壓縮成一份交接文件，讓另一個代理能接續工作。
teach跨多次 session 教你一項新技能或概念，以當前目錄作為有狀態的教學工作區。
to-questionnaire轉正把一個你獨自答不了的決策，變成給唯一能答的人填的 Markdown 問卷。盤問的是「這份問卷怎麼送」（給誰、要收回什麼），不是主題本身。
wait-what新增訊息沒聽懂的當下就開火。代理用它補上你缺少的上下文重新講一遍——白話英文，用你 GLOSSARY.md 的詞彙。
