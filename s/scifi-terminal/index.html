Sci-Fi Terminal Panes · 科幻終端機課程

Build the Bridge Console

把終端機變成科幻電影裡的駕駛艙。Six short lessons from plain terminal to a sci-fi movie bridge console — split panes, pastel HUD, live readouts, CRT glow — built with existing tools only: tmux + Catppuccin + starship + Ghostty + cool-retro-term. Config over scripts; understanding over copy-paste.六堂短課，從素人終端機到科幻電影駕駛艙——分割窗格、粉彩 HUD、即時讀數、CRT 螢光。只用現成工具，設定檔而不寫腳本。

Lessons · 課程

English · all lessons

  • Lesson 01 — Zero-Config Movie Look · install the TUI props, first movie screen. (~10 min)
  • Lesson 02 — tmux Panes From Scratch · the grid, the prefix key, surviving sessions. (~15 min)
  • Lesson 03 — Catppuccin tmux + TPM · plugin manager, pastel HUD status bar. (~15 min)
  • Lesson 04 — starship Powerline Prompt · the segmented prompt in one command. (~10 min)
  • Lesson 05 — Ghostty Theming + Bridge Assembly · complete the trilogy, assemble the console. (~15 min · payoff)
  • Lesson 06 — CRT Finale: cool-retro-term · the movie-prop screenshot. (~10 min · finale)

About · 關於

Mission: learn the techniques behind the movie-console look — the 4-layer stack (emulator → multiplexer → prompt → TUI props) — so it can be rebuilt on any machine with brew + config files. No shell scripts.
任務：學會電影駕駛艙外觀背後的技術——四層堆疊（終端機 → 多工器 → 提示符 → TUI 道具）——只用 brew 與設定檔，就能在任何機器上重建。不寫 shell script。
