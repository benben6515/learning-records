第 02 課 · 科幻終端機

tmux 窗格從零開始

約 15 分鐘 第 2 層 第一份設定

四個分頁只是預告。電影是全部同時出現，排成網格。把一個終端機變成那個網格的工具叫 tmux——已裝在你機器上（3.7b），而且完全沒設定過。這其實很幸運：你會學得乾乾淨淨，沒有舊習慣。

階層：server → session → window → pane

tmux 是一個背景 server，你把 client 掛上去。Server 裡住著 session（有名字的工作區，例如 bridge）；session 裡有 window（全螢幕分頁）；每個 window 可切成多個 pane——你的科幻面板。魔力在於：session 不會跟著終端機關閉而消失。關掉 Ghostty、重開、重新 attach——你的駕駛艙還在跑。

Prefix 鍵 tmux 指令是兩段式：Ctrl-b（兩鍵一起按住再放開）然後按一個鍵。Ctrl-b 的意思是「接下來我是在跟 tmux 講話，不是跟程式」。前一天會覺得怪，之後變肌肉記憶。

蓋網格

$ tmux new -s bridge        # 建立名為 "bridge" 的 session

開始分割——記住：先 prefix，再按鍵：

  • Ctrl-b % — 分左右（垂直分隔線）
  • Ctrl-b " — 分上下（水平分隔線）
  • Ctrl-b ←→↑↓ — 在窗格間移動
  • Ctrl-b z — 把一個窗格放大成全螢幕（toggle——專注時超好用）
  • Ctrl-b x — 關掉目前窗格（會問 y/n）

分割三、四次，每格跑一個 TUI（btop、fastfetch、cmatrix、cbonsai -L 30）——這就是駕駛艙，而且完全沒寫任何設定。用 Ctrl-b d（detach）離開晃一下，再回來：

$ tmux attach -t bridge      # 你的駕駛艙還活著

第一份設定 — 三行，零腳本

tmux 會讀 ~/.config/tmux/tmux.conf。建立檔案，寫這三行：

# ~/.config/tmux/tmux.conf
set -g mouse on                # 可點擊窗格、拖分隔線、捲動
set -g status-position top     # 狀態列移到頂部，像 HUD
set -g default-terminal "tmux-256color"

免重啟重載：Ctrl-b :，輸入 source-file ~/.config/tmux/tmux.conf，按 Enter。（set -g 是「全域設定」；tmux-256color 告訴 tmux 裡的程式可以放心用彩色。）

設定檔 ≠ 腳本 Shell script 是你寫的程式——有邏輯。設定檔是工具讀的設定清單。你的任務禁腳本、擁抱設定：tmux.conf 是宣告式的——每一行都是「把選項 X 設成 Y」。這就是為什麼電影感不需要寫程式。

為什麼預設狀態列那麼醜？

那條綠色底欄是 tmux 的 1990 年代出廠妝。它完全可以換主題——顏色、內容、模組——但手刻很累。下一課我們用套件管理器裝 Catppuccin 主題，狀態列一秒變粉彩 HUD。記住這個模式：主題是「用套件消費的設定」，不是你寫的程式。

現在就做 — 蓋兩次

憑記憶蓋（而非複製貼上）才會留下來。第一輪照著課文；第二輪憑記憶：

  • 建立 session "bridge"，切成 4 格，每格一個 TUI。
  • 用 Ctrl-b z 放大一格，再切回來。
  • Ctrl-b d 脫離，關掉 Ghostty 分頁，再 tmux attach -t bridge 回來。
  • 寫好 3 行 tmux.conf，現場重載。
  • 全部殺掉，憑記憶重建整個網格。
