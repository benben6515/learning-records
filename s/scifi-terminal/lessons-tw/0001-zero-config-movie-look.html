第 01 課 · 科幻終端機

零設定的電影感

約 10 分鐘 4 個指令 先不寫設定

每個科幻駕駛艙——從《異形》的 Nostromo 到《星際爭霸戰》的企業號——其實都是同一張圖：一整面活的系統儀表牆。在我們設定任何東西之前，先用四個指令、零設定得到那個畫面。這正是你任務的第一條規則：現成工具優先，不寫 shell script。

四層堆疊（背起來）

網路上每一個「電影終端機」都是四個獨立工具疊出來的。每一層負責不同的視覺效果——這是貫穿全課的心智模型：

誰負責什麼
  • 第 1 層 — Emulator 終端機（Ghostty）：字體、顏色、透明、模糊
  • 第 2 層 — Multiplexer 多工器（tmux）：窗格網格、邊框、狀態列
  • 第 3 層 — Prompt 提示符（starship）：分段的命令列
  • 第 4 層 — TUI 道具（btop、fastfetch…）：會動的儀表

今天只動第 4 層。btop 你已經有了；我們補上另外兩個搭檔，用平凡的 Ghostty 分頁並排打開。有主題的窗格要等第 02–05 課。

安裝道具

一個指令，三個經典工具（Homebrew 已驗證有這些套件）：

$ brew install fastfetch cmatrix cbonsai

你剛拿到了什麼：

  • fastfetch — 系統資訊面板：OS、CPU、GPU、記憶體，加上 logo。是「船籍資料」儀表。
  • cmatrix — 落下的綠色字符。純電影感，零用途。是氣氛。
  • cbonsai — 用 ASCII 長出來的程式生成盆栽。是「生態艙」面板。
  • btop — 已在你機器上：即時 CPU／記憶體／網路圖表。是「輪機室」。

這些全部是 TUI（Terminal User Interface）：畫在終端機裡的全螢幕互動程式，不是你自己寫的腳本。完整名單見 工具詞彙表。

你的第一個電影畫面

在 Ghostty 開四個分頁（⌘T），每頁跑一個：

$ btop
$ fastfetch
$ cmatrix
$ cbonsai -L 30

離開方式：q（btop、cmatrix）或 Ctrl-c。btop 裡用 1–9 切換版面——找一個你喜歡的。

為什麼這已經很像科幻 電影駕駛艙的設計圍繞三件事：資訊密度 + 動態 + 不對稱：形狀各异的面板，每個都在忙著顯示即時資料。四個分頁的 TUI 意外三項全有。缺的只是同時出現在一個畫面——這正是下一課 tmux 窗格要解決的。
現在就做 — 第一個戰果

蓋出四分頁電影牆，然後像艦橋軍官一樣巡視分頁。做完就打勾（進度存在這台裝置上）：

  • 跑完 brew install 指令，等它結束。
  • 開四個 Ghostty 分頁，啟動 btop、fastfetch、cmatrix、cbonsai。
  • 在 btop 用 1–9 切版面，選一個最愛。
  • 依序巡完四個分頁——好好享受。

然後回答下面兩題，把模型鎖進記憶。
