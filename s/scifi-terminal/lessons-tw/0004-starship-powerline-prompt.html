第 04 課 · 科幻終端機

starship Powerline 提示符

約 10 分鐘 第 3 層 一行指令

第 2 層有主題了；換命令列本身。電影駕駛艙從不出現一個光禿禿的 $——它們顯示分段的狀態條：我在哪、哪個 branch、反應爐健康嗎。那個外觀叫 Powerline prompt，而 starship（你機器上已有）內建一個 Catppuccin 版的 preset——以套件形式發佈的現成設定。一行指令，零腳本。

步驟 0 — 先備份，像個專業人士

你已有一份手調的 ~/.config/starship.toml。蓋掉別人的設定前不備份，是對未來自己的犯罪：

$ cp ~/.config/starship.toml ~/.config/starship.toml.bak

步驟 1 — 套用 preset

$ starship preset catppuccin-powerline -o ~/.config/starship.toml

開一個新 shell（或重啟 tmux）。你的提示符變成一排彩色 powerline 段落：目錄、git branch + 狀態、語言版本、指令耗時——每段都是帶圖示的膠囊，用 箭頭相接，顏色配 Catppuccin mocha。

為什麼叫 "powerline"？為什麼需要 glyph？ Powerline 原本是 2013 年一群 vim 腳本，在提示符段落之間畫斜角分隔。那些斜角不是文字字元——是修補字體裡的 glyph。要記住的依賴鏈就這條：powerline 外觀 → 箭頭 glyph → Nerd Font → Ghostty 已經有了。上一課的 printf 檢查已證實可用。

讀懂你剛拿到的設定

打開 ~/.config/starship.toml 瀏覽。每個段落你會看到：色盤的 fg/bg 顏色、一個 symbol（nerd-font glyph）、一個 style。設定素養勝過複製貼上——下週你可能就想刪掉吵的段落：

# ~/.config/starship.toml（節錄，preset 生成）
[directory]
style = "fg:mochaText bg:mochaPeach"
format = "[ $path ]($style)"
truncation_length = 3
truncation_symbol = "…/"

不喜歡某個顏色？頂部的色盤區塊定義了 mochaBlue 等——改那裡的值，所有段落一起更新。一個色盤，多個效果。

驗證三層一致

你現在有兩層是 Catppuccin：tmux 狀態列（上一課）和提示符（今天）。開一個新的 tmux window，檢查狀態列和提示符像同一套設計系統——同樣的粉彩、同樣的圖示。這份一致性，就是「有主題」和「隨便湊」的差別。第 1 層下一課歸位。

現在就做 — 一段一段看
  • 備份現有 starship.toml。
  • 套用 catppuccin-powerline preset。
  • cd 進某個 git repo——看 git 段落出現。
  • 瀏覽生成的 toml；找到 directory 的 truncation_length 改成 2。
  • 還原備份，誠實比較，留下你的贏家。
