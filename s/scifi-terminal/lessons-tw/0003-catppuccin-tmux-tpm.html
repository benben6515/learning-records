Catppuccin tmux + TPM

約 15 分鐘 第 2 層 套件 + 主題

綠色狀態列是 tmux 的 1990 年代胎記。今天你用任何工具換主題的標準動作把它移除：套件管理的主題，透過設定檔套用。這個模式學一次，fish、neovim、btop、新 Mac 都用同一招。

步驟 0 — 驗證 Nerd Font（30 秒）

有主題的狀態列和提示符充滿圖示——powerline 箭頭、OS logo、模組 glyph。這些來自 Nerd Font。你的 Ghostty 已在跑 0xProto Nerd Font Mono，應該直接可用。驗證：

$ printf '\ue0b0 \uf308 \uf418 \uf425\n'

看到一個箭頭 、Apple logo 和兩個圖示——過關。看到方框或問號，先跟我說，我們把字體修好再繼續。

步驟 1 — 安裝 TPM（套件管理器）

TPM（Tmux Plugin Manager）是 tmux 的套件管理器：你在 tmux.conf 宣告套件，它自動從 GitHub clone。一次性安裝：

$ git clone https://github.com/tmux-plugins/tpm ~/.config/tmux/plugins/tpm

步驟 2 — 宣告主題

把這幾行加進 ~/.config/tmux/tmux.conf（保留第 02 課的行；TPM runner 放最後）：

# ~/.config/tmux/tmux.conf — 接著寫
set -g @plugin 'catppuccin/tmux'
set -g @catppuccin_flavour 'mocha'

run '~/.config/tmux/plugins/tpm/tpm'   # 必須是最後一行

步驟 3 — 安裝並重載

重載 tmux（Ctrl-b : 再 source-file ~/.config/tmux/tmux.conf），然後觸發安裝：

$ # 在 tmux 裡按：
Ctrl-b  I      # 大寫 I = Install — TPM 會 clone catppuccin/tmux

狀態列會顯示安裝訊息。過一會兒你的狀態列變成 Catppuccin mocha：深色底、粉彩模組圖示——session 名、window 清單、日期時間。粉彩 HUD 就是這個。

為什麼是 "mocha"？為什麼粉彩？ Catppuccin 有四種 flavour：latte（亮）、frappé、macchiato、mocha（最深）。深色終端機配 mocha：安靜的背景配彩色重點——「冷靜太空船」色盤，能連續讀幾小時。科幻 UI（和 Catppuccin 設計師）都懂：低飽和背景、高訊號重點。到 catppuccin.com 看四種，之後改一個字就能換。

選配 HUD 微調

兩行大家很愛的（加在 TPM runner 上面）：

set -g @catppuccin_window_tabs_style "right"
set -g @catppuccin_date_time_text "%H:%M"

再試內建膠囊模組，例如 set -g @catppuccin_status_module_text 'music'——每一個都是一行宣告。完整選單在套件 README。

現在就做 — 幹掉綠色狀態列
  • 跑 printf 圖示檢查——確認 Ghostty 能渲染。
  • 把 TPM clone 到 ~/.config/tmux/plugins/tpm。
  • 加上 catppuccin 套件 + flavour 行，TPM runner 放最後。
  • 重載設定，按 Ctrl-b I，看狀態列變身。
  • 把 flavour 改成 macchiato，重載，比較。選一個。
