第 05 課 · 科幻終端機

Ghostty 主題 + 駕駛艙組裝

約 15 分鐘 第 1 層 收穫課

剩最後一層：終端機本身。你的 Ghostty 已經半科幻——opacity 0.66、blur 20、Nerd Font。只缺對的色盤。然後我們把一切組成本課程的成品：駕駛艙。

步驟 1 — 主題那一行

Ghostty 內建 Catppuccin。先看看有哪些：

$ /Applications/Ghostty.app/Contents/MacOS/ghostty +list-themes | grep -i catppuccin

四種 flavour 都會出現（還有 catppuccin-latte 等變體）。編輯 ~/.config/ghostty/config——改一行：

# ~/.config/ghostty/config
theme = catppuccin-mocha

在 Ghostty 按 ⌘⇧, 即時重載（所有視窗立刻換裝——免重啟）。tmux 狀態列、提示符、現在連終端機本體都同一套色盤。三部曲完成。

保留現有的 background-opacity、background-blur 和字體行——它們本來就對。你只改設定的一個字，不是重寫。

步驟 2 — 組裝駕駛艙

把學過的全部依序用上。從新 shell 開始：

$ tmux new -s bridge
# 分割：Ctrl-b %   (左右)      Ctrl-b "   (上下)
# 調整：Ctrl-b Ctrl-← / Ctrl-→ / Ctrl-↑ / Ctrl-↓  (Ctrl 全程按住)

一個好用的布局——先切大概，再用滑鼠微調：

  • 左側，高 — btop（輪機室）
  • 右側，上 — fastfetch（船籍資料）
  • 右側，下 — cmatrix（氣氛）＋有第四格就旁邊放 cbonsai -L 30
沒人教的調整大小技巧 Ctrl-b 之後按住 Ctrl再敲方向鍵——每敲一下窗格就往那個方向長。加 Option 一次跳 5 倍：Ctrl-b Ctrl+Option+→。第 02 課開了滑鼠後拖分隔線也行——但鍵盤調整才是艦橋軍官的動作。

步驟 3 — 跟它一起生活

Detach（Ctrl-b d）讓 session 繼續跑。明天開工前 tmux attach -t bridge 回來。一個可以離開又回來的儀表，才是 session 的全部意義——電影感是更好工作流的副作用。

現在就做 — 組裝
  • 列出 Ghostty 主題；設 theme = catppuccin-mocha；⌘⇧, 重載。
  • 組橋：左 btop、右上 fastfetch、右下 cmatrix。
  • 用 Ctrl-b + Ctrl-方向鍵調到比例順眼。
  • 截圖。這是整門課的 before/after。
  • 脫離、關視窗、明天重新 attach——驗證續命。
