第 06 課 · 科幻終端機

CRT 終章：cool-retro-term

約 10 分鐘 換終端機 課程終章

你的駕駛艙住在 Ghostty 裡——現代、清晰、耐操。最後一招是電影圈最老的技術：換一塊玻璃。cool-retro-term 是一個模擬 1980 年代陰極射線管（CRT）螢幕的終端機——你的 tmux session 原封不動搬進去跑。不用重設主題、不用新設定：層層獨立，所以換掉第 1 層就換掉一切。

為什麼可行：層是可以換的

這是全課最深的道理。tmux 不知道（也不在乎）哪個 emulator 在畫它；starship 不知道自己在哪台終端機；btop 只管印顏色。因為每一層只負責渲染上一層，你可以換掉 emulator、保住整個堆疊。電影 UI 設計師管這叫「螢幕是道具」——內容與玻璃無關。

安裝與啟動

$ brew install --cask cool-retro-term
$ open -a cool-retro-term

在 cool-retro-term 裡面，掛上你現有的 session：

$ tmux attach -t bridge

同一個駕駛艙——現在是掃描線下透著螢光綠、微微彎曲的玻璃。截圖。那就是你要的電影畫面。

調效果

cool-retro-term 的設定（右鍵 → Settings，或滑桿面板）就是 CRT 模擬旋鈕：

  • Scanlines 掃描線 — 橫向暗線。調低「掃描線強度」= 更淡、更現代 HUD。
  • Glow 光暈 — 亮像素往外暈開的程度。高光暈＋綠字 = 經典螢光。
  • Curvature 曲面 — 螢幕邊緣彎曲。一點點就很夠。
  • Flicker / jitter / noise — 擬真 vs. 舒適。日常使用：趨近於零。
  • 內建 preset — 試 Vintage、Green Screen、Modern（淡、其實能天天用）。

把某個調好的樣式設為預設：Settings → Load Preset、微調、再 Current Settings → Set as Default。你的 tmux／starship 主題一行都不用動。

道具 vs. 日常主力 電影 UI 是設計來給人看的，不是給人用的——密、對比低、會閃。你的 Ghostty 設定（第 01–05 課）才是日常主力：色盤冷靜、久看不累。cool-retro-term 是道具：電影感最大、人因最小。你學到的技術是分清楚誰是誰——而且因為堆疊分層，兩個都能要。
現在就做 — 那張關鍵截圖
  • 安裝並打開 cool-retro-term。
  • 在裡面 attach bridge session。
  • 調掃描線、光暈、曲面；試 Green Screen 和 Modern preset。
  • 截圖——本課程最終作品。
  • 重建挑戰：殺掉 session，3 分鐘內憑記憶重組整個 bridge。
