Sci-Fi Terminal Panes · Course Map

Build the Bridge Console

Six short lessons from "plain terminal" to a sci-fi movie bridge console — using existing tools only, config over scripts, understanding over copy-paste. The unchanging mental model: 4 layers — emulator → multiplexer → prompt → TUI props.

Lessons

  • 01 — The Zero-Config Movie Look · install the TUI props, first four-tab movie screen. (~10 min · Layer 4)
  • 02 — tmux Panes From Scratch · the pane grid, prefix key, surviving sessions, first three config lines. (~15 min · Layer 2)
  • 03 — Catppuccin tmux + TPM · kill the green bar: plugin manager, pastel HUD, Nerd Font check. (~15 min · Layer 2)
  • 04 — starship Powerline Prompt · one preset command for the segmented prompt; backup like a professional. (~10 min · Layer 3)
  • 05 — Ghostty Theming + Bridge Assembly · complete the palette trilogy, assemble the finished console. (~15 min · Layer 1 · payoff)
  • 06 — CRT Finale: cool-retro-term · pour the console into a CRT simulator; the movie-prop screenshot. (~10 min · finale)

Reference sheets

  • Hack Toolbox — every "looks like a movie" TUI, grouped by bridge role (the expanded prop catalog).
  • tmux Cheatsheet — every key, command, and the complete course tmux.conf on one printable page.
  • Tool Glossary — which tool plays which role, layer by layer, plus the standard bridge layout.

How to use this course

  • In order, one per day. Each lesson builds on the last; each ends with a visible win.
  • Do the tasks. Checklists save progress; quizzes lock in the model.
  • Re-run 02 and 05 after a week — building the bridge from memory is the graduation test.
