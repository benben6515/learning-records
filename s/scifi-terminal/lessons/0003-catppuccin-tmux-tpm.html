Lesson 03 · Sci-Fi Terminal Panes

Catppuccin tmux + TPM

~15 min Layer 2 Plugin + theme

The green bar is tmux's 1990s birthmark. Today you remove it with the standard pattern for theming any tool: a package-managed theme applied through config. Learn the pattern once here, and you can theme fish, neovim, btop, or a fresh Mac the same way.

Step 0 — verify your Nerd Font (30 seconds)

Themed status bars and prompts are full of icons — powerline arrows, OS logos, module glyphs. Those come from a Nerd Font. Your Ghostty already runs 0xProto Nerd Font Mono, so this should just work. Verify:

$ printf '\ue0b0 \uf308 \uf418 \uf425\n'

If you see an arrow , the Apple logo, and two icons — you're set. If you see boxes or question marks, tell me and we'll fix the font before going on.

Step 1 — install TPM (the plugin manager)

TPM (Tmux Plugin Manager) is tmux's package manager: you declare plugins in tmux.conf, it clones them from GitHub on demand. One-time setup:

$ git clone https://github.com/tmux-plugins/tpm ~/.config/tmux/plugins/tpm

Step 2 — declare the theme

Add these lines to ~/.config/tmux/tmux.conf (keep your Lesson-02 lines; TPM's runner goes last):

# ~/.config/tmux/tmux.conf — continued
set -g @plugin 'catppuccin/tmux'
set -g @catppuccin_flavour 'mocha'

run '~/.config/tmux/plugins/tpm/tpm'   # must be the LAST line

Step 3 — install and reload

Reload tmux (Ctrl-b : then source-file ~/.config/tmux/tmux.conf), then trigger the install:

$ # inside tmux, press:
Ctrl-b  I      # capital I = "Install" — TPM clones catppuccin/tmux

A status message confirms the install. A moment later your bar is Catppuccin mocha: dark background, pastel module icons — session name, window list, date-time. That's the pastel HUD.

Why "mocha"? Why pastel? Catppuccin comes in four flavours: latte (light), frappé, macchiato, mocha (darkest). Mocha on a dark terminal gives quiet backgrounds with colorful accents — the "calm spaceship" palette, readable for hours. Sci-fi UIs (and Catppuccin's designers) know: low saturation background, high signal accents. Browse all four at catppuccin.com and switch flavours later by changing one word.

Optional HUD trim

Two more config lines people love (add above the TPM runner):

set -g @catppuccin_window_tabs_style "right"
set -g @catppuccin_date_time_text "%H:%M"

Also try the built-in pill modules, e.g. set -g @catppuccin_status_module_text 'music' — each is one declarative line. The full menu is in the plugin README.

Do it now — kill the green bar
  • Run the printf glyph check — confirm icons render in Ghostty.
  • Clone TPM to ~/.config/tmux/plugins/tpm.
  • Add the catppuccin plugin + flavour lines, TPM runner last.
  • Reload config, press Ctrl-b I, watch the bar transform.
  • Change the flavour to macchiato, reload, compare. Pick one.
