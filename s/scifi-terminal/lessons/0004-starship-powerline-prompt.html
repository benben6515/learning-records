Lesson 04 · Sci-Fi Terminal Panes

starship Powerline Prompt

~10 min Layer 3 One command

Layer 2 is themed; now the command line itself. Movie consoles never show a bare $ — they show segmented status strips: where am I, what branch, is the reactor healthy. That look is a Powerline prompt, and starship (already installed on your machine) ships a Catppuccin one as a preset — a ready-made config published as a package. One command, zero scripts.

Step 0 — back up, like a professional

You already have a hand-tuned ~/.config/starship.toml. Overwriting someone's config without a backup is a crime against your future self:

$ cp ~/.config/starship.toml ~/.config/starship.toml.bak

Step 1 — apply the preset

$ starship preset catppuccin-powerline -o ~/.config/starship.toml

Open a new shell (or restart tmux). Your prompt is now a row of colored powerline segments: directory, git branch + status, language versions, command duration — each an icon-bearing pill separated by arrows, colored to match Catppuccin mocha.

Why "powerline"? Why it needs glyphs Powerline started as a set of vim scripts (2013) drawing angled separators between prompt segments. The angles aren't text characters — they're glyphs from a patched font. That's the whole dependency chain to remember: powerline look → arrow glyphs → Nerd Font → Ghostty already has one. Your Lesson-03 printf check confirmed this works.

Read the config you just got

Open ~/.config/starship.toml and skim it. You'll find, for each segment: the palette's fg/bg colors, a symbol (a nerd-font glyph), and a style. Config literacy beats copy-paste — next week you might delete a segment you find noisy:

# ~/.config/starship.toml (excerpt, preset-generated)
[directory]
style = "fg:mochaText bg:mochaPeach"
format = "[ $path ]($style)"
truncation_length = 3
truncation_symbol = "…/"

Don't like a color? The palette block at the top defines mochaBlue etc. — change values there and every segment updates. One palette, many effects.

Verify the three layers agree

You now have Catppuccin at two layers: tmux bar (Lesson 03) and prompt (today). Open a fresh tmux window and check the bar and prompt feel like one designed system — same pastels, same icons. That coherence is what separates "themed" from "thrown together". Layer 1 joins next lesson.

Do it now — segment by segment
  • Back up your existing starship.toml.
  • Apply the catppuccin-powerline preset.
  • cd into a git repo — watch the git segment appear.
  • Skim the generated toml; find directory's truncation_length and set it to 2.
  • Restore your backup, compare honestly, keep your winner.
