CRT Finale: cool-retro-term

~10 min Emulator swap Course finale

Your bridge console lives in Ghostty — modern, crisp, productive. The final technique is the oldest one in cinema: change the glass. cool-retro-term is a terminal emulator that simulates a 1980s cathode-ray-tube monitor — and it runs your tmux session inside it, unchanged. No re-theming, no new config: the layers are independent, so swapping Layer 1 changes everything.

Why this works: layers are swappable

This is the deepest lesson of the course. tmux doesn't know (or care) which emulator is drawing it; starship doesn't know which terminal it's in; btop just prints colors. Because each layer only renders the layer above, you can replace the emulator and keep the entire stack. Movie UI designers call the same idea "the screen is a prop" — the content is independent of the glass.

Install and launch

$ brew install --cask cool-retro-term
$ open -a cool-retro-term

Inside cool-retro-term, attach your existing session:

$ tmux attach -t bridge

The same bridge console — now glowing phosphor green under scanlines, on gently curved glass. Take the screenshot. That's the movie frame you asked for.

Dial the effects

cool-retro-term's settings (right-click → Settings, or the sliders overlay) expose the CRT simulation knobs:

  • Scanlines — the horizontal dark lines. Lower "scanline intensity" = subtler, more modern-HUD.
  • Glow / blooming — how much bright pixels bleed outward. High glow + green text = classic phosphor.
  • Curvature — screen edge bending. A little goes far.
  • Flicker / jitter / noise — realism vs. comfort. For daily use: near zero.
  • Built-in profiles — try Vintage, Green Screen, Modern (subtle, actually usable daily).

To make a profile the default: settings → "Load Preset", tune, then "Current Settings → Set as Default". Your tmux/starship theme lines never change.

Prop vs. daily driver Movie UIs are designed to be looked at, not used — dense, low contrast, flickering. Your Ghostty setup (Lessons 01–05) is the daily driver: calm palette, readable for hours. cool-retro-term is the prop: maximum cinema, minimum ergonomics. The technique you learned is knowing which tool is which — and that you can have both, because the stack is layered.

  • Dial scanlines, glow, curvature; try the Green Screen and Modern presets.
