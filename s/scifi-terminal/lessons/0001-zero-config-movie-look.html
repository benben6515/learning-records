Lesson 01 · Sci-Fi Terminal Panes

The Zero-Config Movie Look

~10 min 4 commands No config yet

Every sci-fi console — from Alien's Nostromo to the Enterprise bridge — is really the same picture: a grid of live system readouts. Before we configure anything, you'll get that picture with four commands and zero configuration. This is your mission's first rule in action: existing tools first, no shell scripts.

The 4-layer stack (memorize this)

Every "movie terminal" on the internet is a stack of four independent tools. Each layer owns different visual effects — this is the mental model for the whole course:

Who owns what
  • Layer 1 — Emulator (Ghostty): fonts, colors, transparency, blur
  • Layer 2 — Multiplexer (tmux): the pane grid, borders, status bar
  • Layer 3 — Prompt (starship): the segmented command line
  • Layer 4 — TUI props (btop, fastfetch…): the moving readouts

Today we only touch Layer 4. You already have btop; we'll add its two co-stars and open them side by side in plain Ghostty tabs. Themed panes arrive in Lessons 02–05.

Install the props

One command, three classic tools (Homebrew does the work — verified available):

$ brew install fastfetch cmatrix cbonsai

What you just got:

  • fastfetch — the system-info panel: OS, CPU, GPU, memory, plus a logo. The "ship registry" readout.
  • cmatrix — falling green glyphs. Pure cinema, zero purpose. The mood.
  • cbonsai — a growing procedural bonsai tree in ASCII. The "bio-dome" panel.
  • btop — already on your machine: live CPU / memory / network graphs. The "engine room".

These are all TUIs — Terminal User Interfaces: full-screen interactive apps drawn inside the terminal, not scripts you wrote. See the tool glossary for the full crew.

Your first movie screen

In Ghostty, open four tabs (⌘T) and run one command per tab:

$ btop
$ fastfetch
$ cmatrix
$ cbonsai -L 30

Quit each with q (btop, cmatrix) or Ctrl-c. In btop, 1–9 switch UI layouts — find one you like.

Why this already looks sci-fi Movie consoles are designed around information density + motion + asymmetry: different-shaped panels, each busy with live data. Four tabs of TUIs accidentally have all three. What they lack is being on screen at once — that's what tmux panes fix in Lesson 02.
Do it now — your first win

Build the four-tab movie screen, then flip through the tabs like a bridge officer. Tick as you go (progress saved on this device):

  • Run the brew install command and wait for it to finish.
  • Open four Ghostty tabs and launch btop, fastfetch, cmatrix, cbonsai.
  • In btop, cycle layouts with 1–9 and pick a favorite.
  • Flip through all four tabs in sequence — enjoy it.
