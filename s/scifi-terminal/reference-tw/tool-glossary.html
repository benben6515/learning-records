工具詞彙表

駕駛艙的完整班底：哪個工具演哪個角色、住在哪一層、需要的唯一指令。概念定義在工作區的 GLOSSARY.md。

第 1 層 — Emulator 終端機（玻璃）

工具角色指令
Ghostty日常主力。字體、色盤、透明、模糊設定檔 theme = catppuccin-mocha；⌘⇧, 重載
cool-retro-term道具。CRT 掃描線、螢光、曲面brew install --cask cool-retro-term；open -a cool-retro-term
Warp這台 Mac 有裝；不屬於本堆疊—

第 2 層 — Multiplexer 多工器（窗格）

工具角色指令
tmux 3.7b窗格網格、邊框、狀態列；不死的 sessiontmux new -s bridge → 速查表
TPMtmux 的套件管理器git clone …/tpm ~/.config/tmux/plugins/tpm；Prefix I 安裝
catppuccin/tmux粉彩 HUD 狀態列主題set -g @plugin 'catppuccin/tmux'

第 3 層 — Prompt 提示符（命令列）

工具角色指令
starship快速、可主題化的提示符引擎starship preset catppuccin-powerline -o ~/.config/starship.toml
Nerd Font（0xProto）供應 powerline 箭頭與圖示驗證：printf '\ue0b0 \uf308\n'

第 4 層 — TUI 道具（儀表）

工具艙位角色指令
btop輪機室——CPU/GPU/記憶體/網路圖表btop；1–9 版面、q 離開
fastfetch船籍資料——OS/CPU/GPU + logo 面板fastfetch
cmatrix氣氛——落下的綠色字符cmatrix；q 離開
cbonsai生態艙——程式生成 ASCII 盆栽cbonsai -L 30；Ctrl-c 離開
