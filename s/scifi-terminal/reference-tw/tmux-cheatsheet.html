tmux 速查表

課程用到的每個 tmux 按鍵與指令，一頁列印。Prefix = Ctrl-b（按住放開後再按指令鍵）。依 tmux 3.7b 驗證。

Session — 工作區

指令作用
tmux new -s bridge建立具名 session
tmux ls列出 session
tmux attach -t bridge重新掛上 session
Prefix dDetach（session 繼續跑）
Prefix $重新命名 session
Prefix sSession 選單

Pane — 科幻面板

指令作用
Prefix %分左右
Prefix "分上下
Prefix ←→↑↓窗格間移動
Prefix z窗格全螢幕（toggle）
Prefix x關閉窗格
Prefix Ctrl-←→↑↓調整大小（方向鍵全程按住 Ctrl）
Prefix Ctrl+Opt+方向鍵大步調整
Prefix q閃現窗格編號
Prefix Space循環預設布局（even-horizontal、main-pane…）
Prefix { / }與相鄰窗格交換

Window — 全螢幕分頁

指令作用
Prefix c新 window
Prefix n / p下 / 上一個 window
Prefix 1–9跳到第 N 個 window
Prefix &關閉 window
Prefix ,重新命名 window

設定與重載

指令作用
Prefix :命令提示
source-file ~/.config/tmux/tmux.conf重載設定（在 Prefix : 輸入）
Prefix ITPM：安裝套件
Prefix UTPM：更新套件

檔案：~/.config/tmux/tmux.conf——設定用 set -g、套件用 set -g @plugin，TPM runner run '…/tpm/tpm' 永遠最後。

課程完整版 tmux.conf

# ~/.config/tmux/tmux.conf
set -g mouse on
set -g status-position top
set -g default-terminal "tmux-256color"

# 主題（第 03 課）
set -g @plugin 'catppuccin/tmux'
set -g @catppuccin_flavour 'mocha'
set -g @catppuccin_window_tabs_style "right"
set -g @catppuccin_date_time_text "%H:%M"

# 套件管理器 — 最後一行
run '~/.config/tmux/plugins/tpm/tpm'

階層 — 記住順序

server → session（bridge）→ window（分頁）→ pane（面板）。Session 活過終端機關閉；所以駕駛艙隨時待命。完整詞彙：工具詞彙表 · 課程地圖。
