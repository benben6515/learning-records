懶人包 — 一行全裝

最快蓋出一面電影牆(為 macOS 挑的密度 + 多樣性組合):

$ brew install btop glances asitop fastfetch bandwhich termshark \
    lazygit lazydocker gdu yazi lnav tty-clock mapscii cmatrix \
    cbonsai genact no-more-secrets pipes-sh asciiquarium figlet lolcat
