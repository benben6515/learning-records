tmux Cheatsheet

Every tmux key and command used in the course, on one printable page. Prefix = Ctrl-b (press and release, then the command key). Verified against tmux 3.7b.

Sessions — the workspace

CommandDoes
tmux new -s bridgeStart named session
tmux lsList sessions
tmux attach -t bridgeRe-attach to session
Prefix dDetach (session keeps running)
Prefix $Rename session
Prefix sSession picker

Panes — the sci-fi panels

CommandDoes
Prefix %Split left/right
Prefix "Split top/bottom
Prefix ←→↑↓Move between panes
Prefix zZoom pane full-screen (toggle)
Prefix xKill pane
Prefix Ctrl-←→↑↓Resize (hold Ctrl through arrows)

Config & reload

CommandDoes
Prefix :Command prompt
source-file ~/.config/tmux/tmux.confReload config (type at Prefix :)
Prefix ITPM: install plugins
Prefix UTPM: update plugins

File: ~/.config/tmux/tmux.conf — settings with set -g, plugins with set -g @plugin, TPM runner run '…/tpm/tpm' always last.

The course tmux.conf, complete

# ~/.config/tmux/tmux.conf
set -g mouse on
set -g status-position top
set -g default-terminal "tmux-256color"

# theme (Lesson 03)
set -g @plugin 'catppuccin/tmux'
set -g @catppuccin_flavour 'mocha'
set -g @catppuccin_window_tabs_style "right"
set -g @catppuccin_date_time_text "%H:%M"

# plugin manager — LAST line
run '~/.config/tmux/plugins/tpm/tpm'

Hierarchy — remember the order

server → session (bridge) → window (tab) → pane (panel). Sessions survive terminal closure; that's why the bridge is always ready. Full glossary: tool glossary · course map.
